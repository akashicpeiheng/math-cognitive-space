# 张量 (Tensor)

#微分几何 #张量 #多重线性代数 #定义 #通用技术 #入门

张量是向量的自然推广：它是在[[向量空间]]（或[[流形]]上每点的切空间）上取多个向量与对偶向量为输入的实值多重线性函数。张量的概念源于"寻找与坐标系选择无关的物理规律的数学公式"这一需求，"张量"这一术语可能源于它最早被用于研究弹性体中一点的应力系统。如今，张量在微分几何、广义相对论以及众多数学分支中扮演着基础角色。

# 前置知识

## 必备知识

- **[[向量空间]]与基底**：知道 $n$ 维[[向量空间]] $V$、基底 $\{e_i\}$、元素的分量展开 $u = u^i e_i$。
- **线性函数（对偶向量）**：知道线性映射 $f: V \to \mathbb{R}$ 的概念；全体这样的线性函数构成对偶空间 $V^*$，其对偶基底 $\{e^j\}$ 满足 $e^j(e_i) = \delta^j_i$。
- **多重线性**：一个函数如果对每一个输入分量都各自是线性的，就称为多重线性（多重线性映射的含义可以比喻为一部机器：只要输入，便生产出一个实数，且此实数对每个输入量都线性依赖）。

## 辅助知识

- **基变换与协变/反变规律**：设 $\tilde{e}_i = a_i^k e_k$，对偶基底满足 $e^i = a_j^i \tilde{e}^j$。向量 $u \in V$ 的分量遵循"反变"规律，而 $f \in V^*$ 的分量遵循 $\tilde{f}_j = a_j^i f_i$，与基底自身的变换规律一致，故称"协变"。反变向量和协变向量强调的是分量在基底变换下变换规律的异同：前者是 $V$ 本身的元素，后者是 $V^*$ 的元素。
- **Einstein 求和约定**：相同指标出现时要对其求和。
- **矩阵相似变换**：(1, 1) 型张量在不同基底下对应相似矩阵，这帮助理解缩并与迹。

## 拓展知识

- **[[微分流形]]与切空间**：[[流形]]上每点 $p$ 有切空间 $T_p M$ 与[[余切空间]] $T_p^* M$，张量的定义可以逐点搬到[[流形]]上得到张量场。
- **范畴论中的[[张量积]]**：同态的[[张量积]] $f \otimes g$ 满足单位律 $\mathrm{id}_A \otimes \mathrm{id}_B = \mathrm{id}_{A \otimes B}$，[[张量积]]可以看成一个二元函子。
- **[[协变导数]]与联络**：[[切丛]]上的联络可以通过要求"与[[张量积]]、外积、缩并可交换"推广到任意型张量场上。

# 动机

## 引入动机

- **学科内部线索**：[[向量空间]]中出现了两类"向量"——$V$ 中的元素（反变向量）与 $V^*$ 中的元素（协变向量），其分量在基底变换下遵循不同规律。要在一个统一框架下同时处理这两类量以及它们的多重线性组合（如双线性函数、二次型、线性算子），就需要一个能同时容纳多个上、下指标的结构。
- **外部应用线索**：最初张量计算的目的是要找到与坐标系的选择无关的物理规律的数学公式，这类公式称为张量方程。如果公式两边都是同类型的张量，只要它们在一个坐标系下成立，则它们在任意一个坐标系下都成立。弹性体中一点的应力系统是最早的物理原型。
- **审美/结构线索**：张量的概念在数学上已经被解释为[[向量空间]] $V$ 或 $V^*$ 上的多重线性函数，这是一个简洁、统一且与坐标无关的定义，"使一个对象的存在被视为理所当然"。

## 构造动机

概念的"胚子"是分量式的：在过去，$V$ 上的 $(r, s)$ 型张量是用分量来定义的——如果对于 $V$ 的每一个基底指定了 $n^{r+s}$ 个数 $\tau^{i_1 \cdots i_r}_{j_1 \cdots j_s}$，使得当基底变换时这组数按照多重的反变、协变线性变换规律变换，则称这种结构为一个张量。经典教材（如 Dubrovin–Fomenko–Novikov）也采用这种方式：张量（或张量场）是相对于一个坐标系的一族数，每个点对应一组分量，坐标变换时按固定的多重链式法则变换。

这个胚子的"发展"是：用这组数构造多重线性函数 $\tau^{i_1 \cdots i_r}_{j_1 \cdots j_s} e_{i_1} \otimes \cdots \otimes e_{i_r} \otimes e^{j_1} \otimes \cdots \otimes e^{j_s}$，它与基底的选择无关，于是是张量空间中完全确定的元素。现在我们直接采用多重线性函数来定义张量，这样更方便、意义更明确。这正是现代规范形式取代分量式定义的过程。

# 形式

## 规范的通用形式

现代规范形式（多重线性函数定义）：

> 设 $(r, s)$ 为非负整数对。如果函数
> $$\theta : \underbrace{T_p^* M \times \cdots \times T_p^* M}_{r} \times \underbrace{T_p M \times \cdots \times T_p M}_{s} \to \mathbb{R}$$
> 对于每个分量都是线性的，则称 $\theta$ 为 $p$ 处的 $(r, s)$ 型张量；$r$ 称为逆变指数，$s$ 称为协变指数。全体 $(r, s)$ 型张量记作 $\otimes^{r,s} T_p M$（或 $V_s^r = \mathcal{L}(V^*, \dots, V^*; V, \dots, V; \mathbb{R})$），在自然的加法和数乘下成为[[向量空间]]。

与分量式定义的对比：分量式定义把张量视为"在所有坐标系下的全部分量表示的总体"，直观且贴近计算（Ricci 演算正是基于此）；多重线性函数定义则是坐标无关的，"更方便、意义更明确"，适合现代几何的语言。两种定义等价（见"证明"一节）。Needham 的表述把输入空位分成两组并记一条界线：$H(\varphi_1, \cdots, \varphi_f \| v_1, \cdots, v_v)$，输入的顺序一般来说很重要。

张量的阶（rank）是它所取的输入（向量和/或对偶向量）的总数 $r + s$；按约定 0 阶张量就是实数。我们规定 $(r, 0)$ 型的张量称为 $r$ 阶的逆变张量，$(0, s)$ 型的张量称为 $s$ 阶的协变张量。

## 必要条件分析

本笔记对象是定义而非定理，但定义中的两个条件各自不可或缺：

- **多重线性**：若去掉对某一分量的线性性，则分量在基变换下不再遵循纯线性的变换规律，张量方程"在一个坐标系成立即在所有坐标系成立"的性质随之崩溃。
- **取值只依赖求值点处的输入**：Needham 强调张量的第二个定义性质是"输出只依赖于在求值点的输入向量"。例如黎曼曲率 $R$ 的定义式虽由导数建立，但它只取决于位于特定点的三个向量的值，而与向量在该点附近如何变化无关——如果这一条不满足（比如某个含二阶导的表达式），它就不是张量。对位置函数 $J$（满足 $J(o)=1$）把 $W_{\mathrm{OLD}}$ 换成 $W_{\mathrm{NEW}} = J W_{\mathrm{OLD}}$，直接计算表明 $R(U, V; W_{\mathrm{NEW}}) = R(U, V; W_{\mathrm{OLD}})$ 在 $o$ 处成立，含 $J$ 的导数的四项"奇迹般地"全部抵消。

## 等价表达

设 $\{e_i\}$ 是 $V$ 的基底，$\{e^j\}$ 是对偶基底，则 $(r, s)$ 型张量空间 $V_s^r$ 的基底是

$$\{e_{i_1} \otimes \cdots \otimes e_{i_r} \otimes e^{j_1} \otimes \cdots \otimes e^{j_s}\},$$

任意 $\tau \in V_s^r$ 可表示为

$$\tau = \tau^{i_1 \cdots i_r}_{j_1 \cdots j_s} e_{i_1} \otimes \cdots \otimes e_{i_r} \otimes e^{j_1} \otimes \cdots \otimes e^{j_s},$$

其分量是 $\tau^{i_1 \cdots i_r}_{j_1 \cdots j_s} = \tau(e^{i_1}, \cdots, e^{i_r}, e_{j_1}, \cdots, e_{j_s})$。在[[流形]]上，$(0, s)$ 型张量（协变张量）的基底为 $dx^{j_1}|_p \otimes \cdots \otimes dx^{j_s}|_p$，分量 $A_{j_1 \cdots j_s} = A_p(\partial/\partial x^{j_1}, \cdots, \partial/\partial x^{j_s})$。

**变换律**：设 $\tilde{e}_i = a_i^k e_k$，对偶基底 $\tilde{e}^j = b_l^j e^l$（$(b_l^j)$ 是 $(a_l^j)$ 的逆矩阵），则

$$\tilde{\tau}^{i_1 \cdots i_r}_{j_1 \cdots j_s} = b_{k_1}^{i_1} \cdots b_{k_r}^{i_r} a_{j_1}^{l_1} \cdots a_{j_s}^{l_s} \tau^{k_1 \cdots k_r}_{l_1 \cdots l_s}.$$

在[[流形]]上，$(k, l)$ 型张量在两个坐标系中的分量变换关系（张量变换律）为

$$T'^{\mu_1 \cdots \mu_k}{}_{\nu_1 \cdots \nu_l} = \frac{\partial x'^{\mu_1}}{\partial x^{\rho_1}} \cdots \frac{\partial x^{\sigma_l}}{\partial x'^{\nu_l}} T^{\rho_1 \cdots \rho_k}{}_{s_1 \cdots s_l}.$$

许多教科书正是采用上式作为张量定义，它与多重线性函数定义等价。

## 形式的类别

张量是"一大堆东西的总称"，按 $(r, s)$ 分类，经典例子包括：

- 速度向量是 $(1, 0)$ 型张量；
- 余向量（对偶向量）是 $(0, 1)$ 型张量；
- 向量上的二次型是 $(0, 2)$ 型张量；余向量上的二次型是 $(2, 0)$ 型张量；
- 向量或余向量上的线性算子是 $(1, 1)$ 型张量；
- 度规 $g$ 是对称、非退化的 $(0, 2)$ 型张量（对称指 $g(v, u) = g(u, v)$，非退化指 $g(v, u) = 0, \forall u \Rightarrow v = 0$）；
- 黎曼曲率张量 $R$ 是输入三个向量、输出一个向量的多重线性映射，通过用一个 1-形式缩并后，成为阶为 $(1,3)$（1 上 3 下）型的张量：$R(\varphi \| u, v, w) := \varphi(\delta w)$。

按输入结构还有：$(1, s)$ 型张量是取值在切空间中的多重线性映射 $A_p: (T_pM)^s \to T_pM$。

## 在自然语言中，相关命题如何表达？

"张量是一部机器，有 $k$ 个上槽和 $l$ 个下槽，只要在上、下槽分别输入 $k$ 个对偶矢量和 $l$ 个矢量，便生产出一个实数，且此实数对每个输入量都线性依赖。"（梁灿彬）"一个张量是输入若干个 1-形式和若干个向量的实值多重线性函数，它在某点的值只依赖于这些 1-形式和向量在该点的值。"（Needham）"张量是类似于向量的量，在基底变换时其分量按多重的反变或协变线性变换规律进行变换。"（陈维桓）

## 降维表述

在更底层的语言（集合论、范畴论）中：张量是多重线性映射这一"泛性质式"的对象。两个[[向量空间]] $V, W$ 的[[张量积]]可定义为

$$V \otimes W = \{f: V^* \times W^* \to \mathbb{R} \mid f \text{ 关于两个分量都是线性的}\},$$

其中 $v \otimes w(\varphi, \psi) = \varphi(v) \cdot \psi(w)$；双线性函数与线性函数之间的这种一一对应转换关系是[[张量积]]运算的特征性质。同态的[[张量积]] $(f \otimes g)(a \otimes b) = f(a) \otimes g(b)$ 的构造由"$(a,b) \mapsto f(a) \otimes g(b)$ 是双线性的"保证，它满足单位律 $\mathrm{id}_A \otimes \mathrm{id}_B = \mathrm{id}_{A \otimes B}$；从 $A, B$ 得到 $A \otimes B$、从 $f, g$ 得到 $f \otimes g$，既可以看成一种二元运算，也可以看成一个二元函子（姜伯驹《同调论》）。

## 升维视角

- **张量场**：在[[流形]] $M$ 上每点指定一个 $(k, l)$ 型张量，就得到一个 $(k, l)$ 型张量场；若对任意光滑对偶矢量场与光滑矢量场的输入，输出都是光滑函数，则称为[[光滑张量场]]。
- **张量代数**：$\otimes T_p M = \sum_{r,s} \otimes^{r,s} T_p M$（有限和），连同加法、数乘和[[张量积]]形成 $\mathbb{R}$ 上的一个代数，称为张量代数。
- **张量丛上的联络**：令 $\nabla$ 与[[张量积]]、外积、缩并运算可交换，可将[[切丛]]上的联络推广到任意型张量丛；协变微分为零的张量场称为平行张量场，在 Levi-Civita 联络下[[黎曼度量]]总是平行的。

## 相似对象联动理解

- **对称与反称张量**：$(0, 2)$ 型张量可表为其对称和反称部分之和 $T_{ab} = T_{(ab)} + T_{[ab]}$，其中 $T_{(ab)} := \frac{1}{2}(T_{ab} + T_{ba})$，$T_{[ab]} := \frac{1}{2}(T_{ab} - T_{ba})$；但对 $l > 2$ 的 $(0, l)$ 型张量此分解不成立，例如 $T_{abc} \neq T_{(abc)} + T_{[abc]}$，然而 $T_{abc} = T_{(abc)} \Rightarrow T_{[abc]} = 0$。
- **外形式**：$r$ 阶协变张量空间 $V_r^0 = \mathcal{L}(V, \cdots, V; \mathbb{R})$ 是 $n^r$ 维[[向量空间]]，反称的协变张量即外形式——外代数是张量代数的商结构这一视角可与之联动。

# 证明

## 概括证明

核心命题"分量式定义与多重线性函数定义等价"的证明可以一句话概括：**用分量造出来的多重线性函数与基底无关，用多重线性函数取分量则自动满足变换律。**

## 细节

**命题 1（两种定义等价）**：给定每个基底下满足变换律 (1.2.14) 的一族数，构造 $\tau^{i_1 \cdots i_r}_{j_1 \cdots j_s} e_{i_1} \otimes \cdots \otimes e^{j_s}$，则它与基底选择无关，是 $V_s^r$ 中完全确定的元素；反之，任何多重线性函数 $\tau$ 的分量 $\tau(e^{i_1}, \cdots, e_{j_s})$ 在 $\tilde{e}_i = a_i^k e_k$ 下满足

$$\tilde{\tau}^{i_1 \cdots i_r}_{j_1 \cdots j_s} = \tau(\tilde{e}^{i_1}, \cdots, \tilde{e}^{i_r}, \tilde{e}_{j_1}, \cdots, \tilde{e}_{j_s}) = b_{k_1}^{i_1} \cdots b_{k_r}^{i_r} a_{j_1}^{l_1} \cdots a_{j_s}^{l_s} \tau^{k_1 \cdots k_r}_{l_1 \cdots l_s},$$

即变换律成立，故两种定义给出同一对象类。

**命题 2（同型张量构成线性空间）**：在同一点，同型张量的集合构成线性空间。若 $T = (T^{i_1 \cdots i_p}_{j_1 \cdots j_q})$ 与 $S = (S^{i_1 \cdots i_p}_{j_1 \cdots j_q})$ 都是 $(p, q)$ 型张量，则任意线性组合 $\lambda T + \mu S = U$ 也是 $(p, q)$ 型张量，分量 $U^{i_1 \cdots i_p}_{j_1 \cdots j_q} = \lambda T^{i_1 \cdots i_p}_{j_1 \cdots j_q} + \mu S^{i_1 \cdots i_p}_{j_1 \cdots j_q}$。要点是：线性组合必须由**同一点**的相应分量构成——若把张量看成定义在空间各点上的函数族，则不同点的张量不能直接相加。$\otimes^{0,1} T_p M = T_p^* M$，$\otimes^{1,0} T_p M = T_p^{**} M = T_p M$（不区分 $T_p M$ 与其二次对偶）；$(r, s) = (0, 0)$ 时规定为 $\mathbb{R}$。

**命题 3（缩并的良定义性）**：(1, 1) 型张量 $T$ 可看作 $V$ 到 $V$ 的线性变换；同一 $T$ 在任意两个基底的分量矩阵互为相似矩阵：$T'^\mu_{\nu} = (A^{-1})^\mu_{\rho} T^\rho_{\sigma} A^{\sigma}_{\nu}$，故

$$T'^\mu_{\mu} = (A^{-1})^\mu_{\rho} T^\rho_{\sigma} A^{\sigma}_{\mu} = \delta^{\sigma}_{\rho} T^\rho_{\sigma} = T^\rho_{\rho},$$

即不同基底下矩阵有相同的迹。迹 $T^\mu_{\mu}$ 是与基底无关的性质，称为 $T$ 的缩并 (contraction)。一般地，$(r, s)$ 型张量关于第一个反变指标和第一个协变指标的缩并就是把这两个指标取相同的值并在求值范围内求和，得到 $(r-1, s-1)$ 型张量，分量为 $(C(\tau))^{i_1 \cdots i_{r-1}}_{j_1 \cdots j_{s-1}} = \tau^{k i_1 \cdots i_{r-1}}_{k j_1 \cdots j_{s-1}}$。

**命题 4（[[张量积]]的性质与张量代数）**：[[张量积]]

$$\otimes : \otimes^{r,s} T_p M \times \otimes^{t,h} T_p M \to \otimes^{r+t, s+h} T_p M, \quad (\theta, \eta) \mapsto \theta \otimes \eta$$

定义为 $(\theta \otimes \eta)(W_1, \cdots, W_{r+t}; X_1, \cdots, X_{s+h}) = \theta(W_1, \cdots, W_r; X_1, \cdots, X_s) \cdot \eta(W_{r+1}, \cdots; X_{s+1}, \cdots)$，满足：对加法的分配律、数乘的结合 $(\lambda\theta) \otimes \eta = \theta \otimes (\lambda\eta) = \lambda(\theta \otimes \eta)$、结合律 $(\theta \otimes \xi) \otimes \eta = \theta \otimes (\xi \otimes \eta)$，且 $(\otimes^{r,s} T_p M) \otimes (\otimes^{t,h} T_p M)$ 与 $\otimes^{r+t, s+h} T_p M$ 同构。注意（Needham 强调）：在两个 1-形式的[[张量积]] $(\varphi \otimes \psi)(v, w) = \varphi(v)\psi(w)$ 中，次序很重要，$\varphi \otimes \psi \neq \psi \otimes \varphi$；张量乘法中阶数相加，因此标量可以看作 0 阶张量。

**命题 5（对称/反称分解，$l = 2$ 情形）**：设 $T(u, v) = T_{ab} u^a v^b$，$T(v, u) = T_{ab} v^a u^b = T_{ba} u^a v^b$，故 $T$ 对称当且仅当 $T_{ab} = T_{ba}$。若 $T_{abc} = T_{(abc)}$，则展开式（共 $l!$ 项）中每一项都等于 $T_{abc}$；若 $T_{abc} = T_{[abc]}$，则偶排列项等于 $T_{abc}$、奇排列项等于 $-T_{abc}$。

# 应用

## 直接应用

- **度规张量与欧氏几何**：$n$ 维欧氏[[向量空间]] $(V, g)$ 中，同一个向量既有反变分量 $(u^1, \cdots, u^n)$（由 $u = u^i e_i$），也有协变分量 $u_i = u \cdot e_i$；后者按 1 阶协变规律变换。由关于 $\lambda$ 的二次多项式的判别式得 $g^2(u, v) - g(u,u)g(v,v) \le 0$，从而可以定义长度 $|u| = \sqrt{u \cdot u}$ 与夹角余弦 $\cos\angle(u, v) = g(u,v)/(|u||v|)$。度规还是升降指标的桥梁：用度规降指标 $g_{ca} T^a_{\ b} = T_{cb}$。
- **黎曼曲率张量**：$R$ 告诉我们空间本身的曲率。将最初"输出向量 $\delta w$"的定义用 1-形式 $\varphi$ 缩并，改造成标准张量形式 $R(\varphi \| u, v, w) = \varphi(\delta w)$，其关于 $w$ 的线性性由 $\delta(k_1 w_1 + k_2 w_2) = k_1 \delta w_1 + k_2 \delta w_2$ 与内蕴导数的线性性直接证实。

## 间接应用

- **张量方程的坐标不变性**：只要公式两边都是同类型张量，在一个坐标系下成立就在任意坐标系下成立——这是张量在物理规律表述中"确实有用"的核心。
- **物理（广义相对论）**：能量-动量张量 $\mathbf{T}$、爱因斯坦张量 $\mathbf{G}$、度规张量 $\mathbf{g}$ 都用粗体罗马字母表示的典型高阶张量；闵氏度规 $\eta_{ab}$ 把基向量映为对偶基：$\eta_{ab}(\partial/\partial x^0)^b = -(dx^0)_a$，$\eta_{ab}(\partial/\partial x^i)^b = (dx^i)_a$。
- **对称性与各向同性**：在反射与交换坐标下保持不变性可推出各向同性张量的限制：唯一的各向同性二阶张量是标量矩阵 $(\lambda \delta^i_j)$；三阶的各向同性张量只有零张量（Dubrovin–Fomenko–Novikov）。各向同性概念涉及等距群，因而以（黎曼）度规的存在为前提，但张量概念本身并不依赖度规。
- **同调代数**：带系数的同调群理论中，[[张量积]]的函子性质（单位律、可加性）是基础工具。

# 推广

- **从点到场**：从一点处的张量推广为[[流形]]上的（光滑）张量场，再推广为张量丛上的联络与协变微分 $\nabla T$（一个 $(r, s+1)$ 型场张量），$\nabla$ 与 $\otimes$、$\wedge$、缩并均可交换。
- **从[[向量空间]]到一般模**：同调论中[[张量积]]对任意 Abel 群（模）定义，同态的[[张量积]]与函子性质在带系数同调群中发挥作用。
- **记号体系的推广**：抽象指标记号把上下指标视为"空位类型"的标记而非取值分量，形式上与具体指标记号极为相似，是"张量面面观"的简单直观体现。注意各文献对协变/逆变张量空间的记号约定并不统一（Lee 提醒读者留意每位作者的约定）。

# 常见的误解

- **误解一：张量就是一组数（矩阵/数组）**。原因：分量式定义先入为主。初学者忽略了"这组数必须按特定变换规律变换"这一条件——同一组数在不同基底下给出不同的族时，并不构成张量。正确观点是：张量是坐标无关的多重线性函数本身，分量只是它在某个坐标系下的"照片"。
- **误解二：上、下指标只是记号差异，$T^a_b$ 与 $T_{ba}$ 一样**。原因：忽略了上、下指标分别容纳对偶矢量与矢量两类不同的输入。在不用度规升降指标时上下指标各排各的序，但一旦升降指标就必须小心；只有对称张量才允许写 $T_{ab} = T_{ba}$（梁灿彬强调：用抽象指标写等式比用它单独表示一个张量时要更为小心）。
- **误解三：任何多重线性式都是张量**。忽略了"取值只依赖求值点处输入值"这一条件：含导数的表达式（如联络系数）一般不是张量；黎曼曲率之所以是张量，靠的是含 $J$ 导数的四项恰好抵消这种"非平凡"的机制。
- **误解四：任意张量都能分解为对称加反称部分**。这只对 2 阶情形成立；$l > 2$ 时 $T_{abc} \neq T_{(abc)} + T_{[abc]}$。
- **误解五：张量概念依赖度规**。各向同性的概念需要度规，但张量概念本身不依赖度规（Dubrovin–Fomenko–Novikov 特别注明）。

# 启发

- 一个"多坐标系下都要成立"的物理需求，最终被提炼为一个纯代数的、坐标无关的对象。**先有变换规律、后有不变对象**，这个顺序值得记住：不变性可以从繁琐的规律中"长"出来。
- "机器带槽"的比喻让人意识到：数学可以这样看——对象的本质在于它**接受什么输入、按什么规则输出**，而不在于它在某个坐标系里长什么样。
- 黎曼曲率中"导数表达式却是张量"的现象与"假奇迹"的提醒形成共鸣：表面上偶然的抵消背后往往有结构性的原因，值得追问而不是庆祝。

# 总结

## 思想

把"与坐标无关的量"统一为"多重线性函数"：分量会变，对象不变；变换规律不是定义的枷锁，而是不变性的表达。

## 方法

- **对偶转化**：通过 $V \leftrightarrow V^*$ 的对偶视角统一逆变与协变（用于定义与降维表述）。
- **比较法**：两种定义（分量式 vs 多重线性式）互相翻译以证等价（用于"等价表达"）。
- **基底无关性检验**：通过相似矩阵验证迹的基底无关性（用于缩并的良定义性）。
- **反例构造**：对每个条件构造"删掉即崩溃"的反例（用于必要条件分析与常见误解）。

# 回看并提问
