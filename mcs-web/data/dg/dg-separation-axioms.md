# 分离公理

> 拓扑空间的开集公理非常一般，以至于很多"坏"空间也能满足。分离公理是一系列附加条件，要求拓扑具有足够多的开集来"分开"空间中本应分开的点或闭集。它们就像给拓扑空间加上了不同精度的"显微镜"——从最低配的 T₀ 到最高配的 T₄，每升一级就可以区分更复杂的对象。

# 前置知识

## 必备知识

- **拓扑空间与开集、闭集**：知道什么是拓扑、开集、闭集、邻域、闭包等基本概念。
- **连续映射与同胚**：知道连续映射的定义，以及拓扑等价（同胚）的含义。
- **单点集闭包**：理解单点集的闭包可能包含其他点，这一点在 T₀ 和 T₁ 公理的区别中至关重要。

## 辅助知识

- **序列极限**：了解一般拓扑空间中序列极限的定义，以及极限不唯一性的原因。Hausdorff 空间的一个核心优点就是极限唯一。
- **紧致性**：知道紧致空间的定义。Hausdorff 条件下的紧致子集具有许多良好性质（如闭性）。

## 拓展知识

- **可数公理**：第一可数公理（C₁）和第二可数公理（C₂）与分离公理协同工作。例如"第二可数 + 正则 ⇒ 正规"就是两个体系交叉应用的典范。
- **Urysohn 引理与 Tietze 扩张定理**：这两个定理本质上刻画了正规空间，是分离公理理论的高峰。
- **Urysohn 度量化定理**：第二可数 + 正规 Hausdorff 空间可度量化，这是分离公理和可数公理结合的终极成果之一。
- **流形与微分几何**：流形的定义中明确要求 Hausdorff 条件，这是为了排除"看起来像局部欧氏空间但整体奇怪"的空间。

# 动机

## 引入动机

**学科内部线索**：拓扑公理（开集公理）本身非常宽泛，由此出发能够证明的结论非常有限。例如，在一般拓扑空间中，一个序列可以收敛到多个不同的点；一个连续函数可以无法将两个不相交闭集区分开；甚至单点集都不一定是闭集。这些"反常识"现象说明拓扑公理太弱，需要补充额外的条件。

**历史线索**：Hausdorff 在 1914 年的经典著作《Grundzüge der Mengenlehre》（集合论基础）中提出的邻域公理体系，其实比现代通用的拓扑公理多了一个条件——这个条件后来被单独拆出来，称为 **Hausdorff 性质**（T₂ 公理）。也就是说，在 Hausdorff 眼中，"空间"天然就应该有分离性质。后来的数学家将分离条件剥离出来，形成了一族独立的公理。

**外部应用线索**：在微分几何中，流形被定义为"局部同胚于欧氏空间"的拓扑空间，但仅此条件远远不够——存在局部同胚于 ℝⁿ 但不是 Hausdorff 的空间（例如带两个原点的直线）。为了保证流形上能够做分析和构造单位分解，必须加上 Hausdorff 条件。

**审美/结构线索**：分离公理形成了一个自然的"阶梯"——T₀ → T₁ → T₂ → T₃ → T₄，每一级都在前一级基础上增加了区分能力。这种层级结构本身就具有美感，也让数学家可以根据需要"按需取用"。

## 构造动机

从度量空间出发来理解分离公理是最自然的路径。

**第一步：从度量空间看"分离"是什么**。在 ℝⁿ（或一般的度量空间）中，任意两个不同的点 x ≠ y，它们之间的距离 d(x, y) > 0。取 ε = d(x, y)/2，则两个球形邻域 B(x, ε) 和 B(y, ε) 互不相交。这就是 T₂ 公理（Hausdorff 性质）的胚子。

**第二步：从区分点到区分闭集**。在度量空间中，如果一个闭集 A 和另一个闭集 B 不相交，那么它们之间也有"距离"——可以证明存在开邻域 U ⊇ A 和 V ⊇ B 使得 U ∩ V = ∅。这就是 T₄ 公理（正规性）的胚子。

**第三步：抽象化为公理阶梯**。将上述观察分别提炼为不同层次的条件，就得到了 T₀–T₄ 分离公理。字母 T 来自德语的"Trennungsaxiom"（分离公理）。

# 形式

## 规范的通用形式

下面列出最常用的五个分离公理。每个公理都可以独立于其他公理来定义，但在实际应用中通常搭配 T₁ 公理使用。

### T₀ 公理（Kolmogorov 性质）

**定义**：对任意两个不同的点 x, y ∈ X，存在一个开集 U，使得 U 恰好包含其中一点而不包含另一点。

**解读**：这是最弱的分离条件，只要求"能区分"两个点，但不要求区分的方式是对称的。

### T₁ 公理（Fréchet 性质）

**定义**：对任意两个不同的点 x, y ∈ X，存在 x 的开邻域 U 不含 y，也存在 y 的开邻域 V 不含 x。

**等价刻画**：X 满足 T₁ 公理当且仅当 X 中的每个单点集都是闭集。

**解读**：T₁ 要求两个点能被"互斥地"区分——用开集包围 x 时能排除 y，反过来也能。T₁ 公理意味着每个有限子集都是闭集。

### T₂ 公理（Hausdorff 性质）

**定义**：对任意两个不同的点 x, y ∈ X，存在不相交的开邻域 U ∋ x 和 V ∋ y。

**等价刻画**：对角线 Δ = {(x, x) | x ∈ X} 是 X × X 的闭子集。

**解读**：这是最重要的分离公理，满足 T₂ 的空间称为 **Hausdorff 空间**。它保证两个点可以被"完全隔开"——各自有不相交的邻域。

### T₃ 公理（正则性）

**定义**：X 满足 T₁ 公理，且对任意闭集 F ⊂ X 和任意点 x ∉ F，存在不相交的开邻域 U ∋ x 和 V ⊇ F。

**解读**：T₃ 将"区分对象"从两个点推广到"一个点和一个闭集"——要求能用开集将一个点和它外面的闭集隔开。满足 T₁ + T₃ 的空间称为**正则空间**。

### T₄ 公理（正规性）

**定义**：X 满足 T₁ 公理，且对任意两个不相交的闭集 A, B ⊂ X，存在不相交的开邻域 U ⊇ A 和 V ⊇ B。

**解读**：T₄ 将"区分对象"进一步推广到"两个不相交的闭集"。满足 T₁ + T₄ 的空间称为**正规空间**。

> **术语提醒**：不同文献对"正则空间"和"正规空间"的定义略有差异。有些书直接用 T₃ 空间指代正则空间、T₄ 空间指代正规空间（不要求额外满足 T₁），而另一些书则要求 T₁ + T₃ 或 T₁ + T₄。阅读时需注意上下文。

### 关系图

在 T₁ 公理满足的前提下，这些公理有清晰的蕴涵关系：

```
T₄（正规）⇒ T₃（正则）⇒ T₂（Hausdorff）⇒ T₁ ⇒ T₀
```

> 注意：没有 T₁ 的前提时，T₃ 和 T₄ 不一定能推出 T₂。例如在 ℝ 上取拓扑 τ = {(−∞, a) | −∞ ≤ a ≤ +∞}，该空间满足 T₄（因为任何两个非空闭集都相交，导致 T₄ 条件空真），但不满足 T₁、T₂ 或 T₃。

## 必要条件分析

### 删除 T₁ 条件会怎样？

T₁ 公理等价于"单点集是闭集"。如果去掉这个条件，T₃ 和 T₄ 公理就失去了"区分闭集"的意义——因为根本不知道哪些集合是闭集。例如上文的 (−∞, a) 拓扑，它满足 T₄ 但单点集不是闭集，因此不是 T₁ 空间，也不满足 T₂ 和 T₃。

### 在 T₂ 基础上删除"不相交"

如果只要求两个点各自有邻域但不要求它们不相交，那其实就是 T₁ 公理，它允许序列极限不唯一等"坏"现象。T₂ 的"不相交"是关键。

### 删除 T₂：为什么流形定义必须加 Hausdorff 条件？

考虑两条直线的并集 ℝ × {0, 1}，将除了 (0,0) 和 (0,1) 以外的所有对应点 (x,0) 和 (x,1) 粘合起来。得到的商空间每个点都有一个邻域同胚于 ℝ 的开子集，但 (0,0) 和 (0,1) 这两个点的任意邻域都相交——因此不是 Hausdorff 空间。如果不加 Hausdorff 条件，这个"伪流形"就会混入流形的范畴，导致很多分析工具失效。

## 等价表达

### T₁ 公理的等价表述

- X 满足 T₁ 公理 ⇔ X 的每个单点集是闭集。
- X 满足 T₁ 公理 ⇔ X 的每个有限子集是闭集。
- X 满足 T₁ 公理 ⇔ X 的拓扑包含余有限拓扑（即所有有限集的补集都是开集）。

### T₂ 公理的等价表述

- X 是 Hausdorff 空间 ⇔ 对角线 Δ = {(x, x)} 是 X × X 的闭子集。
- X 是 Hausdorff 空间 ⇔ 收敛序列的极限唯一（当 X 还满足第一可数公理时，这个条件也是充分的）。

### T₃ 公理的等价表述

- X 满足 T₁ + T₃ ⇔ 对任意点 x 和它的开邻域 W，存在 x 的开邻域 U 使得 Ū ⊆ W。

### T₄ 公理的等价表述

- X 满足 T₁ + T₄ ⇔ 对任意闭集 A 和它的开邻域 W，存在 A 的开邻域 U 使得 Ū ⊆ W。
- X 是正规空间 ⇔（Urysohn 引理）对任意两个不相交闭集 A, B，存在连续函数 f: X → [0, 1] 使得 f(A) = {0}，f(B) = {1}。
- X 是正规空间 ⇔（Tietze 扩张定理）定义在闭子集上的连续实值函数可以连续延拓到整个空间。

## 在自然语言中，相关命题如何表达？

- **T₀**："任意两个点，至少有一个有开集把自己包住而排除另一个。"
- **T₁**："任意两个点，各自都能找开集包住自己、排除对方。"
- **T₂**："任意两个点，各自有不相交的开邻域，完全隔开。"
- **T₃**："一个闭集外面的一点，可以和这个闭集完全隔开。"
- **T₄**："两个不相交的闭集，可以完全隔开。"

## 降维表述

用集合论的语言重新叙述：

- **T₀**：∀x ≠ y ∈ X，∃U ∈ 𝒯，使得 (x ∈ U ∧ y ∉ U) 或 (y ∈ U ∧ x ∉ U)。
- **T₁**：∀x ≠ y ∈ X，∃U, V ∈ 𝒯，使得 x ∈ U, y ∉ U 且 y ∈ V, x ∉ V。
- **T₂**：∀x ≠ y ∈ X，∃U, V ∈ 𝒯，使得 x ∈ U, y ∈ V, U ∩ V = ∅。
- **T₃**：X 满足 T₁，且 ∀F 闭集，∀x ∉ F，∃U, V ∈ 𝒯，使得 x ∈ U, F ⊆ V, U ∩ V = ∅。
- **T₄**：X 满足 T₁，且 ∀A, B 闭集，A ∩ B = ∅，∃U, V ∈ 𝒯，使得 A ⊆ U, B ⊆ V, U ∩ V = ∅。

## 升维视角

- 在**范畴论**中，Hausdorff 空间的对角线映射 X → X × X 是闭嵌入，这可以看作"分离性"的范畴化表达。
- 在**代数几何**中，概形（scheme）的分离性类比于 Hausdorff 性质，但用"对角线是闭嵌入"来定义，因为 Zariski 拓扑下 Hausdorff 条件几乎从不成立。
- 在**泛函分析**中，每个 Banach 空间在弱拓扑下都是 Hausdorff 空间（由 Hahn–Banach 定理保证），这保证了"足够多的线性泛函可以区分点"。
- 在**微分几何**中，流形上的单位分解定理依赖于 Hausdorff 条件和第二可数公理，而单位分解是把局部构造（如 Riemann 度量、向量场）拼成整体对象的基石。

# 证明

## 概括证明

**命题 1：T₁ 公理 ⇔ 单点集是闭集**
> 若 T₁ 成立，任取 y ≠ x，由 T₁ 知 y 有邻域不含 x，故 y 不是 x 的聚点，因此 {x} 的闭包就是自身。反之，若单点集是闭集，则 X\{y} 是含 x 而不含 y 的开邻域，同理 X\{x} 是含 y 而不含 x 的开邻域。

**命题 2：Hausdorff 空间中收敛序列的极限唯一**
> 设序列 {xₙ} 收敛到两个不同的点 x 和 y。取 x 和 y 的不相交开邻域 U 和 V。由收敛性，U 和 V 都包含 {xₙ} 的几乎所有项，这与 U ∩ V = ∅ 矛盾。

**命题 3：Hausdorff 空间的紧致子集是闭集**
> 设 A 是 Hausdorff 空间 X 的紧致子集，x ∉ A。对每个 y ∈ A，取 x 和 y 的不相交开邻域 U_y 和 V_y。{V_y} 覆盖 A，由紧致性存在有限子覆盖 {V_{y₁}, …, V_{yₙ}}，则 U = ∩ U_{yᵢ} 和 V = ∪ V_{yᵢ} 是 x 和 A 的不相交开邻域，因此 x 不是 A 的聚点，A 为闭集。

**命题 4：T₃ 的等价形式——闭邻域刻画**
> T₃ 成立当且仅当对任意点 x 和它的开邻域 W，存在 x 的开邻域 U 使得 Ū ⊆ W。（证明由定义直接构造。）

**命题 5：T₄ 的等价形式——闭邻域刻画**
> T₄ 成立当且仅当对任意闭集 A 和它的开邻域 W，存在 A 的开邻域 U 使得 Ū ⊆ W。（证明：取 B = Wᶜ，则 A 与 B 为不相交闭集，由 T₄ 存在不相交开邻域 U ⊇ A 和 V ⊇ B，则 Ū ⊆ Vᶜ ⊆ W。）

**命题 6：Urysohn 引理（正规空间的函数刻画）**
> X 是正规空间当且仅当对任意不相交闭集 A, B，存在连续函数 f: X → [0, 1] 使得 f(A) = {0}，f(B) = {1}。证明核心是利用正规性归纳构造一列以二进位有理数编号的开集，然后定义 f(x) = inf{r | x ∈ Uᵣ}。

**命题 7：第二可数 + 正则 ⇒ 正规**
> 利用可数拓扑基，分别构造 A 和 B 的可数开覆盖，再通过"交错截断"技巧构造出不相交的开邻域。这个定理说明在第二可数空间中，T₃ 自动"升级"为 T₄。

# 应用

## 直接应用

**例 1 度量空间满足所有 T₁–T₄ 公理**：度量空间 (X, d) 中单点集是闭集（T₁），不同点取 ε = d(x, y)/2 的球形邻域不相交（T₂），对不相交闭集 A, B 可构造连续函数 f(x) = d(x, A)/(d(x, A) + d(x, B)) 再用 Urysohn 引理或直接构造邻域（T₄）。

**例 2 Hausdorff 空间中连续函数的不动点集是闭集**：设 f: X → X 连续，X 为 Hausdorff 空间，则 Fix(f) = {x | f(x) = x} 是闭集。因为 g(x) = (x, f(x)) 的像为连续映射，而 Hausdorff 空间中对角线是闭集，故原像为闭集。

**例 3 Hausdorff 空间中连续映射的图是闭集**：设 Y 为 Hausdorff 空间，f: X → Y 连续，则 G_f = {(x, f(x))} 是 X × Y 的闭子集。

**例 4 紧致 Hausdorff 空间是正规空间**：紧致 Hausdorff 空间不仅自身是 Hausdorff 的，而且自动满足 T₄ 公理。这为在紧致空间上应用 Urysohn 引理提供了保证。

**例 5 紧致子集与 Hausdorff 空间**：若 A 是 Hausdorff 空间 X 的紧致子集，x ∉ A，则 x 与 A 有不相交的开邻域。这一定理在分析中经常用于将点与紧集分离。

## 间接应用

- **Urysohn 度量化定理**：一个满足第二可数公理的正规 Hausdorff 空间可以嵌入到 Hilbert 空间，从而可度量化。这个定理的证明中，分离公理（T₄）和可数公理（C₂）缺一不可——先用 T₄ 构造可数多个 Urysohn 函数，再用 C₂ 保证这些函数足以区分不同的点。
- **单位分解定理**：在微分几何中，流形上的光滑单位分解依赖于 Hausdorff 条件和第二可数公理。单位分解在微分几何中无处不在——从构造 Riemann 度量到定义流形上的积分。
- **Tietze 扩张定理**：正规空间上的连续函数可以从闭子集延拓到整个空间。这是泛函分析和拓扑学中常用的工具，例如在 Hahn–Banach 定理的几何形式证明中有着类似的思想。
- **Stone–Čech 紧化**：完全正则空间（T₃½ 空间）存在最大的紧化，称为 Stone–Čech 紧化 βX，它是泛函分析和拓扑代数中研究 C*-代数的基本工具。
- **商空间与群作用**：若 X 是 Hausdorff（或正规）空间，群 G 在 X 上作用，则商空间 X/G 也是 Hausdorff（或正规）空间。这一结论在拓扑群和代数拓扑中经常使用。

# 推广

- **T₃½（完全正则性）**：介于 T₃ 和 T₄ 之间的分离公理。空间 X 称为完全正则的（或 Tychonoff 空间），如果它是 T₁ 空间，且对任意闭集 F 和点 x ∉ F，存在连续函数 f: X → [0, 1] 使得 f(x) = 1，f(F) = {0}。Urysohn 引理说明 T₄ ⇒ T₃½，而 T₃½ ⇒ T₃。Tychonoff 空间的重要性在于它是 Stone–Čech 紧化的存在前提。
- **T₅（完全正规性）**：要求空间是 T₁ 且所有子空间都正规。这等价于任意两个"分离的"子集（A ∩ cl(B) = cl(A) ∩ B = ∅）有不相交的开邻域。
- **T₆（完美正规性）**：要求空间是 T₁ 且每个闭集都是可数个开集的交集（Gδ 集）。
- **分离公理与乘积空间**：T₁、T₂、T₃ 都具有可乘性（两个空间的乘积仍保持该性质），但 T₄ 不具有可乘性——Sorgenfrey 平面就是两个正规空间的乘积不正规的经典反例。
- **分离公理与子空间**：T₁、T₂、T₃ 都具有遗传性（子空间保持该性质），但 T₄ 不具有遗传性——正规空间的子空间不一定正规。
- **公开问题**：在一般拓扑学中，寻找同时满足某些分离公理和可数公理但又不平凡的空间，一直是构造性拓扑学的研究主题。例如，是否存在一个正则 Hausdorff 空间不是完全正则的？这类问题在 20 世纪中叶引发了大量构造性工作。

# 常见的误解

**误解 1："T₂ 空间就是度量空间"**
事实：Hausdorff 空间是度量空间的必要条件，但不是充分条件。存在 Hausdorff 空间不可度量化（例如 Sorgenfrey 直线 ℝₛ 是 Hausdorff 空间，但不可度量化；不过更简单的反例是：任何不可数集上的余可数拓扑是 Hausdorff 空间，但不是度量空间，因为度量空间满足第一可数公理，而余可数拓扑在不可数集上不满足 C₁）。

**误解 2："T₃ ⟹ T₂ 不需要任何额外条件"**
事实：T₃ 公理的定义本身就包含了 T₁ 条件（单点集是闭集），因此 T₃ 确实能推出 T₂。但如果不要求 T₁，单独的"点与闭集分离"条件推不出 T₂。例如 (−∞, a) 拓扑满足 T₄（从而满足 T₃），但不满足 T₁ 和 T₂。所以关键在于"T₃ 暗含了 T₁"。

**误解 3："正规空间就是'正常'的空间"**
事实：正规空间（T₄）的条件其实相当强，很多在日常中常见的空间并不正规。例如 Sorgenfrey 平面 ℝₛ × ℝₛ 是正则 Hausdorff 空间但不是正规的。又如 ℝ 上的 Zariski 拓扑（闭集为有限集）不是正规空间。事实上，在一般拓扑学中，正规性是一个相当"脆弱"的性质——它不遗传给子空间，也不在乘积下保持。

**误解 4："T₀ 和 T₁ 差别不大，可以忽略"**
事实：T₀ 和 T₁ 的差别其实很关键。T₀ 只要求"能区分"两个点，但不要求"对称地"区分；而 T₁ 要求对称区分。在 T₀ 空间中，单点集不一定是闭集。例如在 ℝ 上取拓扑 {∅, ℝ, {0}}，这个空间是 T₀ 的但不是 T₁ 的，因为 {0} 不是闭集。T₀ 是几乎所有"正经"拓扑空间都满足的条件，而 T₁ 才真正保证了点作为拓扑学"原子"的独立性。

# 启发

- **"精度阶梯"思想**：分离公理展现了一种"分级调节"的思维模式——从区分点到区分闭集，从非对称区分到对称区分，每一级都在前一级的基础上提升精度。这种"逐步加强条件"的思维在数学中随处可见（如 Lᵖ 空间、可微性分类等）。
- **"反例驱动"的学习方式**：分离公理的学习中，**反例是理解的关键**。正是那些不满足某条公理的空间（如余有限拓扑不满足 T₂、Sorgenfrey 平面不满足 T₄），才让我们真正理解每条公理存在的意义。没有一个反例是"为了刁难人"而构造的——它们都是天然出现在数学中的。
- **"微观"与"宏观"的区分**：T₁ 和 T₂ 关注的是"点与点"的微观分离，T₃ 关注的是"点与闭集"的分离，T₄ 关注的是"闭集与闭集"的宏观分离。这种从微观到宏观的递进，对应着"拓扑工具"从弱到强的能力范围。
- **"存在足够多的连续函数"是分离公理的隐性目标**：T₄ 的 Urysohn 引理告诉我们，正规空间上存在足够多的连续函数来区分闭集。而 T₃½（完全正则性）则直接以"存在足够多的连续函数"为定义。这提示我们：拓扑空间是否需要更多的连续函数，取决于我们想要在空间上做什么样的分析。

# 总结

## 思想

> **"用开集去分离，从点到闭集，每提升一级就多一分操作空间。"**

分离公理的核心思想是：用开集作为"隔离层"，将空间中不应该混淆的部分（点、闭集）区分开来。分离能力越强，能做的分析工具就越多（连续函数、极限唯一性、紧致性等）。

## 方法

| 方法 | 在笔记中的应用 |
|------|---------------|
| **构造不相交开邻域** | T₂ 公理中取 ε/2 球形邻域证明度量空间是 Hausdorff |
| **闭邻域刻画** | T₃ 和 T₄ 的等价形式（Ū ⊆ W）在证明中反复使用 |
