# σ-代数

简介：σ-代数是测度论的"舞台"。我们想给集合量"长度、面积、体积"，但很快就发现：不可能给一个集合的**所有**子集都合理地指派测度。补救的办法，是先把注意力收缩到"一部分子集"上，只对这部分子集谈测度。σ-代数正是对"这部分子集"的最低要求：它要包含空集、对取补封闭、对可数并封闭。有了它，才有可测空间、可测映射、测度与积分。

# 前置知识

## 必备知识

只需要三样东西：

1. **集合的运算**：并 $A\cup B$、交 $A\cap B$、差 $A\setminus B$、补 $A^c=X\setminus A$（$X$ 为预先给定的全集）。

2. **De Morgan 公式**：$(A\cap B)^c=A^c\cup B^c$，$(A\cup B)^c=A^c\cap B^c$，$(A^c)^c=A$。这条公式是整篇笔记里反复使用的一把钥匙——它把"并"和"交"在取补下互为对偶这件事写清楚了。

3. **幂集**：$X$ 的一切子集构成的集合，记为 $\mathcal{P}(X)$（也记作 $\mathcal{D}(X)$ 或 $2^X$）。若 $X$ 有 $n$ 个元素，则幂集有 $2^n$ 个元素。

另外需要知道"可数"的意思：能与自然数集建立对应（有限或可数无限）。σ-代数里的 σ 就是冲着"可数"来的。

## 辅助知识

- **开集与闭集**（度量空间或拓扑空间中）：开集对任意并封闭、对有限交封闭；闭集对任意交封闭、对有限并封闭。把拓扑的三条性质与 σ-代数的三条性质摆在一起对照看，收获最大。
- **连续映射**：$f$ 连续 $\iff$ 每个开集的原像是开集。
- **可数个有理数可以排列成序列**：$\mathbb{Q}$ 可数，这件事让 $\mathbb{R}$ 上的 Borel 代数可以由可数个集合生成。

## 拓展知识

- 外测度、Carathéodory 可测条件、Carathéodory 扩张定理（从代数上的加性函数扩张出 σ-代数上的测度）。
- 拓扑群上的 Haar 测度（Lebesgue 测度的平移不变性是它的一个特例）。
- $L^p$ 空间的可分性与 σ-代数的可分性之间的等价。
- 度量空间的完备化——与测度空间的完备化形成了漂亮的平行。

# 动机

## 引入动机

**路径一（学科内部线索）：想把"体积"做成一个能取极限的工具。**

我们希望有一个定义在集合上的函数 $m$，满足三条性质：

- (a) 若 $E=[a,b]$ 是区间，则 $m(E)=b-a$（与直觉一致）；
- (b) 若 $E=\bigcup_{n=1}^{\infty}E_n$ 且诸 $E_n$ 两两不交，则 $m(E)=\sum_{n=1}^{\infty}m(E_n)$（可数可加）；
- (c) $m(E+h)=m(E)$（平移不变）。

其中 (b) 之所以必须是"可数可加"而不能只是"有限可加"，是因为分析中到处是极限论证，只有可数可加才撑得住。可一旦要求可数可加，就必须先回答一个问题：**这些 $E_n$ 以及它们的并，得落在同一族被允许谈论的集合里**：否则"$\bigcup_n E_n$ 的测度"这句话本身就没有意义。也就是说，可数可加这条要求，逼着我们去挑出一个"对可数并封闭"的集合族。σ-代数就是被 (b) 逼出来的。

**路径二（外部/反面线索）：幂集太大了，并非人人都配拥有体积。**

最理想的情形是：给 $\mathbb{R}^d$ 的**每一个**子集都指派一个非负数作为它的测度（长度／面积／体积），允许取 $+\infty$，并且同时满足上面的 (a)(b) 与平移不变性。

这个想法是错的——**这样的测度根本就不存在**。$\mathbb{R}$ 中就存在不可测集（Vitali，1905）：利用 $[0,1]$ 中"两数之差为有理数"这一等价关系，从每个等价类中各取一个代表组成集合 $\mathcal{N}$，则 $\mathcal{N}$ 不可测。由此得出的结论是：**一个令人满意的测度论不可能包含 $\mathbb{R}$ 的所有子集**。

**路径三（审美/结构线索）：退一步，海阔天空。**

既然不能给所有子集都指派测度，补救的办法是：只测量一族特定类型的集合——可测集。一旦把注意力限制在可测集上，(a)(b)(c) 就全部满足了；而我们日常遇到的集合几乎都是可测的（开集、闭集都可测），对分析学来说已经足够好。

于是问题从"测度的定义域该是什么"翻转成了：**在 $\mathcal{P}(X)$ 中，什么样的子集族配得上当测度的定义域？** 答案要求它：非空、能取补、能取可数并（从而也能取可数交）。这就是 σ-代数。

## 构造动机

σ-代数不是一步到位的发明，它有一个"由有限走向可数"的清晰胚子：

| 阶段 | 结构 | 封闭的运算 | 地位 |
|---|---|---|---|
| 前身 | 半环、环 | 差、有限并（半环：交、真差） | 测度最初被定义的地方（面积的基本砖块） |
| 胚子 | **代数**（域） | 有限并、补 | 有限可加测度的自然定义域 |
| 成型 | **σ-代数** | 可数并、补 | 可数可加测度的自然定义域 |

从代数到 σ-代数，只改一个字：把"有限并"换成"可数并"。这一字之差恰恰是整个 Lebesgue 理论区别于 Jordan／Riemann 式"有限可加"理论的关键：**分析中要做极限，而极限天然要用到可数操作**。

再往前一步，还有"由谁生成"的问题：我们手上往往只有一小撮集合（比如所有开集、所有半开区间），希望用它们撑起一个 σ-代数。由于任意多个 σ-代数的交仍是 σ-代数，就可以把所有"包含这小撮集合的 σ-代数"交起来，得到包含它们的最小 σ-代数 $\sigma(\mathcal{M})$。由开集生成的那个，就是 Borel 代数 $\mathcal{B}(X)$。

历史节点：1898 年 Borel 提出可测集；1902 年 Lebesgue 建立测度与积分理论；1905 年 Vitali 构造出不可测集。

# 形式

## 规范的通用形式

**形式 A（以 $\varnothing$ 起手，最常见的教科书形式）**

给定集合 $X$，$\mathcal{A}\subset\mathcal{P}(X)$ 是 $X$ 的某些子集构成的集合族。若

1. $\varnothing\in\mathcal{A}$；
2. 若 $A\in\mathcal{A}$，则 $A^c\in\mathcal{A}$；
3. 若 $A_1,A_2,\cdots\in\mathcal{A}$（可数个），则 $\bigcup_{i=1}^{\infty}A_i\in\mathcal{A}$；

则称 $\mathcal{A}$ 是 $X$ 上的一个 **σ-代数**。若把 3) 中的"可数"换成"有限"，得到的就叫 **代数**。

**形式 B（以全集起手）**

$\mathcal{F}$ 是 $\Omega$ 上的 σ-代数，如果

(i) $\Omega\in\mathcal{F}$；
(ii) 对补封闭；
(iii) 对可列并封闭。

**两种形式的对比**：形式 A 与形式 B 等价。形式 A 中 $\varnothing\in\mathcal{A}$ 配合 2) 立刻给出 $X=\varnothing^c\in\mathcal{A}$；形式 B 中 $\Omega\in\mathcal{F}$ 配合 (ii) 立刻给出 $\varnothing\in\mathcal{F}$。

- 形式 A 的好处：条件 1) 是一条"存在性"陈述，验证时第一步最轻（只要指出空集在族里），与"测度要求 $\mu(\varnothing)=0$"的口径一致，读起来像是"最小元素在族内"。
- 形式 B 的好处：直接点明"全集本身要可测"，与可测空间 $(\Omega,\mathcal{F})$ 中"整块舞台在族里"的直觉一致；并且在验证"由某族集合生成 σ-代数"时，先检查 $\Omega$ 往往比先检查 $\varnothing$ 更自然。

**由定义立即得到**：对 σ-代数 $\mathcal{A}$，有 $X\in\mathcal{A}$，且可数交也封闭：

$$A_i\in\mathcal{A}\ (i\ \text{可数})\ \Longrightarrow\ \bigcap_{i}A_i=\Big(\bigcup_i A_i^c\Big)^c\in\mathcal{A}.$$

理由只有一句：**并和交在取补下是对偶的**。

## 必要条件分析

现在逐条删掉条件，看结论如何崩溃。

**删掉 1)（不含空集）**：其实若 $\mathcal{A}\neq\varnothing$ 且满足 2)、3)，则 1) 是自动的：任取 $A\in\mathcal{A}$，由 2) 得 $A^c\in\mathcal{A}$，由 3)（把二元并写成可数并）得 $A\cup A^c=X\in\mathcal{A}$，再取补得 $\varnothing\in\mathcal{A}$。所以条件 1) 的真正作用只是**排除空族 $\mathcal{A}=\varnothing$ 这一平凡情形**、保证族非空。这是"三条公理并非彼此独立"的一个漂亮例证。

**删掉 2)（不对补封闭）**：取 $X$ 为不可数集，令 $\mathcal{A}=\{A\subset X: A\ \text{可数}\}\cup\{X\}$。它含 $\varnothing$ 与 $X$，对可数并封闭，但对补封闭失败：可数集的补一般既不可数也不等于 $X$。于是"从里面减去一个集合"都做不到——差集 $A\setminus B=A\cap B^c$ 也就无从谈起。整条测度论会立刻卡死在"单调性 $A\subset B\Rightarrow\mu(A)\le\mu(B)$"这一步。

**把 3) 的"可数并"缩回"有限并"**：得到的是代数而非 σ-代数，最要命的损失是**不能取极限**。经典反例：令 $\Omega=\mathbb{R}$，$I_k=[k-1,k)$，$\mathcal{A}_n=\sigma\{I_k:1\le k\le n\}$。每个 $\mathcal{A}_n$ 都是 σ-代数，但对每个 $n$ 有 $[0,n)\in\mathcal{A}_n$，而 $\bigcup_{n\ge1}[0,n)=[0,\infty)$ 不属于任何一个 $\mathcal{A}_n$，从而不属于 $\bigcup_n\mathcal{A}_n$：**递增的 σ-代数序列之并，对可列并不封闭**。

另一个标准例子（不可数 $\Omega$ 上）：$\mathcal{A}=\{A\subset\Omega: A\ \text{有限或}\ A^c\ \text{有限}\}$ 是代数但不是 σ-代数。

**再多要一点（不可数并）会怎样**：不能要。可测集族对可数并、可数交封闭，但**不可数并或不可数交是不允许的**。$\mathbb{R}^d$ 中任意一点的单点集都可测且测度为零，若允许不可数并，则任意集合都是可测的零测集——整套理论当场塌掉。这正是"σ"这个字母的边界所在。

## 等价表达

设 $\mathcal{F}$ 是代数，则下列各条等价：

(i) $\mathcal{F}$ 是 σ-代数；
(ii) $\mathcal{F}$ 对单调下降序列的极限封闭，即 $A_n\in\mathcal{F}$，$A_n\downarrow\ \Rightarrow\ \bigcap_{n=1}^{\infty}A_n\in\mathcal{F}$；
(iii) $\mathcal{F}$ 对单调上升序列的极限封闭，即 $A_n\uparrow\ \Rightarrow\ \bigcup_{n=1}^{\infty}A_n\in\mathcal{F}$；
(iv) $\mathcal{F}$ 对可列不交并封闭。

（(ii)、(iii) 说的是同一件事的两面：取补即可互换；(iv) 之所以够用，是因为**任何可数并都能改写成可数不交并**：$\bigcup_n A_n=\biguplus_n\big(A_n\setminus\bigcup_{k<n}A_k\big)$。）

还有两组非常好用的"拼装公式"：

- **σ-代数 = 代数 + 单调类**。单调类 $\mathcal{M}\subset\mathcal{P}(\Omega)$ 指的是对单调序列的极限封闭（既对上升、又对下降）。
- **σ-代数 = π 类 + λ 类**。λ 类指：(i) $\Omega\in\mathcal{A}$；(ii) 对真差封闭；(iii) 对单调上升序列的极限封闭；π 类指对有限交封闭。

这两组公式的实用价值在教学上极高：验证"σ-代数"这种涉及**可数**运算的性质很痛苦，而"代数"只涉及有限运算、"单调类／λ 类"只涉及单调极限，两者都更容易验证。这就是"把 σ 的东西拆成有限的东西 + 极限的东西"的技术。

## 形式的类别

把相关概念摆在一起看层级：

| 名称 | 封闭的运算 | 与 σ-代数的关系 |
|---|---|---|
| 半环 | 交、真差 | 测度最初的定义域，生成 σ-代数 |
| 代数 | 有限并、补 | 把"有限并"换成"可数并"即得 σ-代数 |
| **σ-代数** | 可数并、可数交、补 | 本体 |
| 单调类 | 单调序列的极限 | σ-代数必是单调类；反之需补上"代数" |
| λ 类 | 真差、单调上升极限（含 $\Omega$） | 再补上"π 类"即得 σ-代数 |
| 子 σ-代数 | 同上 | $\mathcal{A}'\subset\mathcal{A}$ 且自身是 σ-代数 |
| Borel σ-代数 $\mathcal{B}(X)$ | 同上 | 由 $X$ 中一切开集生成的 σ-代数 |
| 乘积 σ-代数 $\mathcal{A}_1\otimes\mathcal{A}_2$ | 同上 | 由矩形 $A_1\times A_2$ 生成 |

三个近乎平凡却必须刻在脑子里的例子：

1. $\mathcal{A}=\mathcal{P}(X)$ 是 $X$ 上的 σ-代数（最大的）；
2. $\mathcal{A}=\{\varnothing,X\}$ 是 $X$ 上的 σ-代数（最小的）；
3. 若 $X$ 是**可数集**，$\mathcal{A}$ 是 $X$ 上的 σ-代数且对每个 $x\in X$ 有 $\{x\}\in\mathcal{A}$，则 $\mathcal{A}=\mathcal{P}(X)$——因为此时任何子集都是可数个单点的并。

边界提示：若 $\Omega$ 是**有限集**，则 $\Omega$ 上任何一个代数都是 σ-代数（有限集只有有限多个子集，可列并本质上都是有限并）。所以"代数 vs σ-代数"的区别只在无限集上才显现。

## 在自然语言中，相关命题如何表达？

- $A\in\mathcal{A}$ ⟶ "$A$ 是**可测集**"（在还没谈测度之前，说"$A$ 是被允许谈论的集合"更贴切）。
- 对补封闭 ⟶ "若我能测量 $A$，我就能测量'不在 $A$ 里的那部分'。"
- 对可数并封闭 ⟶ "若我能测量 $A_1,A_2,\dots$，我就能测量'落在其中至少一个里'的那部分。"
- $\mathcal{A}'\subset\mathcal{A}$ 是子 σ-代数 ⟶ "信息更少／视角更粗"：我能测的东西变少了。
- $f$ 可测 ⟶ "用 $f$ 去问目标空间的任何可测问题，拉回到源空间都是可测问题。"

## 降维表述

σ-代数是幂集 $\mathcal{P}(X)$（这是一个对有限并、有限交、补封闭的布尔代数）的一个**子集族**，它在补运算与可数并运算下封闭。换句话说：它是幂集这个布尔代数中，一个"连可数运算也扛得住"的子布尔代数。

从逻辑的角度重述：$\mathcal{P}(X)$ 中的元素可看作"关于点 $x\in X$ 的命题"，$\sigma$-代数中的元素就是那些我们**允许提问的命题**：补对应"非"，可数并对应"存在某个 $n$ 使第 $n$ 个命题成立"，可数交对应"对所有 $n$ 都成立"。σ-代数 = 一张被认可的提问清单，对"非"和"可数次的或／且"封闭。

## 升维视角

- **从拓扑看**：给定拓扑（或距离）空间 $X$，由一切开集生成的 σ-代数 $\mathcal{B}(X)$ 称为 Borel 代数，其元素称 Borel 集。这样，"$X$ 上的 σ-代数"这一概念把拓扑空间纳入了测度论的范畴。
- **从范畴看**：可测空间 $(X,\mathcal{A})$ 是对象，可测映射是态射；σ-代数的拉回 $f^*\mathcal{B}$ 正是态射在"结构"上的逆像操作。
- **从测度看**：σ-代数只是舞台，配上测度 $\mu:\mathcal{A}\to[0,\infty]$（$\mu(\varnothing)=0$ 且对两两不交的可数族可数可加）才成为测度空间 $(X,\mathcal{A},\mu)$。
- **从分离性看**：还可以要求 σ-代数是"可分的"（存在可分的子 σ-代数 $\mathcal{F}_0$，使每个 $A\in\mathcal{F}$ 都与某个 $B\in\mathcal{F}_0$ 相差一个零测集）；在 σ-有限测度下，这与诸 $L^p$ 空间的可分性等价。

## 如果改主题有与自身相似的对象，要联动理解

**σ-代数 ↔ 拓扑**（这是最值得对照的一对）

| | 拓扑 $\mathcal{T}$ | σ-代数 $\mathcal{A}$ |
|---|---|---|
| 并 | 任意并 | 只保证**可数**并 |
| 交 | 只保证**有限**交 | 可数交 |
| 补 | 不封闭 | 封闭 |
| 包含的极端情形 | $\{\varnothing,X\}$ 与 $\mathcal{P}(X)$ 都是拓扑 | $\{\varnothing,X\}$ 与 $\mathcal{P}(X)$ 都是 σ-代数 |

一句话：拓扑"上面对并大方、对交吝啬"，σ-代数"对并交一样（都可数）、而且补也管"。这解释了为什么 Borel 代数 $\mathcal{B}(X)=\sigma(\text{开集})$ 一般严格大于开集族。

**可测映射 ↔ 连续映射**：连续 = 开集的原像开；可测 = 可测集的原像可测。两者句式完全一样，只是把"开集"换成"可测集"。由此立刻得到：**连续映射必可测**。

**测度空间的完备化 ↔ 度量空间的完备化**：一个是往 σ-代数里"手动加入所有零测集的子集"，一个是往度量空间里"手动加入所有 Cauchy 列的极限"。操作的精神完全一致。

# 证明

## 概括证明

本篇几乎所有关于 σ-代数的证明，都逃不出下面三种套路，各一句话概括：

1. **逐条验证**：要证 $\mathcal{A}$ 是 σ-代数，就把三条性质一条条对着定义验一遍（交、拉回、限制、完备化都是这样证的）。
2. **取交得最小**：要造"包含 $\mathcal{M}$ 的最小 σ-代数"，就把所有包含 $\mathcal{M}$ 的 σ-代数交起来——前提是**任意交仍为 σ-代数**。
3. **优良集原理**（最有启发性的一条）：要证"某性质对所有 $A\in\sigma(\mathcal{M})$ 成立"，就去证明"满足该性质的集合的全体构成一个 σ-代数且包含 $\mathcal{M}$"，于是它必然包含 $\sigma(\mathcal{M})$。不要试图直接描述 $\sigma(\mathcal{M})$ 长什么样——通常描述不出来。

## 定理一：σ-代数的任意交仍是 σ-代数

**命题**：任意给定指标集 $J$，若对每个 $j\in J$，$\mathcal{A}_j$ 都是 $X$ 上的 σ-代数，则 $\mathcal{A}:=\bigcap_{j\in J}\mathcal{A}_j$ 也是 $X$ 上的 σ-代数。

**证明（套路 1）**：

1) 对每个 $j$ 有 $\varnothing\in\mathcal{A}_j$，故 $\varnothing\in\mathcal{A}$。
2) 若 $A\in\mathcal{A}$，则对每个 $j$ 有 $A\in\mathcal{A}_j$，从而 $A^c\in\mathcal{A}_j$，即 $A^c\in\bigcap_j\mathcal{A}_j=\mathcal{A}$。
3) 若 $A_1,A_2,\cdots\in\mathcal{A}$，则对每个 $j$ 有 $A_1,A_2,\cdots\in\mathcal{A}_j$，故 $\bigcup_{i=1}^{\infty}A_i\in\mathcal{A}_j$ 对所有 $j$ 成立，从而 $\bigcup_i A_i\in\mathcal{A}$。$\square$

**为什么重要**：注意这里 $J$ **可以是不可数的**，"任意交"没有可数性限制。这条性质是整个"生成"概念的地基。

推论（生成的 σ-代数）：给定 $\mathcal{M}\subset\mathcal{P}(X)$，令 $\Sigma=\{\mathcal{A}: \mathcal{A}\supset\mathcal{M},\ \mathcal{A}\ \text{为 σ-代数}\}$。它非空（因为 $\mathcal{P}(X)\in\Sigma$），于是 $\sigma(\mathcal{M}):=\bigcap_{\mathcal{A}\in\Sigma}\mathcal{A}$ 是包含 $\mathcal{M}$ 的**最小** σ-代数。

**推论（Borel 代数的存在唯一性）**：把 $\mathcal{M}$ 取为 $X$ 中一切开集，就得到 $\mathcal{B}(X)$。"最小"的精确含义是：任何包含所有开集的 σ-代数 $\mathcal{S}$ 都满足 $\mathcal{B}(X)\subset\mathcal{S}$。由于 σ-代数的交仍是 σ-代数，把 $\mathcal{B}(X)$ 定义为所有含开集的 σ-代数之交，其存在性与唯一性一并解决。

## 定理二：代数 + 单调类 ⇒ σ-代数

**命题**：若 $X$ 上的代数 $\mathcal{A}$ 同时是单调类，则 $\mathcal{A}$ 为 σ-代数。

**证明（关键在于"用有限逼近可数"）**：设 $A_1,A_2,\cdots\in\mathcal{A}$，要证 $\bigcup_{n\ge1}A_n\in\mathcal{A}$。令

$$S_n=\bigcup_{k\le n}A_k\in\mathcal{A}\quad(\text{代数对有限并封闭}).$$

则 $\{S_n\}_{n\ge1}$ 单调上升且 $\bigcup_{n\ge1}A_n=\bigcup_{n\ge1}S_n$。由 $\mathcal{A}$ 是单调类，后者的极限 $\bigcup_n S_n\in\mathcal{A}$，故 $\bigcup_n A_n\in\mathcal{A}$。$\square$

**注**：代数与 σ-代数的唯一区别，就在于可数并不一定封闭——而"单调类"恰好补上了从有限通往可数的那一步。

## 定理三：单调类定理 $m(\mathcal{A})=\sigma(\mathcal{A})$

**命题**：设 $\mathcal{A}$ 为 $X$ 上的代数，$\mathcal{M}$ 为 $\mathcal{A}$ 生成的单调类，则 $\mathcal{M}=\sigma(\mathcal{A})$。

**概括证明（套路 3，这是全篇最值得学的一个证明）**：

- 方向 "$\mathcal{M}\subset\sigma(\mathcal{A})$" 是平凡的：σ-代数是单调类，而 $\sigma(\mathcal{A})$ 是包含 $\mathcal{A}$ 的单调类，$\mathcal{M}$ 是**最小**的那个，故 $\mathcal{M}\subset\sigma(\mathcal{A})$。
- 方向 "$\sigma(\mathcal{A})\subset\mathcal{M}$" 不平凡。由定理二，只需证 $\mathcal{M}$ 是代数（那时 $\mathcal{M}$ 是 σ-代数，作为含 $\mathcal{A}$ 的 σ-代数，它必包含最小的那个 $\sigma(\mathcal{A})$）。

**细化（优良集原理的实际操作）**：对每个 $A\in\mathcal{P}(X)$ 定义"与 $A$ 相处融洽的集合"的集合

$$\Phi_{\mathcal{M}}(A):=\{B\in\mathcal{P}(X): A\cup B,\ A-B,\ B-A\in\mathcal{M}\}.$$

注意定义关于 $A,B$ 对称，故 $B\in\Phi_{\mathcal{M}}(A)\iff A\in\Phi_{\mathcal{M}}(B)$。

*第一步*：说明每个 $\Phi_{\mathcal{M}}(A)$ 是单调类。取 $\Phi_{\mathcal{M}}(A)$ 中单调上升列 $\{A_i\}$ 与单调下降列 $\{B_i\}$，逐条验证极限仍在其中，例如

$$A\cup\lim_{i\to\infty}A_i=A\cup\Big(\bigcup_{i\ge1}A_i\Big)=\bigcup_{i\ge1}(A\cup A_i),$$

而 $\{A\cup A_i\}_{i\ge1}$ 是 $\mathcal{M}$ 中的单调上升列，$\mathcal{M}$ 为单调类，故右端属于 $\mathcal{M}$；又如

$$A-\lim_{i\to\infty}A_i=A-\bigcup_{i\ge1}A_i=\bigcap_{i\ge1}(A-A_i),$$

而 $\{A-A_i\}_{i\ge1}$ 是 $\mathcal{M}$ 中的单调下降列，故其交仍在 $\mathcal{M}$ 中。

*第二步*：由对称性，若 $A\in\mathcal{A}$，则对任意 $B\in\mathcal{A}$ 有 $B\in\Phi_{\mathcal{M}}(A)$（因为 $\mathcal{A}$ 是代数且 $\mathcal{A}\subset\mathcal{M}$），即 $\mathcal{A}\subset\Phi_{\mathcal{M}}(A)$；而 $\Phi_{\mathcal{M}}(A)$ 是单调类且 $\mathcal{M}$ 是包含 $\mathcal{A}$ 的**最小**单调类，故 $\mathcal{M}\subset\Phi_{\mathcal{M}}(A)$。

*第三步*：再由对称性，$A\in\mathcal{A}$、$B\in\mathcal{M}$ 蕴含 $A\in\Phi_{\mathcal{M}}(B)$，即 $\mathcal{A}\subset\Phi_{\mathcal{M}}(B)$；重复第二步的论证得 $\mathcal{M}\subset\Phi_{\mathcal{M}}(B)$。于是对任意 $A,B\in\mathcal{M}$ 有 $A\cup B$、$A-B$、$B-A\in\mathcal{M}$，即 $\mathcal{M}$ 是代数。$\square$

**这个证明教给我们什么**：想直接"写出" $\sigma(\mathcal{A})$ 里的元素是不可能的（它要经过超限迭代）。绕开它的办法是——**不去描述对象，而去描述"具有该性质的对象的全体"**，并证明这个全体自身是个 σ-代数。

## 定理四：拉回与生成元判据

**引理**：设 $\mathcal{M}\subset\mathcal{P}(Y)$，$\mathcal{B}=\sigma(\mathcal{M})$，$f:X\to Y$。则

$$f^*(\sigma(\mathcal{M}))=\sigma(f^*(\mathcal{M})),$$

即：**拉回生成元，就生成了拉回的 σ-代数**。

**证明（套路 3）**：

- "$\supset$"：$\mathcal{M}\subset\sigma(\mathcal{M})$，故 $f^*\mathcal{M}\subset f^*(\sigma(\mathcal{M}))$，后者是 σ-代数，故 $\sigma(f^*\mathcal{M})\subset f^*(\sigma(\mathcal{M}))$。
- "$\subset$"：令 $\mathcal{B}'=\{B\subset Y: f^{-1}(B)\in\sigma(f^{-1}(\mathcal{M}))\}$。显然 $\mathcal{M}\subset\mathcal{B}'$。又因对任意可数个 $B_i$ 有 $f^{-1}\big(\bigcup_i B_i\big)=\bigcup_i f^{-1}(B_i)$（原像与并可交换），可知 $\mathcal{B}'$ 是 σ-代数，故 $\sigma(\mathcal{M})\subset\mathcal{B}'$，进而 $f^*(\sigma(\mathcal{M}))\subset\sigma(f^*(\mathcal{M}))$。$\square$

**推论（可测性的生成元判据）**：给定可测空间 $(X,\mathcal{A})$、$(Y,\mathcal{B})$，且 $\mathcal{B}=\sigma(\mathcal{M})$。则 $f:X\to Y$ 可测 $\iff f^*(\mathcal{M})\subset\mathcal{A}$。

**推论（最常用的特例）**：若 $Y$ 上配备 Borel 代数，则 $f$ 可测 $\iff$ 对每个开集 $U\subset Y$ 有 $f^{-1}(U)\in\mathcal{A}$。特别地，**拓扑（度量）空间之间的连续映射一定是可测映射**。

**注**：原像之所以好使，是因为它与并、交、补都能交换（$f^{-1}(B^c)=(f^{-1}(B))^c$，$f^{-1}(\bigcup B_i)=\bigcup f^{-1}(B_i)$），而像 $f(B)$ 做不到——这正是"拉回"而不是"推出"成为基本操作的原因。

# 应用

## 直接应用

### 例 1：把 $\sigma\{A,B\}$ 具体写出来（"最小 σ-代数"长什么样）

设 $A,B\subset\Omega$，且 $A\neq B$、$A\cap B\neq\varnothing$，则

$$\sigma\{A,B\}=\{\varnothing,\Omega,A,B,A^c,B^c,A\cap B,A\cap B^c,A^c\cap B,A^c\cap B^c,A\cup B,A\cup B^c,A^c\cup B,A^c\cup B^c\}.$$

思路：从 $A,B$ 出发，反复取补、交、并，直到族封闭为止。这个例子说明：由两个集合生成的 σ-代数最多只有 14 个元素——**因为 $A,B$ 把 $\Omega$ 切成至多 4 块"原子"，σ-代数的元素就是这些原子的任意并（$2^4=16$，去掉因退化而重复的情形即为上述列表）**。

### 例 2：由"含 $A$ 的所有集合"生成的 σ-代数

设 $A\subset\Omega$，$\mathcal{E}=\{B\subset\Omega: B\supset A\}$，则

$$\sigma(\mathcal{E})=\mathcal{F}:=\{B\subset\Omega: B\supset A\ \text{或者}\ B\subset A^c\}.$$

验证要点（套路 1）：$\Omega\in\mathcal{F}$ 显然；对补封闭要分两种情形——若 $B\supset A$ 则 $B^c\subset A^c$，若 $B\subset A^c$ 则 $B^c\supset A$，两种情形都回到 $\mathcal{F}$；可列并封闭同理按"是否含 $A$"分类讨论。再说明任何含 $\mathcal{E}$ 的 σ-代数必含 $\mathcal{F}$，即得最小性。

### 例 3：$\mathcal{B}(\mathbb{R})$ 可以由可数多个集合生成（"新工具如何简化旧痛苦"）

定义 $\mathcal{B}(\mathbb{R})$ 时，要的是"包含**所有**开集的最小 σ-代数"，而开集有不可数多个。事实上可以少得多：

$$\mathcal{B}(\mathbb{R}^1)=\sigma\big(\{(-\infty,a): a\in\mathbb{Q}\}\big).$$

**证明思路**：$\mathbb{R}$ 上任一开集 $U$ 可写成可数个两两不交开区间之并 $U=\bigcup_{k=1}^{\infty}(a_k,b_k)$（端点允许为 $\pm\infty$），故 $\mathcal{B}(\mathbb{R}^1)$ 可由所有开区间生成；令 $\mathcal{A}=\sigma(\{(-\infty,a):a\in\mathbb{R}\})$，由于 σ-代数在可数并、可数交、取补下封闭，对任意 $a<b$ 有

$$[a,b)=(-\infty,b)\cap\big(\mathbb{R}\setminus(-\infty,a)\big)\in\mathcal{A},$$

进而可由这些半开区间拼出所有开区间。最后把端点 $a$ 限制到 $\mathbb{Q}$ 上（利用有理数的稠密性），即得结论。

同理，$\mathcal{B}(0,\infty)$ 可以由下面任一族生成：

$$\{(0,b):b>0\},\qquad\{(a,\infty):a>0\},\qquad\{[a,\infty):a>0\}.$$

**这个例子"简化了什么旧痛苦"**：本来要验证"某个性质对所有开集成立"，现在只需对一列射线验证——配合生成元判据，验证量从不可数降到可数。

### 例 4：生成元判据的直接收益——连续函数自动可测

由推论，若 $X,Y$ 是度量空间（均配备 Borel 代数），$f:X\to Y$ 连续，则 $f$ 可测。于是我们在**一瞬间**获得了一大类可测映射：所有连续映射。而连续性通常比可测性容易验证得多。

## 间接应用

- **可测映射的复合仍可测**：若 $f:(X,\mathcal{A})\to(Y,\mathcal{B})$、$g:(Y,\mathcal{B})\to(Z,\mathcal{C})$ 可测，则对 $C\in\mathcal{C}$ 有 $g^{-1}(C)\in\mathcal{B}$，从而 $f^{-1}(g^{-1}(C))\in\mathcal{A}$，即 $(g\circ f)^{-1}(C)\in\mathcal{A}$。这条性质使"可测空间与可测映射"构成一个范畴。
- **可测函数类的优越性**：可测函数与可测集的关系，如同连续函数与开（闭）集的关系；但它有一个关键优越性——**可测函数类在逐点极限下封闭**。这才是 Lebesgue 理论能做极限运算的根本原因。
- **Borel 层级的实际产出**：从最简单的开集、闭集出发，按复杂性递增可以排列 Borel 集：开集的可数交称 $G_\delta$ 集，闭集的可数并称 $F_\sigma$ 集，可数个 $F_\sigma$ 集之交称 $F_{\sigma\delta}$ 集（例如 $F_n=[1/n,1]$ 之并 $(0,1]$ 是不闭的 $F_\sigma$ 集，而 $G_n=(-1/n,1/n)$ 之交 $\{0\}$ 是不开的 $G_\delta$ 集）。这套层级能给出很精致的结论，例如：**$\mathbb{R}^1$ 上连续函数 $f$ 的可微点集是一个 $F_{\sigma\delta}$ 集**（证明思路是说明不可微点集是可列个 $G_{\delta}$ 集之并，引用上、下导数即可）。
- **测度的构造**：Carathéodory 扩张定理告诉我们，只要在一个**代数**上给出 σ-有限的加性函数，就能唯一地扩张成 $\sigma(\mathcal{A})$ 上的测度。σ-代数在这里扮演的角色是"扩张的终点"：它是能让可数可加性说得通的最小舞台。
- **Lebesgue 测度的刻画**：在 $(\mathbb{R}^n,\mathcal{B}(\mathbb{R}^n))$ 上存在唯一测度 $m$，使方块的测度等于其体积；且平移不变性在"单位方块测度为 1"的规范化下**唯一刻画**了 Lebesgue 测度。

# 推广

**条件可以放宽（先在小结构上干活，再扩张）**：不必一上来就在 σ-代数上定义测度。可以在半环、环、代数上先定义加性函数，再用 Carathéodory 扩张定理把它扩张到生成的 σ-代数上；σ-有限性保证扩张唯一。

**结论可以泛化（σ-代数的几种"搬运"方式）**：

1. **子 σ-代数**：$\mathcal{A}'\subset\mathcal{A}$ 且自身是 σ-代数。直观含义是"信息减少／观测变粗"。
2. **拉回**：$f:X\to Y$，$f^*\mathcal{B}=\{f^{-1}(B): B\in\mathcal{B}\}$ 是 $X$ 上的 σ-代数。性质：若 $\mathcal{B}'\subset\mathcal{B}$ 为子代数，则 $f^*(\mathcal{B}')$ 也是 $f^*(\mathcal{B})$ 的子代数；且 $(f\circ g)^*=g^*\circ f^*$（函子性）。
3. **限制**：若 $Y'\subset Y$，则 $\mathcal{B}|_{Y'}=\{B\cap Y': B\in\mathcal{B}\}$ 是 $Y'$ 上的 σ-代数（它就是包含映射 $\iota:Y'\hookrightarrow Y$ 的拉回 $\iota^*\mathcal{B}$）。特例：对 $X\subset\mathbb{R}^n$，定义 $\mathcal{B}(X)=\iota^*\mathcal{B}(\mathbb{R}^n)=\{B\cap X: B\in\mathcal{B}(\mathbb{R}^n)\}$。
4. **乘积（张量积）**：两个可测空间 $(X_1,\mathcal{A}_1)$、$(X_2,\mathcal{A}_2)$ 给出 $X_1\times X_2$ 上的 $\mathcal{A}_1\otimes\mathcal{A}_2$，由所有矩形 $A_1\times A_2$ 生成。乘积情形的一个核心结论是 $\mathcal{B}(\mathbb{R}^2)\supset\mathcal{B}(\mathbb{R})\otimes\mathcal{B}(\mathbb{R})$；更一般地，若 $X_1,X_2$ 是**可分**距离空间，则乘积空间上的 Borel 代数恰好等于 Borel 代数之张量积：$\mathcal{B}_{X}=\mathcal{B}_{X_1}\otimes\mathcal{B}_{X_2}$。（这也是 Fubini 定理得以成立的前提。）
5. **完备化**：给定测度空间 $(X,\mathcal{A},\mu)$，令

$$\mathcal{A}'=\{A'\subset X:\ \exists\,B,C\in\mathcal{A},\ B\subset A'\subset C,\ \mu(C-B)=0\},$$

则 $\mathcal{A}'$ 仍是 σ-代数，$\mu'(A'):=\mu(B)$ 良定义且为测度，$(X,\mathcal{A}',\mu')$ 是完备的（零测集的子集都在族里），并且是**最小**的完备化。从 Borel 集的观点看，Lebesgue 可测集正是 $\mathcal{B}(\mathbb{R}^d)$ 的完备化——即附加上"测度为零的 Borel 集的子集"。
6. **可分 σ-代数**：可以要求 σ-代数是可分的（存在可分子 σ-代数，使每个集合与之相差零测集）。在 σ-有限测度下，这一性质等价于诸 $L^p$ 空间可分的 Banach 空间——把"集类的可数性"与"函数空间的可分性"直接挂钩。

**值得继续追的问题**（学习清单，不做断言）：

- $\mathcal{B}(\mathbb{R}^d)$ 与 Lebesgue 可测集族之间差了什么？（答案与完备化有关。）
- 生成元判据还能走多远？例如：验证一个函数族的可测性时，能把生成元缩到多小？
- 单调递增的 σ-代数序列之并不是 σ-代数（见上文反例）；那么什么样的条件能保证它是？
- 不可数并一律禁止；那么有哪些"部分不可数操作"在某些附加结构（如完备测度、紧性）下可以被救回来？

# 常见的误解

1. **"可测集的子集仍然可测。"**
   错。反例：$\Omega=\{1,2,3\}$，$\mathcal{F}=\{\varnothing,\{1\},\{2,3\},\Omega\}$ 是 σ-代数，但 $A=\{2,3\}\in\mathcal{F}$ 的子集 $B=\{2\}\notin\mathcal{F}$。
   *忽略了什么条件*：定义只要求对补、可数并封闭，从未要求对"取子集"封闭。只有当测度空间**完备**（或该子集恰是零测集的子集）时，这件事才成立。

2. **"两个 σ-代数的并还是 σ-代数。"**
   错。反例：$\Omega=\{1,2,3\}$，$\mathcal{A}_1=\{\varnothing,\{1\},\{2,3\},\Omega\}$，$\mathcal{A}_2=\{\varnothing,\{2\},\{1,3\},\Omega\}$ 都是 σ-代数，但
   $$\mathcal{A}_1\cup\mathcal{A}_2=\{\varnothing,\{1\},\{2\},\{1,3\},\{2,3\},\Omega\}$$
   连**代数**都不是：$\{1\}\cup\{2\}=\{1,2\}\notin\mathcal{A}_1\cup\mathcal{A}_2$。
   *忽略了什么条件*：并运算不保证封闭性。要扩张一个族，正确的做法是取 $\sigma(\mathcal{A}_1\cup\mathcal{A}_2)$，而不是取并集。

3. **"一列递增的 σ-代数的并还是 σ-代数。"**
   错。反例：$\Omega=\mathbb{R}$，$I_k=[k-1,k)$，$\mathcal{A}_n=\sigma\{I_k:1\le k\le n\}$。每个 $[0,n)\in\mathcal{A}_n$，但 $\bigcup_{n\ge1}[0,n)=[0,\infty)$ 不属于任何一个 $\mathcal{A}_n$。
   *忽略了什么条件*：即使"嵌套"也不够——可数并需要**一次性**完成，而递增并只允许"在某一层内"操作。

4. **"既然对可数并封闭，那对不可数并差不多也封闭吧。"**
   绝对不能。处理可测集时，**不可数并或者交的运算是不允许的**。理由见"必要条件分析"：若允许不可数并，则任意集合都是可数个（甚至不可数个）单点之并，全部可测且测度为零，测度论立刻自毁。

5. **"单调类就是 σ-代数。"**
   不对。σ-代数一定是单调类，但反之需要"它同时也是代数"这个前提（σ-代数 = 代数 + 单调类）。单调类只管单调极限，不管任意两个元素的并与差。

6. **"有限集上的代数和 σ-代数当然是两回事。"**
   恰好相反：若 $\Omega$ 有限，则 $\Omega$ 上任何代数都是 σ-代数。区别只在无限集上出现。

7. **"Borel 集就是由开集经过有限次（或可数次）运算得到的集合。"**
   不完整。从开集、闭集出发，可以按复杂性分层排下去：$G_\delta$（开集的可数交）、$F_\sigma$（闭集的可数并）、$F_{\sigma\delta}$（可数个 $F_\sigma$ 之交）……这个层级并不会在可数步内终止。$\mathcal{B}(X)$ 是"包含开集的最小 σ-代数"，是一个**自上而下（取所有 σ-代数之交）**的定义，而不是"自下而上逐层构造到某一层"的定义。

8. **"把 σ-代数当成拓扑来用。"**
   见"联动理解"一节的对照表：拓扑对**任意**并封闭但只对**有限**交封闭，且不要求对补封闭；σ-代数对可数并、可数交、补都封闭但**不能**做不可数并。两者都包含 $\{\varnothing,X\}$ 与 $\mathcal{P}(X)$ 这两个极端，但中间地带差别很大。

# 启发

- **"退让"是一种创造力。** 我们想给所有集合量体积，被 Vitali 构造挡了回来；于是退一步——不量"所有集合"，只量"一族对可数运算封闭的集合"。结果不但没损失什么（遇到的集合几乎都可测），反而得到了能取极限的强大理论。**当一条路被证明走不通时，先问"我愿意放弃哪个要求"，而不是"我该怎么硬闯"。**
- **"最小"这个词，要靠"任意交"来落地。** 想要"包含 $\mathcal{M}$ 的最小 σ-代数"，最省事的定义不是去描述它内部长什么样（通常描述不出来），而是把所有候选者交起来。这个套路在数学里反复出现（生成的子群、生成的拓扑、闭包、凸包……）。**定义"最小的某某"时，先问："某某的任意交还是某某吗？"**
- **不要试图描述对象，去描述"具有该性质的对象的全体"。** 单调类定理的证明（$\Phi_{\mathcal{M}}(A)$ 那段）是这一点的最佳示范：与其把 $\sigma(\mathcal{A})$ 的元素一个个写出来，不如证明"好集合的全体"本身是个 σ-代数。这是从"枚举"思维跳到"结构"思维的一瞬间。
- **"可数"是一道精心选择的门槛。** 有限并太少（撑不住极限），不可数并太多（会把整个幂集放进来），可数并刚好。数学里这种"卡在中间最合适"的选择，几乎总是深层原因造成的，值得停下来想清楚。

# 总结

## 思想

**用"放弃全体子集"换取"可数可加"**：σ-代数是这样一个妥协——它小到能避开不可测集的悖论，又大到对补、可数并、可数交封闭，足以承载极限运算。

**把无限（可数）拆成有限 + 极限**：σ-代数 = 代数 + 单调类 = π 类 + λ 类。凡是要验证"σ 级"的性质，先想办法拆成"有限级"和"极限级"两步。

## 方法

| 技术 | 在本文何处使用 |
|---|---|
| 逐条验证定义 | 定理一（σ-代数的交）、例 2、拉回与限制的验证 |
| 取交得最小对象 | 生成 σ-代数 $\sigma(\mathcal{M})$、Borel 代数的存在唯一性 |
| 优良集原理（证明"好集合的全体"是 σ-代数） | 定理三（单调类定理）、定理四（拉回与生成元判据） |
| 用补做对偶（De Morgan） | 由可数并封闭推出可数交封闭；上升与下降的互相转换 |
| 有限逼近可数（$S_n=\bigcup_{k\le n}A_k$） | 定理二（代数 + 单调类 ⇒ σ-代数） |
| 只验生成元（生成元判据） | 例 3、例 4（连续 ⇒ 可测） |
| 原像可交换（$f^{-1}$ 与并、交、补） | 定理四及拉回的函子性 |
| 刻意构造反例 | "必要条件分析"与"常见的误解"两节 |

# 回看并提问

1. 三条公理并不独立（"含空集"可由另两条推出，只要族非空）。那么这条公理存在的意义究竟是什么？如果把它删掉、只要求"族非空"，定义会变吗？
2. 为什么 σ-代数要求对**补**封闭，而拓扑不要求？如果 σ-代数也不要求对补封闭（只要求可数并、可数交），会得到什么结构？它还能承载测度吗？
3. 单调类定理中，$\Phi_{\mathcal{M}}(A)$ 这个"优良集"为什么要同时装 $A\cup B$、$A-B$、$B-A$ 三样？少装一样会断在哪一步？
4. 生成的 σ-代数 $\sigma(\mathcal{M})$ 一般无法逐元素描述。那么"我能判断某个具体集合是否属于 $\sigma(\mathcal{M})$"这件事，通常靠什么手段完成？
5. 拉回 $f^*$ 与测度的推出 $f_*\mu$ 方向相反。为什么"拉回"在 σ-代数层面总是可行，而"像"却困难重重？
6. 完备化（加入零测集的子集）之后得到的仍是 σ-代数。这个操作与"度量空间完备化"的相似是巧合，还是同一个范畴论构造的两种表现？
7. 既然 $\mathcal{B}(\mathbb{R})$ 可由可数个集合生成，能否说"Borel 集只有可数多个"？如果不能，断点在哪里？
8. 如果把"可数并"换成"任意并"，σ-代数就退化成什么？这个退化如何反过来解释"σ"这个字母的必要性？
