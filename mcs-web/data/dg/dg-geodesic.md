# 测地线

> 弯曲空间里"直线"应该是什么？测地线给出了三种看起来毫不相干、却彼此等价的回答：**最直的线**（测地曲率为零，切矢沿自身平行）、**最短的线**（弧长在固定端点变分下取临界值）、**不受侧向力的自由运动轨迹**（加速度只有法向分量）。测地线把"内蕴几何"真正立了起来：它只依赖第一基本形式（度量），与曲面怎么嵌在空间里无关。它是 Gauss-Bonnet、Hopf-Rinow、Jacobi 方程、广义相对论中自由粒子运动的共同底座。

# 前置知识

## 必备知识

- **曲线的曲率与主法向量**：空间曲线 $r(s)$（$s$ 为弧长）的曲率向量 $d^2r/ds^2$ 指向主法向量方向；密切平面由切向量与主法向量张成。
- **曲面的第一基本形式** $\mathrm{I}=g_{\alpha\beta}\,du^\alpha du^\beta$：它决定曲面上曲线的弧长与夹角，是内蕴量的全部来源。
- **曲面的法向量与法曲率**：曲面 $S$ 上一条曲线 $C$ 的曲率 $\kappa$ 与测地曲率 $\kappa_g$ 满足 $\kappa_g=\kappa\cos\theta$，其中 $\theta$ 是曲线的次法向量与曲面法向量的夹角。
- **协变导数 / 联络 $\nabla$ 与克氏符 $\Gamma^\mu_{\nu\sigma}$**：向量场沿曲线的"沿自身不变"靠平行移动来定义；$\nabla$ 与度量适配时平行移动保持内积。
- **常微分方程组的初值问题**：二阶方程组在给定位置与初速度后解局部存在唯一，且解对初值连续（光滑）依赖。

## 辅助知识

- **弧长泛函与变分的语言**：$l=\int_{t_1}^{t_2}\big(g_{\mu\nu}\dot x^\mu\dot x^\nu\big)^{1/2}dt$，长度不是"函数"而是"泛函"，临界条件是变分 $\delta l=0$。
- **曲面的外在几何与内蕴几何之分**：法曲率、测地挠率、渐近曲线、曲率线都不是内蕴的；测地曲率在保长变形下不变，是内蕴量。
- **旋转曲面的坐标**：$r=(u\cos v,\ u\sin v,\ f(u))$，第一基本形式 $\mathrm{I}=(1+f'(u)^2)(du)^2+u^2(dv)^2$，$(u,v)$ 是正交参数系。

## 拓展知识

- **平行移动**：曲面上沿曲线保持切向、且"压回曲面"意义下不变的向量场；它是构造测地线的另一条路。
- **抽象曲面（二维黎曼流形）与 $n$ 维黎曼流形**：把第一基本形式换成度量 $g$，把测地曲率换成协变导数。
- **高斯曲率与角盈**：测地三角形的内角和偏离 $\pi$ 的程度，由 $\iint K\,d\sigma$ 控制。

# 动机

## 引入动机

**路径一：学科内部——内蕴几何需要"直线"。**
1827 年 Gauss 提出的内蕴观点，把几何交给了"生活在曲面上、只能理解二维世界的智慧生物"。这些生物能做的第一件事，就是把连接两个邻近点的**最短路径**定义为"直线"，然后才能谈三角形、圆、角盈。没有测地线，"内蕴几何"就没有砖块。

**路径二：外部应用——"最短路"是真实需求。**
在球面上，两点间的大圆短弧才是导航要走的路线；在一般曲面上，拉紧一根细绳，张力自然保证路径尽可能短。细绳贴着曲面绷紧的轨迹，就是测地线——这是最朴素也最可靠的构造法。

**路径三：物理——自由运动的轨迹。**
设想质点在曲面 $S$ 上运动，只受把它约束在曲面上的力，不受任何其他外力。由 Newton 第二定律，约束力沿曲面法向，于是加速度也沿法向，速率恒定，而加速度恰好指向轨迹的主法线方向——轨迹的主法向量就是曲面法向量。也就是说：**完全自由的质点，自动沿测地线走**。反过来，测地线可以理解为"不受侧向力的运动"。

**路径四：审美与结构——"直"比"短"更本质。**
长度最小化是个容易出错的性质：球面上连接两个非对径点的大圆有两段弧，短弧最短，长弧也是测地线；对径点之间则有无数条测地线。于是人们转而用"直性"来刻画：**测地曲率为零**。雅各布·伯努利在 1697 年就发现了它的等价说法——测地线在每一点处的密切平面包含曲面的法向量。

## 构造动机

**胚子（古典曲面论，外在刻画）**
约翰·伯努利（1697）传给欧拉的观察：把测地线想象成无摩擦地绷紧在曲面上的吉他弦。弦已收缩到最短，若回复力还有切向分量，弦就会继续滑动缩短——矛盾。所以回复力只能沿法向，密切平面必含曲面法向量，测地曲率为零。翻译成定理：**曲面上的曲线是测地线，当且仅当它是一条直线，或者它的主法向量处处是曲面法向量**。

**中间形态（内蕴化 + 方程化）**
- Gauss 的内蕴观点确立后，人们注意到测地线方程 $\dfrac{d^2u^\alpha}{ds^2}+\Gamma^\alpha_{\beta\gamma}\dfrac{du^\beta}{ds}\dfrac{du^\gamma}{ds}=0\ (\alpha=1,2)$ **只涉及第一基本形式**，与第二基本形式无关，因此测地线属于内蕴几何。
- 变分观点成熟：弧长的第一变分公式把"最短"与"测地曲率为零"焊在一起。
- 守恒量出现：旋转面上的克莱罗定理给出首次积分 $p\sin\psi=$ 常数，把二阶方程降到一阶。

**现代规范形式（流形 / 联络）**
黎曼 1854 年把 Gauss 的曲面内蕴几何一举推广到 $n$ 维；联络的语言使定义收缩成一行：$(M,\nabla_a)$ 上的曲线 $\gamma(t)$ 称为**测地线**，若其切矢满足

$$T^b\nabla_bT^a=0 .$$

有度规时取与 $g_{ab}$ 适配的联络（Levi-Civita 联络）。这行式子同时是方程、是几何、也是物理。

# 形式

## 规范的通用形式

**形式 A（流形/联络，最通用）**
设 $(M,\nabla_a)$ 带仿射联络，曲线 $\gamma(t)$ 的切矢 $T^a$。$\gamma$ 是测地线 $\Leftrightarrow\ T^b\nabla_bT^a=0$。等价说法：**切矢沿曲线自身平行**。

**形式 B（局部坐标，最可算）**
若 $\gamma$ 落在坐标域内，$x^\mu=x^\mu(t)$ 为参数式，则

$$\frac{d^2x^\mu}{dt^2}+\Gamma^\mu_{\nu\sigma}\frac{dx^\nu}{dt}\frac{dx^\sigma}{dt}=0,\qquad \mu=1,\dots,n .$$

这是 $n$ 个二阶常微分方程，**一般不是线性的**；给定 $(p,v)$ 后解局部存在唯一。

**形式 C（曲面坐标，最直观）**
正交参数系 $(u,v)$ 下，用测地曲率的 Liouville 公式可写成一阶系统：

$$\frac{du}{ds}=\frac{1}{\sqrt E}\cos\theta,\quad \frac{dv}{ds}=\frac{1}{\sqrt G}\sin\theta,\quad \frac{d\theta}{ds}=-\frac{1}{2\sqrt G}\frac{\partial\log E}{\partial v}\cos\theta+\frac{1}{2\sqrt E}\frac{\partial\log G}{\partial u}\sin\theta .$$

**形式 D（抽象曲面）**
单位切向量沿曲线自身平行，即协变导数沿曲线为零。

**优劣对比**

| 形式 | 优点 | 缺点 |
|---|---|---|
| A（$T^b\nabla_bT^a=0$） |  coordinate-free，一眼看出"平行"本质；适用于伪黎曼 | 不能直接算 |
| B（坐标方程） | 可直接数值/解析求解，ODE 理论直接可用 | 依赖坐标，形式笨重 |
| C（Liouville 系统） | 降为一阶，便于找首次积分（如克莱罗定理） | 依赖正交参数系，仅限二维 |
| D（抽象曲面） | 凸显内蕴性，可直接搬到抽象曲面 | 需要先建立协变微分算子 |

## 必要条件分析

**针对"切矢沿自身平行"（$T^b\nabla_bT^a=0$）**

- **删掉"平行" $\to$ 允许 $\alpha T^a$**：若只要求 $T^b\nabla_bT^a=\alpha T^a$（$\alpha$ 为线上函数），曲线的**像**仍是同一条几何曲线，但该参数已不是仿射参数；严格地说这应称为"非仿射参数化的测地线"。$\alpha\neq0$ 时它连测地线的定义都不满足。
- **重参数化的自由度**：若 $t$ 是仿射参数，则 $t'$ 也是仿射参数 $\Leftrightarrow\ t'=at+b$（$a\neq0$）。任意非线性重参数化都会引入 $\alpha=-\left(\dfrac{dt}{dt'}\right)^2\dfrac{d^2t'}{dt^2}\neq0$，把测地线方程破坏掉。这就是为什么"测地线"是**带参数**的对象，而不只是点的集合。
- **删掉"与度量适配"**：平行移动不再保内积，切矢长度会沿线变化，"弧长参数"与"仿射参数"的一致性（线长参数必为仿射参数）随之失效。

**针对"弧长取临界值"**

- **删掉"固定端点"**：第一变分公式中边界项 $g_{\alpha\beta}v^\alpha\dfrac{du^\beta}{ds}\Big|_a^b$ 不再消失，"临界"无法推出测地曲率为零。端点一松，临界曲线就变成与边界正交的另一族曲线。
- **正定度规换成洛伦兹度规**：结论从"最短"退化为"线长取极值"，而且**类时测地线未必是最长线**（闵氏时空是例外，一定最长）；两点间甚至可能不存在最短类时线。

**针对"完备流形上两点可由最短测地线连接"（Hopf-Rinow）**

- **删掉完备性**：在 $\mathbb{R}^2\setminus\{(0,0)\}$ 上取欧氏度量，从 $p=(-1,0)$ 沿方向 $V=(1,0)$ 出发的测地线会撞上被挖去的原点而"终止"；一般地，$\mathbb{R}^n$ 的任意真开子集带欧氏（或伪欧氏）度量时，都有测地线在有限时间内抵达边界。
- **去掉顶点的单叶锥面** $z=\sqrt{x^2+y^2}$：它不可延拓，却不完备，因为母线不能沿弧长无限延伸而不碰到顶点。可见"完备"严格强于"不可延拓"，严格弱于"紧致"。

## 等价表达

以下五条互相等价（在相应语境下）：

1. **测地曲率为零**：$\kappa_g\equiv0$（曲面）。
2. **切矢沿自身平行**：$T^b\nabla_bT^a=0$（流形）。
3. **外在刻画**：曲线是直线，或其主法向量处处是曲面法向量；等价地，密切平面处处包含曲面法向量。
4. **变分刻画**：弧长在任意有固定端点的变分下取临界值；更一般地，类空/类时曲线为测地线 $\Leftrightarrow$ 线长取极值（正定度规时去掉"类空/类时"）。
5. **动力学刻画**：只受约束力（无侧向外力）的质点轨迹。

**1 $\Leftrightarrow$ 3 的简证**：$\kappa_g=\kappa\cos\theta$，其中 $\theta$ 是次法向量与曲面法向量的夹角。$\kappa_g=0$ 要求每点处 $\kappa=0$（曲线是直线）或 $\cos\theta=0$。若某点 $\kappa\neq0$，则由连续性该点邻域内 $\kappa\neq0$，故 $\cos\theta\equiv0$，$\theta=\pi/2$，即次法向量与曲面法向量垂直 $\Rightarrow$ 主法向量平行于曲面法向量。反之显然。

## 形式的类别

- **按参数**：以弧长（仿射）参数化的测地线；非仿射参数化的测地线（$T^b\nabla_bT^a=\alpha T^a$）。
- **按几何性质**：最短测地线（实现两点间距离）；局部最短测地线；一般的测地线（只是临界点）。
- **按延拓性**：可无限延拓的测地线；极大测地线；测地完备流形上的测地线。
- **按度规定号**：黎曼（正定）情形的测地线；洛伦兹情形下的**类时、类空、类光**三类测地线——因 $g_{ab}T^aT^b$ 沿测地线为常数，故不变号，不存在"不伦不类"的测地线。
- **按所在空间**：曲面上的测地线；抽象曲面上的测地线；$n$ 维（伪）黎曼流形上的测地线。

## 降维表述

- **降到 ODE 初值问题**：测地线 $\equiv$ 由 $(p,v)\in TM$ 唯一确定的二阶常微分方程组的解曲线。整个理论的存在性、唯一性、光滑性全部来自常微分方程组的初值理论。
- **降到流的一阶系统**：把 $(x^\mu,\dot x^\mu)$ 看成切丛上的点，二阶方程 $(*)$ 就是切丛上的一个一阶自治系统，"从 $p$ 以速度 $v$ 出发"即给定切丛中一个点。
- **降到向量空间的直线**：欧氏空间取笛卡儿坐标时 $\Gamma^\mu_{\nu\sigma}=0$，方程退化为 $\ddot x^\mu=0$，通解 $x^\mu(t)=a^\mu t+b^\mu$——测地线即直线段。**测地线就是"直线"这一概念在弯曲空间中的推广**。

## 升维视角

- **二维 $\to$ $n$ 维**：Gauss 的曲面内蕴几何由黎曼（1854）推广为 $n$ 维黎曼空间；曲面上的测地线方程与 $n$ 维的测地线方程形式完全一致。
- **局部 $\to$ 大范围**：引入测地完备与 Hopf-Rinow 定理后，测地线从"局部存在唯一"升级为"全局连接任意两点"，成为大范围黎曼几何的入口；Killing–Hopf 定理（完备、单连通、常截面曲率 $\Rightarrow$ 等距于 $\mathbb{R}^n$、$S^n(R)$ 或 $H^n(R)$）也建立在其上。
- **单条 $\to$ 一族**：测地线的变分给出 **Jacobi 场**；测地线的二阶变分把曲率顶到台前：
  $$\frac{d^2}{ds^2}L_g(s)\Big|_{s=0}=\int_a^b\Big(|D_tV^\perp|^2-\mathrm{Rm}(V^\perp,\dot\gamma,\dot\gamma,V^\perp)\Big)dt .$$
  在球面上它收缩成雅可比方程 $\ddot J=-KJ$，即"曲率是相邻测地线之间的作用力"。
- **正定 $\to$ 伪黎曼**：把度规换成洛伦兹的，测地线变成时空中的自由粒子世界线，长度极值变成"最长"（类时）；广义相对论中引力被理解为时空内蕴几何的曲率。

# 证明

## 概括证明

**一句话总览**：所有核心结论都由同一个动作推动——**把"沿曲线求导"拆成"内蕴部分 + 外在（法向）部分"，然后逼迫其中一部分为零**。

- 外在刻画：加速度全在法向 $\Rightarrow$ 切向（测地）曲率为零。
- 变分刻画：把弧长对变分参数求导，分部积分把导数从变分场转移到曲线上，剩下"测地曲率 $\times$ 变分场"的积分；变分场任意 $\Rightarrow$ 测地曲率必须为零。
- 存在唯一：方程是二阶 ODE，初值 $(p,v)$ 定解。

## 证明一：外在刻画（定理：测地线 $\Leftrightarrow$ 直线或主法向量处处为曲面法向量）

由 $\kappa_g=\kappa\cos\theta$，$\theta$ 为次法向量与曲面法向量夹角。

$(\Rightarrow)$ 若 $C$ 是测地线，$\kappa_g\equiv0$，则每点处 $\kappa=0$ 或 $\cos\theta=0$。若处处 $\kappa=0$，$C$ 是直线。若某点 $p$ 处 $\kappa(p)\neq0$，由 $\kappa$ 的连续性，在 $p$ 的某邻域内 $\kappa\neq0$，故该邻域内 $\cos\theta\equiv0$，即 $\theta=\pi/2$：次法向量垂直于曲面法向量，于是主法向量平行于曲面法向量。由覆盖性与连续性，整条曲线如此。

$(\Leftarrow)$ 反过来显然：主法向量是曲面法向量时 $\cos\theta=0$，故 $\kappa_g=0$。$\blacksquare$

**推论（旋转面的经线）**：旋转面 $S$ 的经线是过旋转轴的平面与 $S$ 的交线，它是母线；作为平面曲线，经线的法线就是它的主法线且必过旋转轴，因而也与平行圆垂直。故经线的主法线同时是曲面法线，经线是测地线。特别地，**球面上的大圆周都是测地线**。

## 证明二：约束质点走测地线（动力学刻画）

设质点运动方程 $r=r(t)$，它只受把它约束在 $S$ 上的力 $F$，故 $F$ 沿曲面法向。Newton 第二定律：

$$F=m\frac{d^2r(t)}{dt^2}\ \Rightarrow\ \frac{d^2r(t)}{dt^2}\cdot\frac{dr(t)}{dt}=\frac1m F\cdot\frac{dr(t)}{dt}=0 ,$$

于是 $\frac{d}{dt}\left|\frac{dr}{dt}\right|^2=0$，速率 $\left|\frac{dr}{dt}\right|$ 为常数——质点做匀速运动，故 $t$ 与弧长 $s$ 成比例。又 $\frac{d^2r}{dt^2}$ 沿法向，恰好指向轨迹 $C$ 的主法线方向，所以 $C$ 的主法向量是曲面法向量。由证明一，$C$ 是 $S$ 上的测地线。$\blacksquare$

## 证明三：弧长的第一变分公式与变分刻画

**设定**：$C:u^\alpha=u^\alpha(s)\ (a\le s\le b)$，$s$ 为弧长。变分 $u^\alpha=u^\alpha(s,t)$ 满足 $u^\alpha(s,0)=u^\alpha(s)$；若 $u^\alpha(a,t)=u^\alpha(a)$、$u^\alpha(b,t)=u^\alpha(b)$，则称**有固定端点**。变分向量场 $v^\alpha(s)=\left.\partial_t u^\alpha(s,t)\right|_{t=0}$，固定端点 $\Rightarrow v^\alpha(a)=v^\alpha(b)=0$。

**推导**：变分曲线的长度

$$L(C_t)=\int_a^b\Big(g_{\alpha\beta}(u(s,t))\,\partial_su^\alpha\,\partial_su^\beta\Big)^{1/2}ds .$$

对 $t$ 求导，在 $t=0$ 处用 $g_{\alpha\beta}\partial_su^\alpha\partial_su^\beta=1$（因 $s$ 是 $C=C_0$ 的弧长参数），得

$$\left.\frac{dL(C_t)}{dt}\right|_{t=0}=\frac12\int_a^b\Big(\partial_\gamma g_{\alpha\beta}v^\gamma\partial_su^\alpha\partial_su^\beta+2g_{\alpha\beta}\partial_sv^\alpha\partial_su^\beta\Big)ds .$$

对第二项分部积分（这是**全证明的关键一步**：把 $\partial_s v^\alpha$ 上的导数搬到 $v^\alpha$ 上），整理出

$$\left.\frac{dL(C_t)}{dt}\right|_{t=0}=g_{\alpha\beta}v^\alpha\frac{du^\beta}{ds}\Big|_{s=a}^{s=b}-\int_a^b g_{\alpha\beta}v^\alpha\Big(\frac{d^2u^\beta}{ds^2}+\Gamma^\beta_{\gamma\delta}\frac{du^\gamma}{ds}\frac{du^\delta}{ds}\Big)ds ,$$

即**弧长的第一变分公式**。固定端点时边界项消失：

$$\left.\frac{dL(C_t)}{dt}\right|_{t=0}=-\int_a^b g_{\alpha\beta}v^\alpha\Big(\frac{d^2u^\beta}{ds^2}+\Gamma^\beta_{\gamma\delta}\frac{du^\gamma}{ds}\frac{du^\delta}{ds}\Big)ds .$$

**定理（变分刻画）**：$C$ 的弧长在它的任意一个有固定端点的变分中达到临界值 $\Leftrightarrow$ $C$ 是测地线。

- $(\Rightarrow)$ 若 $C$ 是测地线，它满足测地线微分方程组，上式积分恒为零。
- $(\Leftarrow)$ 反向是难点：已知对所有固定端点变分都有 $\left.\frac{dL}{dt}\right|_{t=0}=0$，要推出 $\kappa_g=0$。技巧是**刻意选一个特殊的变分向量场**：

$$v^\alpha(s)=\sin\frac{(s-a)\pi}{b-a}\Big(\frac{d^2u^\alpha}{ds^2}+\Gamma^\alpha_{\beta\gamma}\frac{du^\beta}{ds}\frac{du^\gamma}{ds}\Big) ,$$

它满足 $v^\alpha(a)=v^\alpha(b)=0$，故确实对应一个有固定端点的变分。代入第一变分公式，利用

$$\kappa_g^2=g_{\alpha\beta}\Big(\frac{d^2u^\alpha}{ds^2}+\Gamma^\alpha_{\gamma\delta}\frac{du^\gamma}{ds}\frac{du^\delta}{ds}\Big)\Big(\frac{d^2u^\beta}{ds^2}+\Gamma^\beta_{\mu\nu}\frac{du^\mu}{ds}\frac{du^\nu}{ds}\Big) ,$$

得到

$$0=\left.\frac{dL(C_t)}{dt}\right|_{t=0}=\int_a^b\sin\frac{(s-a)\pi}{b-a}\ \kappa_g^2\,ds .$$

被积函数**处处非负**，故只能恒为零：$\kappa_g\equiv0$，$C$ 是测地线。$\blacksquare$

> 这个"取 $v=\sin(\cdot)\times($想要消灭的量$)$"的招式值得记住：**用待证量本身作变分场，靠非负性把它逼成零**。

**推论**：若 $C$ 是曲面上连接 $p,q$ 的最短线，则 $C$ 必是测地线。（最短 $\Rightarrow$ 临界 $\Rightarrow$ 测地线。逆命题不成立。）

## 证明四：存在唯一性

**曲面情形（定理 2.2）**：对曲面 $S$ 上任一点 $p$ 与任一单位切向量 $v$，存在唯一一条以弧长为参数的测地线过 $p$ 且在 $p$ 处以 $v$ 为切向。

*思路*：测地线方程组是二阶常微分方程组，初值 $(v^1,v^2)$ 定解。证明本身还给出：解必满足
$$g_{\alpha\beta}(u(s))\frac{du^\alpha}{ds}\frac{du^\beta}{ds}=g_{\alpha\beta}(u_0)v^\alpha v^\beta=\text{常数}\neq0 ,$$
所以曲线正则、参数与弧长成比例；当初速为单位向量时，$s$ 恰为弧长参数。

**流形情形（定理 3-3-4）**：$p\in M$ 与 $v^a\in V_p$ 决定唯一的测地线 $\gamma(t)$，满足 $\gamma(0)=p$、$\gamma$ 在 $p$ 的切矢等于 $v^a$。*证明*：取含 $p$ 的坐标系，测地线定义等价于 $n$ 个二阶常微分方程，$(p,v^a)$ 就是初值条件 $x^\mu(0)$ 与 $\dot x^\mu(0)$，故有唯一解。**注意："唯一"应理解为局部唯一。**

## 证明五：Gauss 引理与指数映射

**指数映射**：给定 $p\in M$ 与切向量 $v$，存在从 $p$ 出发、初速为 $v$ 的唯一测地线 $\gamma(t)$；取 $p$ 为仿射参数零点，定义

$$\exp_p(v):=\gamma(1) .$$

- $\exp_p(\underline{0})=p$（零初速给出的测地线是常值曲线）。
- **定义域可能只是 $T_pM$ 的子集**：若把 $\gamma(1)$ 从流形中挖掉，则 $v$ 在 $\exp_p$ 下无像。
- **$\exp_p$ 未必单射**：由 $(p,v)$ 与 $(p,v')$ 决定的两条不同测地线可以再次相交，适当调整 $v,v'$ 的长度可使交点恰为 $\gamma(1)=\gamma'(1)$，即 $\exp_p(v)=\exp_p(v')$。
- 由 ODE 解对初值的连续（光滑）依赖性，$\exp_p$ 是光滑映射；且 $d(\exp_p)_0=\mathrm{id}$，故 $\exp_p$ **在原点附近是局部微分同胚**——由此构造**法坐标（正规坐标）**：取 $T_pM$ 的一组标准正交基，把 $q$ 附近唯一点写成 $\exp_p(x^1e_1+\cdots+x^ne_n)$，就把 $(x^i)$ 取为该点坐标。法坐标的好处：在坐标原点处克氏符为零，从 $p$ 出发的测地线在法坐标中就是直线 $x^i=v^it$。
- 小技巧：把初速 $v$ 的长度缩小为原来的 $1/\lambda$，测地线的定义域会**成倍地扩大**（$\gamma(1;v)=\gamma(\lambda;\tfrac 1\lambda v)$）。所以只要 $|v|$ 足够小，$\exp_p$ 总有定义。

**Gauss 引理**：从点 $p$ 出发的测地线与以 $p$ 为中心的测地圆彼此正交（测地圆是测地线族的正交轨线）。

*证明*：取 $p$ 附近正交参数系使 $p$ 对应 $(0,0)$。以 $\theta$ 表示 $p$ 点切向量与 $u^1$-曲线的夹角，记过 $p$、夹角为 $\theta$ 的测地线为 $C_\theta:u^\alpha=u^\alpha(s,\theta)$，$s$ 为弧长。固定 $\theta=\theta_0$、$s\in[0,s_0]$ 得测地线段 $C$；让 $\theta$ 变动，得到 $C$ 的一个变分，其变分向量场 $w^\alpha(s)=\partial_\theta u^\alpha(s,\theta)|_{\theta_0}$ 满足 $w^\alpha(0)=0$（所有变分曲线都从 $p$ 出发），而 $w^\alpha(s_0)$ 正是测地圆在 $s=s_0$ 处的切向量。对 $L(C_\theta)$ 用第一变分公式：由于每条 $C_\theta$ 在 $[0,s_0]$ 上的长度都是 $s_0$，左端 $\frac{d}{d\theta}L(C_\theta)=0$，于是
$$g_{\alpha\beta}w^\alpha(s_0)\frac{du^\beta}{ds}\Big|_{s=s_0}=0 ,$$
即测地线与测地圆正交。$\blacksquare$

## 证明六：Hopf–Rinow（完备 $\Rightarrow$ 两点可由最短测地线连接）

**定义**：$(M,g)$ **测地完备** $\Leftrightarrow$ 每条以弧长参数化的测地线都定义在整个 $\mathbb{R}$ 上；等价地，指数映射的定义域是整个 $TM$。

**定理（Hopf–Rinow）**：连通黎曼流形度量完备 $\Leftrightarrow$ 测地完备。

*（$\Leftarrow$ 方向的反证骨架）*：设 $M$ 度量完备但不测地完备，则存在单位速率测地线 $\gamma:[0,b)\to M$ 不能延拓到任何 $[0,b')$（$b'>b$）。取递增序列 $t_i\nearrow b$，$q_i=\gamma(t_i)$。因 $\gamma$ 以弧长为参数，$d_g(q_i,q_j)\le|t_i-t_j|$，故 $(q_i)$ 是 Cauchy 列，由完备性收敛到某点 $q\in M$。再用测地线在 $q$ 附近的局部存在唯一性把 $\gamma$ 越过 $b$ 延拓出去——矛盾。$\blacksquare$

**推论**：完备连通黎曼流形中，任意两点可由一条**最短测地线段**连接（曲面上即：完备曲面上恒存在连接两点的极小测地线）。进一步，每条路径同伦类中都含一条在该类内长度最短的测地线段。更精细的局部结论：存在 $\varepsilon>0$，使得与 $p$ 距离不超过 $\varepsilon$ 的点 $q$ 有**唯一**一条从 $p$ 到 $q$ 的测地线，其长度等于 $d(p,q)$，且这是 $p,q$ 间唯一达到该长度的路径——**测地线总是局部最短的**。

# 应用

## 直接应用

**例 1（平面）**：欧氏（闵氏）度规在笛卡儿（洛伦兹）坐标下 $\Gamma^\mu_{\nu\sigma}=0$，测地线方程通解为

$$x^\mu(t)=a^\mu t+b^\mu\quad(a^\mu,b^\mu\ \text{为常数}) .$$

若把这种参数式的曲线称为直线段，则**欧（闵）氏空间的测地线就同义于直线段**。整个概念的一致性在此落地。

**例 2（球面）**：设 $S^2\subset\mathbb{R}^3$ 半径 $R$，球心为原点。三维欧氏线元 $ds^2=dr^2+r^2(d\theta^2+\sin^2\theta\,d\varphi^2)$ 在 $S^2$ 上由 $r=R$ 诱导：

$$ds^2=R^2\big(d\theta^2+\sin^2\theta\,d\varphi^2\big),\quad g_{\theta\theta}=R^2,\ g_{\varphi\varphi}=R^2\sin^2\theta,\ g_{\theta\varphi}=g_{\varphi\theta}=0 .$$

由测地线方程可证：**球面上的曲线是测地线当且仅当它是大圆弧（并配以适当的参数化）**。

**例 3（旋转面——克莱罗定理，新工具简化旧痛苦）**：
旋转面 $r=(u\cos v,\ u\sin v,\ f(u))$ 的第一基本形式 $\mathrm{I}=(1+f'^2)(du)^2+u^2(dv)^2$。用 Liouville 形式的一阶系统：

$$\frac{du}{ds}=\frac{\cos\theta}{\sqrt{1+f'^2}},\quad \frac{dv}{ds}=\frac{\sin\theta}{u},\quad \frac{d\theta}{ds}=-\frac{\sin\theta}{u\sqrt{1+f'(u)^2}} .$$

消去 $s$ 得 $\dfrac{d\theta}{du}=-\dfrac{\tan\theta}{u}$，积分即得**首次积分**

$$u\sin\theta=c .$$

于是 $v=v_0+\displaystyle\int\frac{c\sqrt{1+f'(u)^2}}{u\sqrt{u^2-c^2}}\,du$ 即为所求测地线。**$c=0$ 时给出 $v=$ 常数，即经线——与"旋转面的经线是测地线"吻合。**

几何版本（**克莱罗定理**）：设 $S$ 是曲线绕轴旋转生成的旋转曲面，$p$ 是测地线 $g$ 上点 $q$ 到旋转轴的距离，$\psi$ 是过 $q$ 的子午线与 $g$ 的夹角，则 $q$ 沿 $g$ 移动时

$$p\sin\psi=\text{常数} .$$

反之，若沿一条（任一区段都不是平行线的）曲线 $g$ 有 $p\sin\psi$ 恒定，则 $g$ 是测地线。*直观来源*：球面上单位速率质点沿测地线运行时，从球心看去的半径扫过面积的速度不变，投影到赤道平面上扫面积速度也不变，而这份面积速度正比于 $p\sin\psi$——这正是角动量守恒的几何版。

**例 4（非欧平面）**：度量 $\mathrm{I}=\dfrac{4\big((dx)^2+(dy)^2\big)}{(1-x^2-y^2)^2}$（定义域 $D=\{x^2+y^2<1\}$，Gauss 曲率 $K=-1$）上，**测地线是 $D$ 内与边界圆周正交的圆弧和直径**。它们就是"非欧平面上的直线"，于是"过直线外一点至少有两条直线与已知直线不相交"的 Lobachevskii–Bolyai 平行公理显然成立。

**例 5（伪球面 → 贝尔特拉米–庞加莱上半平面）**：该地图是共形的，故夹角 $\psi$ 保持不变。若单位速率质点的角动量为 $\Omega$，由克莱罗定理 $p\sin\psi=\Omega$ 给出 $y=\frac{1}{\Omega}\sin\psi$，即：**质点在地图中的像是与天际线 $y=0$ 正交相交的半圆周，其半径 $1/\Omega$ 恰等于角动量**。测地线的求解被"共形 + 守恒量"彻底简化了。

## 间接应用

**在数学内部可被用来证明的命题**

- **Gauss-Bonnet 公式**：设 $C$ 是抽象曲面 $(D,\mathrm{I})$ 上以测地线为边的三角形，内角 $\alpha_1,\alpha_2,\alpha_3$，则外角之和满足
  $$(\pi-\alpha_1)+(\pi-\alpha_2)+(\pi-\alpha_3)=2\pi-\iint_D K\,d\sigma .$$
  特别地 $K=0$ 时 $\alpha_1+\alpha_2+\alpha_3=\pi$。**测地线承担了"直边"的角色**，使曲率与角盈直接挂钩。
- **Bonnet 定理**：完备曲面若 $K\ge\delta>0$，则 $S$ 紧致且直径 $\rho\le\pi/\sqrt\delta$。*机制*：由 Hopf-Rinow 取连接 $p,q$ 的极小测地线 $\gamma$，沿 $\gamma$ 平行移动一个正交单位向量 $w$，取变分场 $V(s)=w(s)\sin\frac{\pi s}{l}$，用**第二变分**推出若 $l>\pi/\sqrt\delta$ 则 $\gamma$ 不是极小——矛盾。单位球面 $K\equiv1$、$\rho=\pi$ 说明估计是最佳可能的。
- **Killing–Hopf 定理**：完备、单连通、截面曲率恒定的 $n$ 维黎曼流形等距于 $\mathbb{R}^n$、$S^n(R)$ 或 $H^n(R)$——测地完备是前提。
- **内蕴几何的基本词汇**：有了测地线才能定义曲面上两点间的**距离**（足够近的两点距离 = 连接它们的测地线段长度）、**测地线圆**、**测地三角形**，并据此观察 $\varepsilon(\Delta)>0$（类球面）或 $\varepsilon(\Delta)<0$（类双曲），以及周长偏离 $2\pi r$ 的情形。

**在物理与其他学科中的作用**

- **广义相对论**：引力被理解为物质和能量压在时空中形成的**时空内蕴几何的曲率**；自由粒子与光线沿测地线运动（类时/类光测地线）。这也是为什么必须区分"极值"与"最短"：类时测地线在一般时空中**未必是最长线**，两点间也可能不存在最短类时线。
- **力学**：约束在光滑曲面上、无侧向外力的质点自动沿测地线运动——"惯性运动"在弯曲空间中的精确形态。
- **大地测量与导航**：球面上大圆航线即测地线，是"最短路"的原始动机。
- **可视化与实验**：贴着曲面拉紧的细绳、平贴缠绕的窄胶带，都是测地线的物理构造法；把沿测地线削下的窄带平铺到桌面上，测地线会变成平面直线——这正是"内蕴直性"的可触证据。

# 推广

**可以放宽的条件**

- **正则性 / 维数**：从 $\mathbb{R}^3$ 中的光滑曲面放宽到**抽象曲面**（二维黎曼流形，只需一个度量 $\mathrm{I}$ 而无需嵌入），再到 $n$ 维（伪）黎曼流形。曲面上弧长的第一变分公式可以原样搬到抽象曲面上。
- **度规的定号性**：从正定度规放宽到洛伦兹度规；此时"最短"一律改为"线长取极值"，并出现类时/类空/类光的三分。
- **"嵌入"这一条件被彻底丢弃**：测地线方程只含 $g_{\alpha\beta}$（第一基本形式），与第二基本形式无关——这是它作为内蕴概念的根本理由。

**可以泛化的结论**

- **局部 $\to$ 全局**：局部存在唯一（ODE）$\to$ 局部最短（法坐标邻域内的唯一最短路径）$\to$ 完备时全局最短（Hopf-Rinow）$\to$ 同伦类中的最短（每个路径同伦类含一条最短测地线段）。
- **单条 $\to$ 一族**：一阶变分给测地线方程，二阶变分给曲率项；球面常曲率情形的 $\ddot J=-KJ$ 推广为一般变曲率的**雅可比方程（测地线偏差方程）**，其中 $K$ 换成质点当前所在位置的曲率 $K(p)$。正曲率使相邻测地线相互吸引（并在**共轭点**重新相交，如球面上从北极出发的大圆交于南极），负曲率使它们加速分离。
- **到更一般的变分问题**：测地线是拉格朗日量 $L=\big(g_{\mu\nu}\dot x^\mu\dot x^\nu\big)^{1/2}$ 的极值曲线；极值曲线的二阶变分理论（如 §36 的一般框架）是它的母问题。

**相关的重要研究方向（公开问题线索）**

- **球面定理**：一个完备黎曼流形的截面曲率限于什么范围内，就必定与标准球面同胚、甚至微分同胚？这是 20 世纪 60—70 年代大范围黎曼几何的重点，与测地线/完备性紧密相连。
- 更一般地，大范围黎曼几何围绕测地线与曲率展开的课题包括：曲率拼挤问题、具有指定符号曲率的度量存在性、黎曼结构的有限性与塌缩、Yamabe 问题、Ricci 流、调和映射等。
- *说明*：以上仅列出与本主题强关联的研究方向；具体公开问题的最新表述超出当前资料范围。

# 常见的误解

**1. "测地线就是两点之间最短的曲线。"**
最经典也最根深蒂固的误解。球面上连接两个非对径点的大圆有短弧与长弧，**两者都是测地线**，只有短弧最短；对径点之间甚至有**无数条**测地线。正确的说法是：任意**足够接近**的两点可由唯一的测地线段连接，那才是最短路径；反过来，最短线必是测地线（推论），但测地线未必最短。*为什么会错*：教科书常用"拉紧的细绳"引入测地线，"最短"先入为主；而长度最小化是个**整体**性质，测地线本身只是**临界点**（局部变分为零）的概念。

**2. "两点确定唯一一条测地线。"**
忽略了"足够近"和"完备"两个条件。远处的两点可能有多条测地线、也可能一条都没有（如 $\mathbb{R}^2\setminus\{0\}$ 中分居原点两侧的两点）。

**3. "只要曲线的像对了，参数随便取。"**
不行。若 $t$ 是仿射参数，则 $t'$ 仍是仿射参数当且仅当 $t'=at+b$（$a\neq0$）。任意非线性重参数化会引入 $T^b\nabla_bT^a=\alpha T^a$，它已不满足测地线定义，只能叫"非仿射参数化的测地线"。*被忽略的条件*：测地线是**带参数**的曲线，不只是点的集合。

**4. "测地线是曲面的外在性质，要看曲面在空间里怎么弯。"**
恰恰相反。测地曲率在保长变形下不变，是内蕴量；测地线方程只含第一基本形式。把一张纸卷成不同形状（不拉伸、不撕裂），纸上的直线仍是那条测地线——曲颈南瓜上的实验已经说明了这一点。

**5. "测地线总能无限延伸下去。"**
只有**测地完备**才保证这一点。$\mathbb{R}^n$ 的任意真开子集、由球极投影得到的 $\mathbb{R}^n$ 上的度量、去掉顶点的单叶锥面，都会出现"在有限时间内跑到边界/撞上奇点"的测地线。完备性严格强于"不可延拓"，严格弱于"紧致"。

**6. "测地线是长度极小的曲线。"**
在洛伦兹（伪黎曼）情形，类时测地线给出的是**极值**而不一定是极大；一般时空中类时测地线**未必是最长线**（闵氏时空是例外），两点间甚至可能不存在最短类时线。此外，长度泛函的极值也可能既非极大也非极小（对应二阶变分为零的退化情形，如越过共轭点之后）。

**7. 把"测地线"和"极小曲面"混为一谈。**
前者是曲线的长度临界，后者是曲面的面积临界，属于不同维度的变分问题。

# 启发

- **"直"比"短"可靠。** 第一次看到"长弧也是测地线"时会有轻微的不适：明明更长的路，凭什么叫"地线"？但把判据从"全局最短"换成"局部最直"（$\kappa_g=0$ / 切矢自平行），一切立刻顺了。**当整体性质不稳定时，去找局部性质做定义**——这是一个反复出现的思考习惯。

- **同一个对象，四副面孔。** 测地曲率为零（几何）、切矢平行（联络）、弧长临界（变分）、无侧向力的运动（物理）。它们不是"四种测地线"，而是同一件事被四种语言照见。**能在这些语言之间自由翻译，比记住任何一个定义都重要。**

- **分部积分是变分学的引擎。** 第一变分公式的全部推导，核心只有一步：把导数从变分场 $v$ 上搬到曲线上，暴露出那个被称为"测地曲率"的量。随后"取 $v=\sin(\cdot)\times$ 待消灭量"把非负积分逼成零。这个套路在几乎所有变分问题中都会重演。

- **守恒量是降阶的钥匙。** 旋转面上那个看起来无从下手的二阶非线性方程组，因为对称性（绕轴旋转）而有了 $p\sin\psi=$ 常数。找对称性 $\to$ 找首次积分 $\to$ 降阶，这条链子比硬解方程有用得多。

- **"内蕴"是一个可以亲手验证的概念。** 把贴着测地线削下的窄带平铺到桌面，它变成一条直线；把纸卷起来，三角形的内角和纹丝不动。这些实验让 Theorema Egregium 从定理变成了直觉。

- **曲率是"力"。** 看到雅可比方程 $\ddot J=-KJ$ 的那一刻相当震撼：一个纯静的几何量 $K$，居然在扮演弹簧劲度系数的角色，决定相邻测地线是相互吸引还是加速分离，并由此给出共轭点。这也正是引力在广义相对论里的长相。

- **与自己以往认知的冲突。** 在欧氏空间里，"直线"是一个不需要解释的原初概念；到了曲面，它被迫裂成"最短""最直""自由运动"三条路，而这三条路在特定条件下才重合。原以为是同义反复的东西，其实是一个定理。

# 总结

## 思想

**把"直线"拆成两半——"最直"与"最短"——用"最直"（测地曲率为零 / 切矢沿自身平行）做定义，用"最短"做它在局部的回报。** 整个理论就是这两个性质之间的张力：局部它们一致（测地线局部最短），全局它们分离（长弧也是测地线），而完备性正是让"局部回报"升级为"全局承诺"的那个条件。

一句话版：**测地线 = 弯曲空间里"什么都不做"的运动轨迹。**

## 方法

| 技术 | 在笔记中的使用位置 |
|---|---|
| **变分法 + 分部积分** | 弧长第一变分公式的推导；把导数从变分场转移到曲线上 |
| **构造特殊变分场**：$v=\sin\frac{(s-a)\pi}{b-a}\times$(待消灭量) | 变分刻画定理的反向证明，用非负性逼出 $\kappa_g=0$ |
| **反证法** | Hopf–Rinow（假设不可延拓 $\to$ Cauchy 列收敛 $\to$ 局部可延拓，矛盾）；Bonnet 定理（假设 $l>\pi/\sqrt\delta$ $\to$ 第二变分为负 $\to$ 非极小） |
| **降阶 / 首次积分** | 克莱罗定理 $p\sin\psi=c$；旋转面测地线方程的消元与积分 |
| **ODE 存在唯一性 + 对初值的光滑依赖** | 测地线存在唯一；$\exp_p$ 的光滑性 |
| **局部微分同胚 $\to$ 好坐标** | $d(\exp_p)_0=\mathrm{id}$ 构造法坐标，使测地线在其中成为直线 |
| **正交轨线（Gauss 引理）** | 测地圆与径向测地线正交，简化第一基本形式 |
| **二阶变分 / 比较** | Jacobi 方程、共轭点、Bonnet 直径估计 |
| **物理类比（约束运动、角动量守恒、弹簧）** | 动力学刻画；克莱罗定理的角动量解释；曲率即作用力 |
| **共形映射** | 伪球面 $\to$ 贝尔特拉米–庞加莱上半平面，把测地线变成与边界正交的半圆 |

# 回看并提问

1. 测地线的三条刻画（$\kappa_g=0$、$T^b\nabla_bT^a=0$、弧长临界），哪一个最适合做**定义**？为什么？如果先定义"切矢平行"，又如何最自然地看出它蕴含"最直"？
2. 反向证明里为什么非得乘上 $\sin\frac{(s-a)\pi}{b-a}$？换成别的非负函数行不行？这个选择揭示了"变分场可以任选"的哪一部分自由度？
3. 仿射参数的自由度只有 $t'=at+b$。这个"只剩仿射变换"的事实，和仿射联络这个名字、和"直线在仿射变换下保持为直线"之间，有怎样的联系？
4. Gauss 引理说的是"径向测地线 $\perp$ 测地圆"。如果去掉测地性、改用任意曲线族，正交轨线还存在吗？这一步用到了测地线的哪一条性质？
5. $\exp_p$ 不是单射时，两条测地线在 $\exp_p(v)=\exp_p(v')$ 处相交——这个交点与**共轭点**、与第二变分为零，是同一件事的三种说法吗？
6. Hopf–Rinow 把"度量完备"与"测地完备"等价起来。这两个概念一个来自拓扑/分析，一个来自 ODE，它们的等价为什么不是显然的？证明中哪一步最不可省？
7. 洛伦兹情形下"类时测地线未必最长"。这在物理上对应什么现象？正定的证明在哪一步失效？
8. 克莱罗定理中 $p\sin\psi$ 守恒，本质是旋转对称性（角动量守恒）。对一般的有对称性的度量，是否总能把测地线方程降阶？这套思路的边界在哪里？
9. 雅可比方程 $\ddot J=-KJ$ 把曲率读成"劲度系数"。能否反过来：**用相邻测地线的分离行为来定义曲率**？这与截面曲率的定义距离有多远？
10. 如果把"长度泛函"换成"能量泛函"，临界曲线集合相同但参数行为不同——这会怎样改变"最短"与"最直"之间的分工？
