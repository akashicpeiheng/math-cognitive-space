# 坐标图 (Coordinate Chart)

## 简介

坐标图（也称坐标卡、图）是微分几何与拓扑学中最基础的工具之一。它将[[流形]]上的点映射到欧氏空间 $\mathbb{R}^n$ 中的点，使得我们能够用熟悉的实数坐标来刻画曲面上或抽象空间中的位置。从平面上的笛卡儿坐标系到球面上的经纬度，再到抽象[[流形]]上的局部坐标卡，坐标图的核心思想是：**用 $\mathbb{R}^n$ 中的开集来"参数化"[[流形]]上的开集**，从而将微积分的工具搬到[[流形]]上使用。

# 前置知识

## 必备知识

- **欧氏空间 $\mathbb{R}^n$**：$n$ 维实[[向量空间]]，带有标准的笛卡儿坐标 $(x^1,\dots,x^n)$。
- **[[拓扑空间]]与连续映射**：开集、[[同胚]]的概念。
- **多元微积分**：偏导数、Jacobi 矩阵、[[隐函数定理]]。

## 辅助知识

- **线性代数**：[[向量空间]]、基与坐标、线性变换。
- **拓扑学基础**：Hausdorff 空间、开覆盖。

## 拓展知识

- **复[[流形]]**：将 $\mathbb{R}^{2n}$ 等同于 $\mathbb{C}^n$，坐标变换函数要求为全纯函数。
- **纤维丛上的坐标图**：如[[切丛]] $TM$、[[余切丛]] $T^*M$、标架丛 $L(M)$ 上可以引入自然的坐标图。
- **代数簇上的坐标**：在代数几何中，坐标环的概念是[[流形]]上坐标函数的代数类比。

# 动机

## 引入动机

### 学科内部线索

在研究曲线和曲面时，人们很早就发现：**一个空间中的点不一定能用同一组坐标来全局地标记**。例如，二维球面 $S^2$ 上的点虽然可以用 $\mathbb{R}^3$ 中的笛卡儿坐标 $(x,y,z)$ 描述，但这三个坐标是冗余的（因为 $x^2+y^2+z^2=1$），而且不存在从整个球面到 $\mathbb{R}^2$ 的连续双射。换言之，**不能用一个统一的坐标系覆盖整个球面**。因此必须退而求其次：用多个"局部坐标系"（即坐标图）来覆盖整个空间，每个图只覆盖一个开子集。

### 外部应用线索

在物理学中，描述质点在中心力场中的运动时，极坐标系远比笛卡儿坐标系方便——Kepler 定律 $r^2\dot\varphi = \text{常数}$ 在极坐标下表达得极其简洁。在广义相对论中，时空[[流形]]的不同区域往往需要使用不同的坐标系（如 Schwarzschild 坐标与 Kruskal 坐标），坐标变换则是理解时空几何的关键工具。

### 审美/结构线索

坐标图的概念使得"[[流形]]"这个对象可以被严格定义：[[流形]]就是**局部上[[同胚]]于 $\mathbb{R}^n$ 的[[拓扑空间]]**。这个定义的优雅之处在于，它用最少的条件（局部欧氏性 + Hausdorff + 第二可数）抓住了"弯曲空间"的本质，而坐标图就是连接"局部"与"全局"的桥梁。

## 构造动机

坐标图的思想胚芽可以追溯到 Descartes 创立的解析几何。Descartes 用实数对 $(x,y)$ 标记平面上的点，使得几何问题可以转化为代数方程。随后极坐标、柱坐标、球坐标等曲线坐标系相继被引入，人们发现同一个空间可以用不同的坐标参数化。

到了 19 世纪，Gauss 在曲面的内蕴几何研究中意识到，曲面上点的"曲纹坐标" $(u,v)$ 本质上是曲面到 $\mathbb{R}^2$ 的局部映射。Riemann 则将这一思想推广到高维，提出了"[[流形]]"的雏形。20 世纪初，Veblen、Whitney 等人将[[流形]]和坐标图的概念严格公理化，奠定了现代微分几何的基础。

现代规范的坐标图定义如下：

> 设 $M$ 是一个[[拓扑空间]]，$U\subset M$ 是开集，$\varphi:U\to \varphi(U)\subset\mathbb{R}^n$ 是一个[[同胚]]，则称 $(U,\varphi)$ 为 $M$ 的一个**坐标图**（chart），$U$ 称为**坐标邻域**，$\varphi$ 称为**坐标映射**。$\varphi$ 的分量函数 $(x^1,\dots,x^n)$ 称为**局部坐标**。

# 形式

## 规范的通用形式

坐标图有几种常见的表述方式，它们在本质上等价但适用于不同的语境：

1. **用点集拓扑的语言**：$(U,\varphi)$，其中 $U\subset M$ 开，$\varphi:U\to\mathbb{R}^n$ 是[[同胚]]到它的像。
2. **用坐标函数**：在 $U$ 上定义 $n$ 个连续函数 $x^1,\dots,x^n$，使得映射 $p\mapsto (x^1(p),\dots,x^n(p))$ 是[[同胚]]。
3. **用参数化（逆映射）**：$\varphi^{-1}:\varphi(U)\to U$ 称为局部参数化，它把 $\mathbb{R}^n$ 中的区域"贴"到[[流形]]上。

这三种视角各有优劣：前两种强调"给点标坐标"，第三种强调"用参数铺满曲面"。

## 等价表达

- **坐标图 = 局部坐标系**：在实际使用中，"坐标图"和"局部坐标系"常常混用。一套局部坐标系 $\{x^\mu\}$ 就是一个坐标图。
- **图册 (Atlas)**：一族坐标图 $\{(U_\alpha,\varphi_\alpha)\}$，使得 $\{U_\alpha\}$ 覆盖 $M$。图册中的任意两个图之间要求满足**相容性条件**：在 $U_\alpha\cap U_\beta\neq\varnothing$ 时，坐标变换
  $$
  \varphi_\beta\circ\varphi_\alpha^{-1}:\varphi_\alpha(U_\alpha\cap U_\beta)\to\varphi_\beta(U_\alpha\cap U_\beta)
  $$
  是光滑的（或连续的，取决于所要求的可微类）。

## 形式的类别

坐标图可以根据其目标空间和额外结构分类：

1. **拓扑坐标图**：$\varphi$ 仅要求是[[同胚]]，不要求可微性。用于[[拓扑流形]]的定义。
2. **光滑坐标图**：坐标变换是 $C^\infty$ 的。用于[[微分流形]]。
3. **实解析坐标图**：坐标变换是实解析函数。
4. **复坐标图**：目标空间视为 $\mathbb{C}^n$，坐标变换为全纯函数。用于复[[流形]]。

另外，根据坐标网的特殊性质，又有：
- **笛卡儿坐标系**：坐标基底在欧氏度规下正交归一。
- **曲线坐标系**：如极坐标、球坐标、柱坐标，其坐标线是曲线。
- **正交坐标系**：坐标曲线处处正交。
- **重心坐标系**：用于单形上的坐标，满足 $\sum\lambda_i=1$。

## 降维表述

坐标图的概念可以用更底层的集合论语言来叙述：

> $M$ 的一个坐标图 $(U,\varphi)$ 就是 $M$ 的一个开子集 $U$ 与 $\mathbb{R}^n$ 的一个开子集之间的一个**双射**（同时要求双向连续，即[[同胚]]）。

从范畴论的视角看，坐标图是[[流形]]范畴到欧氏空间范畴的局部"窗口"：每个坐标图给出了一个局部等价，而图册则记录了这些局部等价之间如何粘合。

## 升维视角

在更高层的理论下，坐标图是以下概念的特例或原型：

- **纤维丛的局部平凡化**：[[切丛]] $TM$ 的局部坐标 $(x^\mu, \xi^\mu)$ 可以看作底[[流形]]坐标图与切空间坐标的直积。
- **标架丛的坐标图**：在 $L(M)$（线性标架丛）上，坐标图由底[[流形]]的坐标图和切向量的分量共同构成。
- **层论中的局部截面**：坐标映射 $\varphi$ 可以看作结构层的一个局部坐标化表示。

# 证明

## 概括证明

坐标图理论中一个关键结论是：**[[流形]]的维数是良定义的**。如果 $M$ 既是 $m$ 维[[流形]]又是 $n$ 维[[流形]]，则 $m=n$。

**证明思路**：设 $p\in M$，取 $p$ 处的两个坐标图 $(U,\varphi)$ 到 $\mathbb{R}^m$ 和 $(V,\psi)$ 到 $\mathbb{R}^n$。在交集 $U\cap V$ 上，考虑坐标变换 $\psi\circ\varphi^{-1}:\varphi(U\cap V)\to\psi(U\cap V)$。这是一个从一个欧氏空间开集到另一个欧氏空间开集的[[同胚]]，因此根据区域不变性定理或线性化论证（利用 Jacobi 矩阵的秩），必须有 $m=n$。

# 应用

## 直接应用

**例 1：圆周 $S^1$ 的坐标图覆盖**。

将 $S^1$ 视为 $\{(x,y)\in\mathbb{R}^2:x^2+y^2=1\}$。不能用单一坐标图覆盖整个圆周，但可以用四个图：
- $U_1=\{(x,y)\in S^1:y>0\}$，$\varphi_1(x,y)=x$；
- $U_2=\{(x,y)\in S^1:y<0\}$，$\varphi_2(x,y)=x$；
- $U_3=\{(x,y)\in S^1:x>0\}$，$\varphi_3(x,y)=y$；
- $U_4=\{(x,y)\in S^1:x<0\}$，$\varphi_4(x,y)=y$。

每个图都把一段圆弧[[同胚]]地映到开区间 $(-1,1)$。

**例 2：球面 $S^2$ 的坐标图覆盖**。

可以用六个图覆盖单位球面 $S^2$，例如从 $z>0$ 的上半球面投影到 $(x,y)$ 平面：$\varphi_1(x,y,z)=(x,y)$，定义域 $U_1=\{(x,y,z)\in S^2:z>0\}$。类似地取 $z<0$、$y>0$、$y<0$、$x>0$、$x<0$ 六个半球面。

## 间接应用

- **在物理学中**：广义相对论中，时空[[流形]]用坐标图覆盖，坐标变换对应观测者之间的参考系变换。例如 Schwarzschild 度规在事件视界处的坐标奇异性可以通过选择 Kruskal 坐标来消除。
- **在计算机图形学中**：三维曲面的纹理映射（UV mapping）本质上就是在曲面上建立局部坐标图，把曲面上的点对应到二维纹理图像上的坐标。
- **在机器人学中**：机器人操作臂的构型空间（configuration space）是一个[[流形]]，其局部坐标图对应关节角度的参数化。
- **在数据分析中**：[[流形]]学习（如 t-SNE、UMAP）试图为高维数据寻找低维坐标图，本质上是在数据点所在的[[流形]]上构造坐标表示。

# 推广

- **条件放宽**：从[[拓扑流形]]到[[微分流形]]，要求坐标变换从连续加强到光滑；进一步可以要求实解析或全纯。
- **结论泛化**：坐标图的概念可以推广到**带边[[流形]]**（坐标映射的目标空间是半空间 $\mathbb{H}^n$）、**Banach [[流形]]**（目标空间是无穷维 Banach 空间）等更一般的设定。
- **方向性推广**：若所有坐标变换的 Jacobi 行列式都为正，则[[流形]]是**可定向的**。这个条件用于定义[[流形]]上的积分理论。
- **公开问题**：在 $n=4$ 时，$\mathbb{R}^4$ 上存在不可数无穷多个互不微分[[同胚]]的[[光滑结构]]（"怪异 $\mathbb{R}^4$"），这揭示了坐标图[[光滑结构]]分类的深度复杂性。

# 常见的误解

1. **"坐标就是点的固有属性"**。事实：坐标是人为选择的，同一个点在不同坐标图下有不同的坐标值。[[流形]]上的点本身独立于坐标存在。
2. **"一个[[流形]]只需要一个坐标系"**。事实：大部分[[流形]]（如 $S^1,S^2,\mathbb{RP}^2$）无法用一个坐标图覆盖。能够用一个图覆盖的[[流形]][[同胚]]于 $\mathbb{R}^n$ 中的开集。
3. **"坐标曲线就是'直的'"**。事实：在曲线坐标系中，坐标曲线可以是弯曲的。例如极坐标中 $\varphi$ 坐标线是以原点为圆心的同心圆，$r$ 坐标线是从原点出发的射线。
4. **"极坐标的基底 $\{\hat e_r,\hat e_\varphi\}$ 就是坐标基底"**。事实：物理中常用的 $\{\hat e_r,\hat e_\varphi\}$ 是正交归一基底，而非坐标基底 $\{\partial/\partial r,\partial/\partial\varphi\}$。关键区别在于 $\partial/\partial\varphi$ 的长度为 $r$ 而不是 $1$。
5. **"所有坐标系都覆盖整个空间"**。事实：极坐标 $(r,\varphi)$ 在原点处 Jacobi 行列式为 0，不是正则坐标系；而且 $(r,\varphi)$ 和 $(r,\varphi+2\pi)$ 表示同一点，因此极坐标不是全局双射。

# 启发

- **"局部与全局"的张力**：坐标图的思想告诉我们，一个复杂的空间虽然在全局上可能扭曲、有洞、多连通，但在局部上它和平坦的欧氏空间没有区别。这种"局部线性化、全局粘合"的范式贯穿了整个微分几何。
- **坐标的自由与约束**：选择坐标是自由的，但几何量（如曲率）的表达虽依赖于坐标，其内在几何意义却与坐标无关。这种"坐标依赖但几何不依赖"的张力是理解[[张量]]分析的关键。
- **从具体到抽象**：坐标图的概念是从平面直角坐标、球面经纬度等具体例子中抽象出来的，它反过来又成为定义[[流形]]等抽象概念的基石。这种从实例到公理再回到应用的思维路径，在数学中反复出现。

# 总结

## 思想

**"在局部上用 $\mathbb{R}^n$ 来模拟[[流形]]，通过坐标变换来粘合局部信息"** ——这是坐标图乃至整个[[流形]]理论的核心思想。

## 方法

| 方法 | 在笔记中的使用 |
|------|----------------|
| 局部参数化 | 用坐标映射 $\varphi$ 将[[流形]]开集映射到 $\mathbb{R}^n$ |
| 坐标变换 | 通过 $\varphi_\beta\circ\varphi_\alpha^{-1}$ 在不同图之间切换 |
| Jacobi 矩阵 | 描述切向量在坐标变换下的分量变换规律 |
| 图册覆盖 | 用一族相容的坐标图覆盖整个[[流形]] |
| 正则性条件 | 通过 Jacobi 行列式非零判断坐标系的正则性 |
