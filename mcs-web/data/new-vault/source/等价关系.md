# 等价关系：把“相同”相对化

<!-- mcs-section:overview -->
## 对象与任务

> 一句话：等价关系是按某个标准把对象分到同一类的关系；它把“相等”从逐点相同放宽为同类，从而让分类与商集成为可能。

#集合论 #等价关系 #商集 #定义

对象是集合 $X$ 上的等价关系，以及由它得到的等价类与商集 $X/{\sim}$。本篇任务是：给出定义并逐条检查三条性质的作用；证明“等价类构成划分”“划分反过来给出等价关系”“每个等价关系都是商映射的核”；给出商集的通用性质；说明等价关系的生成、与运算的相容性，以及它与相等、同余、同构的层次差别。

阅读价值：数学里大量判断是“按某个标准相同”——$1/2$ 与 $2/4$ 是不同的有序对，却表示同一个有理数；$2$ 与 $7$ 不同，却模 $5$ 同余；两个三角形可以形状相同；两个函数可以几乎处处相等。等价关系把这些“相同”写成可检查的三条性质，并把“同类”变成一个新的对象：等价类。

本篇承诺以上内容。本篇不展开：范畴论中的余等化子、同伦类型论中的 identity type、构造性数学中的 setoid 细节；这些只在“推广与联动”中作为入口出现。尚未处理：等价关系这一术语的历史（本篇不做史料断言），以及一般分类问题（那是各分支的具体任务，不是本节点能完成的）。

<!-- mcs-section:background -->
## 背景与约定

本篇在通常的集合论中工作；$X$ 始终是一个集合，关系是笛卡儿积的子集。

- 二元关系 $R\subseteq X\times X$；记 $x\sim y$ 当且仅当 $(x,y)\in R$。$X$ 上的相等关系记 $\Delta_X=\{(x,x):x\in X\}$，全集关系记 $X\times X$。
- 等价类 $[x]=\{y\in X:y\sim x\}$；商集 $X/{\sim}=\{[x]:x\in X\}$；商映射 $q:X\to X/{\sim}$，$q(x)=[x]$。等价类的个数记作 $\lvert X/{\sim}\rvert$，有限时称为指数。
- 划分：$X$ 的一族非空、两两不交、并为 $X$ 的子集。空集上的划分取空族，使后文对应在空集上也成立。
- “相容”：若 $X$ 上有二元运算 $*$，称 $\sim$ 与 $*$ 相容，是指 $x\sim x'$ 且 $y\sim y'$ 蕴含 $x*y\sim x'*y'$。只有相容时，才能把 $*$ 搬到 $X/{\sim}$ 上。
- 不假设每个等价类有标准代表元；选取代表元有时需要选择公理。商上的定义若依赖代表元，必须验证代表元无关性。
- “同构”只有在固定一个由结构组成的集合时，才是该集合上的等价关系；“所有群在群同构下”不是一个集合上的关系，本篇不把真类（proper class）当作集合处理。
- 名称约定：本篇用“等价关系”指满足三条性质的关系；“同余”专指与代数运算相容的等价关系；“相等”专指 $\Delta_X$。

## 前置知识

必备：

- 集合、子集、幂集、笛卡儿积：关系是 $X\times X$ 的子集。
- 映射、像、纤维：核关系与商映射都用函数语言表述。
- 基本逻辑与量词：三条性质都是带量词的句子。
- 划分：等价类构成划分，划分反过来给出等价关系。

辅助：

- 整数与同余：$\mathbb{Z}/n\mathbb{Z}$ 是最具体的例子。
- 有理数的构造：$\mathbb{Q}$ 可看作 $\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})$ 的商。
- 群、环、模的商：商群、商环、商模都要求同余（正规子群、理想、子模）。

拓展：

- 范畴论：等价关系是群胚对象与余等化子的入口。
- 同伦类型论：identity type 与 setoid 的入口。
- 并查集：维护等价类的算法结构。

<!-- mcs-section:introduction -->
## 历史与动机：引入

现代重构，两条需求：

1. 分类。把对象按某个标准归并：整数按模 $n$ 的余数、三角形按形状、集合按基数、函数按几乎处处相等。需要一种“同类”判断，它要像相等一样可以传递、可以互换。
2. 造新对象。想用“同类”作为一个新的元素：$\mathbb{Z}/n\mathbb{Z}$ 的元素是剩余类，$\mathbb{Q}$ 的元素是有理数类，商空间的点是一族点。需要把“类”本身变成集合的元素，并且让函数、运算能够穿过商映射。

已有工具是集合与映射；困难在于相等太细：$1/2$ 与 $2/4$ 作为有序对不同，作为有理数相同。等价关系就是“按标准把相等放宽”，同时保留相等的可用性质（自反、对称、传递）。

历史：本篇不主张具体术语的起源与年份，只把上述线索当作现代重构。等价关系与划分的对应、商映射的核的表述，是标准集合论与代数教材的内容（入口见文末）。

<!-- mcs-section:construction -->
## 历史与动机：构造

胚子：相等关系 $\Delta_X$。它是最细的“相同”：只把 $x$ 与 $x$ 认作同类。

放宽与调整：

- 去掉“必须逐点相同”，改成某个可判定的标准 $x\sim y$；保留自反，使每个元素至少与自身同类。
- 加入对称，使“同类”是相互的；否则 $[x]$ 的定义会偏向一边。
- 加入传递，使“同类”沿链闭合；否则类会重叠，商集不再是划分。
- 结果是：$x\sim y$ 当且仅当 $[x]=[y]$。也就是说，等价关系把“同类”变成了商集上的真正相等。

竞争形式：

- 划分式：先给 $X$ 的划分，再规定“同块”为等价。
- 核式：先给函数 $f:X\to Y$，再规定 $f(x)=f(y)$ 为等价。
- 预序式：自反且传递的关系称为预序；再要求对称，就得到等价关系（对称预序）。

这些形式互相等价，证明见论证 1–3；它们不是三个不同的对象，而是同一结构的三种入口。

历史边界：以上是现代重构。本篇不把“先有定义、后有商集”的逻辑顺序写成史料。

<!-- mcs-section:intuition -->
## 直觉

图景：把 $X$ 的元素按某个标准装进互不重叠的盒子；每个元素恰好在一个盒子里；盒子就是等价类，盒子集合就是商集。

形式对应：$[x]$ 是 $x$ 所在的盒子；$q(x)=[x]$ 是“取盒子”的映射；$x\sim y$ 就是“在同一个盒子”。

操作：遇到关于 $X$ 的陈述，如果它只依赖盒子，就改写成关于 $X/{\sim}$ 的陈述；遇到商上的定义，先用代表元写出来，再验证与代表元无关。

便利性：传递性自动成立——同一个盒子的关系不需要逐对检查；分类后，问题从“对所有元素”变成“对所有类”。

失效边界：

- 商集丢失信息：从 $X/{\sim}$ 一般不能还原 $X$；$q$ 通常不是单射。
- 运算不一定能下降：$\lvert x\rvert=\lvert y\rvert$ 是 $\mathbb{Z}$ 上的等价关系，但加法不能搬到商上（见论证 6）。
- “同类”依赖所选标准：同一个集合上可以有许多不同的等价关系；没有绝对的“相同”。
- 等价关系不是“接近”：它没有度量含义，$x\sim y$ 是全部或全无。

检验：在 $\mathbb{Z}/5\mathbb{Z}$ 中 $[2]=[7]$，但 $2\ne7$；这说明商映射把不同元素合并。迁移：在 $\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})$ 上写出“表示同一个有理数”的关系，并验证三条性质。

<!-- mcs-section:form -->
## 精确内容

### 一句直觉与标准形式

直觉：等价关系是“按标准同类”，三条性质保证“同类”像相等一样可用。

定义（DEF）：设 $X$ 是集合，$\sim$ 是 $X$ 上的二元关系。称 $\sim$ 为等价关系，如果

1. 自反：$\forall x\in X,\ x\sim x$；
2. 对称：$\forall x,y\in X,\ x\sim y\Rightarrow y\sim x$；
3. 传递：$\forall x,y,z\in X,\ (x\sim y\ \text{且}\ y\sim z)\Rightarrow x\sim z$。

读回自然语言：每个元素与自己同类；同类是相互的；如果 $x$ 与 $y$ 同类、$y$ 与 $z$ 同类，那么 $x$ 与 $z$ 同类。

### 符号与量词范围

$X$ 是集合；$\sim\subseteq X\times X$；$x,y,z$ 取遍 $X$；$[x]$ 是 $X$ 的子集；$X/{\sim}\subseteq\mathcal{P}(X)$；$q:X\to X/{\sim}$ 是满射。注意 $[x]$ 是集合，不是元素 $x$ 本身；$X/{\sim}$ 的元素是子集。

基本恒等（PROOF）：$x\sim y\iff[x]=[y]$。

（$\Rightarrow$）若 $x\sim y$，任取 $z\in[x]$，则 $z\sim x\sim y$，故 $z\in[y]$，所以 $[x]\subseteq[y]$；对称地 $[y]\subseteq[x]$。

（$\Leftarrow$）若 $[x]=[y]$，由自反 $x\in[x]=[y]$，故 $x\sim y$。

### 逐条件分析

下表检查每条性质的作用；每个模型都满足其余两条，故三条彼此不能互推。

| 条件 | 作用 | 删除后的模型 | 证据 |
| --- | --- | --- | --- |
| 自反 | 每个元素属于自己的类；$[x]$ 非空 | $X=\{1,2\}$，$R=\{(1,1)\}$：对称、传递，但 $2$ 不与自身相关 | PROOF |
| 对称 | “同类”相互；$[x]$ 不偏向 | $\mathbb{R}$ 上的 $\le$：自反、传递，但不对称 | PROOF |
| 传递 | 类沿链闭合，避免重叠 | $\mathbb{R}$ 上 $\lvert x-y\rvert<1$：自反、对称，但不传递（$0\sim0.9$，$0.9\sim1.8$，$0\not\sim1.8$） | PROOF |

补充（PROOF）：若 $\sim$ 对称且传递，并且每个 $x\in X$ 都与某个 $y$ 相关，则 $\sim$ 自反：由 $x\sim y$ 得 $y\sim x$，再由传递得 $x\sim x$。这说明自反性不是“多余”，而是保证每个元素都有类；只满足对称与传递的关系称为部分等价关系（partial equivalence relation），它在部分函数与类型论中出现。

三条性质的“独立性”只指每一条不能由其余两条推出；这不表示任意两条加上其他附加条件都不能推出第三条。

### 等价表达与类别

- 划分式：$X$ 的划分 $P$ 给出等价关系 $x\sim_P y$ 当且仅当 $x,y$ 同属 $P$ 的某块（论证 2）。
- 核式：函数 $f:X\to Y$ 给出等价关系 $x\sim_f y$ 当且仅当 $f(x)=f(y)$；每个等价关系都是商映射 $q$ 的核（论证 3）。
- 预序式：等价关系等于对称的预序（自反、传递、对称）。
- 商式：$x\sim y$ 当且仅当 $[x]=[y]$；等价关系正是使商映射的纤维成为类的那个关系。
- 与相等的关系：$\Delta_X\subseteq\sim\subseteq X\times X$；相等是最细的等价关系，全集关系是最粗的（PROOF：自反给前者，定义给后者）。

### 典型例

- 相等 $\Delta_X$；全集 $X\times X$。前者商集与 $X$ 双射，后者商集只有一个元素。
- 模 $n$ 同余：$a\sim b$ 当且仅当 $n\mid(a-b)$（$n\ge1$）。三条性质由整数运算直接验证；商集是 $\mathbb{Z}/n\mathbb{Z}$。PROOF。
- 有理数：在 $X=\mathbb{Z}\times(\mathbb{Z}\setminus\{0\})$ 上令 $(a,b)\sim(c,d)$ 当且仅当 $ad=bc$。自反 $ab=ba$；对称由 $ad=bc$ 交换；传递用 $ad=bc$、$cf=de$ 交叉相乘并消去 $d$。商集是 $\mathbb{Q}$（每个类记作 $a/b$）。PROOF。
- 同一个首字母的单词；同一天生日的人；形状相同的三角形；集合族中基数相同的集合（限制在一个由集合组成的集合上）。这些例子只需逐条核对三条性质（ILLUSTRATION）。
- 无向图的可达性：顶点 $u\sim v$ 当且仅当存在从 $u$ 到 $v$ 的路径（规定 $u$ 到自身有长度 $0$ 的路径）。等价类就是连通分支。PROOF。
- 矩阵的行等价；函数几乎处处相等；固定端点的路径同伦。前两个是标准等价关系；同伦是拓扑中的等价关系，本篇只给入口（ILLUSTRATION/NOT-CLAIMED 细节）。

### 非例与反例

区分：非例只说明“不是等价关系”；反例要满足某个命题的其余前提并否定结论。

- $\le$ 在 $\mathbb{R}$ 上：自反、传递，但不对称（非例）。
- $<$ 在 $\mathbb{R}$ 上：传递，但不自反、不对称（非例）。
- $\lvert x-y\rvert<1$ 在 $\mathbb{R}$ 上：自反、对称，但不传递（反例，针对“自反加对称就够”）。
- “有公共素因子”在 $\mathbb{Z}_{>1}$ 上：自反（$n$ 与自身有公共因子 $n$）、对称，但不传递：$2\sim6$、$6\sim3$，而 $2\not\sim3$（反例，针对“自反加对称推出传递”）。
- 偏序集中的“可比”关系：自反、对称，但不传递；在整除偏序中 $2\sim1$、$1\sim3$，而 $2\not\sim3$（反例）。
- 空集上的空关系是等价关系（三条性质空洞成立）；$\lvert x-y\rvert<1$ 在有理数上仍是反例（非例与反例的边界要按 $X$ 检查）。

## 论证、证明或解题

### 1. 等价类构成划分（PROOF）

设 $\sim$ 是 $X$ 上的等价关系，$\mathcal{C}=\{[x]:x\in X\}$。

- 非空：$x\in[x]$（自反）。
- 覆盖：每个 $x$ 属于 $[x]$。
- 两两不交或相等：若 $[x]\cap[y]\ne\varnothing$，取 $z\in[x]\cap[y]$；则 $z\sim x$、$z\sim y$，由对称与传递得 $x\sim y$。对任意 $w\in[x]$，$w\sim x\sim y$，故 $w\in[y]$，即 $[x]\subseteq[y]$；对称地 $[y]\subseteq[x]$，故 $[x]=[y]$。

因此 $\mathcal{C}$ 是 $X$ 的划分。

### 2. 划分给出等价关系（PROOF）

设 $P$ 是 $X$ 的划分。定义 $x\sim_P y$ 当且仅当存在 $B\in P$ 使 $x,y\in B$。自反：$x$ 属于唯一块 $B$；对称：同块关系对称；传递：若 $x,y$ 同块 $B$、$y,z$ 同块 $B'$，则 $y\in B\cap B'$，由划分的两两不交得 $B=B'$，故 $x,z$ 同块。于是 $\sim_P$ 是等价关系。映射 $\sim\mapsto X/{\sim}$ 与 $P\mapsto\sim_P$ 互为逆（论证 1 与上面的构造），故等价关系与划分一一对应。

### 3. 核、商映射与纤维（PROOF）

对 $f:X\to Y$，$\ker f=\{(x,y):f(x)=f(y)\}$ 是等价关系（三条性质由 $=$ 的性质直接得到）。反过来，若 $\sim$ 是 $X$ 上的等价关系，$q:X\to X/{\sim}$，则 $x\sim y$ 当且仅当 $q(x)=q(y)$，故 $\sim=\ker q$。因此：$X$ 上的等价关系正是以 $X$ 为定义域的函数的核。商映射 $q$ 是满射；$q$ 单射当且仅当 $\sim=\Delta_X$。并且 $X/{\sim}\to\operatorname{im}f$，$[x]\mapsto f(x)$ 是双射（对 $f$ 的核关系）。

### 4. 商集的通用性质（PROOF）

设 $f:X\to Y$ 满足 $x\sim y\Rightarrow f(x)=f(y)$（即 $f$ 在类上为常值）。则存在唯一映射 $\bar f:X/{\sim}\to Y$ 使 $f=\bar f\circ q$。

定义 $\bar f([x])=f(x)$。若 $[x]=[x']$，则 $x\sim x'$，故 $f(x)=f(x')$，所以 $\bar f$ 良定义。唯一性：$q$ 满射，故 $\bar f$ 在每点 $[x]=q(x)$ 的值被 $f(x)$ 强制。这个性质是“先验证常值，再穿过商”的接口；它只处理函数，不自动给出商上的运算——运算需要相容性（论证 6）。

### 5. 生成的等价关系（PROOF）

任意一族等价关系的交仍是等价关系（三条性质逐条对交封闭）。因此对任意关系 $R\subseteq X\times X$，存在包含 $R$ 的最小等价关系，记 $R^{\sim}$：取所有包含 $R$ 的等价关系的交即可（$X\times X$ 是其中一个，族非空）。

显式描述：$x\ R^{\sim}\ y$ 当且仅当存在 $n\ge0$ 与 $x_0,\dots,x_n\in X$，使 $x_0=x$、$x_n=y$，且每个 $(x_i,x_{i+1})\in R\cup R^{-1}$，其中 $R^{-1}=\{(y,x):(x,y)\in R\}$。证明：这样定义的 $S$ 自反（$n=0$）、对称（反转链）、传递（拼接链），且包含 $R$；任何包含 $R$ 的等价关系必含 $R^{-1}$ 并对链传递，故含 $S$，所以 $S=R^{\sim}$。

### 6. 相容性与商上的运算（PROOF/FINITE）

设 $X$ 上有二元运算 $*$。若 $\sim$ 与 $*$ 相容，则 $[x]*[y]:=[x*y]$ 在 $X/{\sim}$ 上良定义：若 $[x]=[x']$、$[y]=[y']$，则 $x\sim x'$、$y\sim y'$，故 $x*y\sim x'*y'$，类相同。反之，若该定义与代表元无关，则相容性成立。

不相容的例子（FINITE）：$X=\mathbb{Z}$，$x\sim y$ 当且仅当 $\lvert x\rvert=\lvert y\rvert$ 是等价关系；但 $1\sim-1$、$2\sim2$，而 $1+2=3$ 与 $-1+2=1$ 不同类（$\lvert3\rvert\ne\lvert1\rvert$），故加法不能下降到商上。这说明“有等价关系”不等于“商上有运算”。

### 7. 预序的反对称化（PROOF）

设 $\le$ 是 $X$ 上的预序（自反、传递）。令 $x\sim y$ 当且仅当 $x\le y$ 且 $y\le x$。则 $\sim$ 是等价关系：自反由预序的自反；对称由定义；传递由 $\le$ 的传递。

在 $X/{\sim}$ 上定义 $[x]\le[y]$ 当且仅当 $x\le y$。良定义：若 $x\sim x'$、$y\sim y'$、$x\le y$，则 $x'\le x\le y\le y'$；自反、传递由 $\le$ 继承；反对称：若 $[x]\le[y]$ 且 $[y]\le[x]$，则 $x\le y$、$y\le x$，故 $x\sim y$，$[x]=[y]$。于是预序商去“互相 $\le$”的等价关系后得到偏序。这是“预序 = 等价关系 + 偏序”的精确版本。

<!-- mcs-section:applications -->
## 应用

直接应用：构造商对象。$\mathbb{Z}/n\mathbb{Z}$、$\mathbb{Q}$、商群 $G/N$、商环 $R/I$、商向量空间 $V/W$、商拓扑空间 $X/{\sim}$、射影空间，它们的元素都是等价类；运算与拓扑必须良定义。

直接应用：分类与标准形。矩阵的行等价类可以用行最简形作代表；有限集按基数分类；相似矩阵的类在代数闭域上可以用 Jordan 形作代表。等价关系把“分类”拆成“找不变量”与“找标准代表元”两件事。

间接应用：并查集维护等价类；按关键字去重与哈希合并；程序规范里的“视为相同”可以用等价关系表述；构造性数学用 setoid 代替商集（入口）。

条件匹配：商上的运算要先验证相容性；商映射一般不单射；代表元的选择不能影响结果。若这三点没有检查，结论不能从商集自动继承。

<!-- mcs-section:connections -->
## 推广与联动

- 划分、核、商：等价关系等于划分，等于商映射的核；三个视角可以互相翻译（论证 1–3）。
- 预序与偏序：预序商去“互相 $\le$”得到偏序（论证 7）；等价关系是“把预序的循环压平”。
- 相容性与同余：代数上的等价关系若与运算相容称为同余；商群、商环、商模都要求同余（正规子群、理想、子模）。等价关系本身只是一层分类，不保证运算下降。
- 关系类型对照：

| 关系类型 | 自反 | 对称 | 传递 | 例子 |
| --- | --- | --- | --- | --- |
| 等价关系 | 是 | 是 | 是 | 模 $n$ 同余 |
| 部分等价关系 | 未必 | 是 | 是 | $x=y\ne0$ 在 $\mathbb{Z}$ 上 |
| 容忍关系 | 是 | 是 | 未必 | $\lvert x-y\rvert<1$ |
| 预序 | 是 | 未必 | 是 | $\le$ 在 $\mathbb{R}$ 上 |
| 偏序 | 是 | 否（除相等外） | 是 | 集合包含 |
| 相等 | 是 | 是 | 是 | $\Delta_X$ |
| 全集关系 | 是 | 是 | 是 | $X\times X$ |

- 更高层：把集合换成对象、把“同属一类”换成“存在可逆态射”，得到群胚与分类空间的语言；集合上的等价关系可以看成一个每态射都可逆的范畴（入口）。同伦类型论把“相等”本身变成类型，等价关系与 identity type 的关系是另一个层次的问题（入口，NOT-CLAIMED）。
- 相等、同余、同构：“相等”是固定集合上的 $\Delta_X$；“同余”是相容的等价关系；“同构”是结构之间的等价关系（在固定一个结构集合后）。三者不能互相替代。

## 误解、试错与启发

以下为常见误区的校准，不含某位学习者的个人经历；个人试错待作者补充。

1. 误区：“自反是自动的。”原因：只检查了对称与传递。检验：$X=\{1,2\}$，$R=\{(1,1)\}$ 对称、传递，但 $2$ 不与自身相关。
2. 误区：“对称加传递一定自反。”原因：漏掉“每个元素至少与某个元素相关”。检验：上述 $R$；若每个 $x$ 都与某个 $y$ 相关，则自反（见精确内容·补充）。
3. 误区：“两个等价类可以相交但不相等。”原因：把“同类”当成“有公共元素”。检验：若 $z\in[x]\cap[y]$，则 $x\sim z\sim y$，故 $[x]=[y]$。
4. 误区：“商映射是单射。”原因：把“取类”当成“保留元素”。检验：$[2]=[7]$ 在 $\mathbb{Z}/5\mathbb{Z}$ 中，但 $2\ne7$；单射只在 $\sim=\Delta_X$ 时成立。
5. 误区：“任何等价关系都能让商上的运算良定义。”原因：只验证了三条性质，没有验证相容性。检验：$\lvert x\rvert=\lvert y\rvert$ 在 $\mathbb{Z}$ 上，$1\sim-1$、$2\sim2$，但 $1+2$ 与 $-1+2$ 不同类。
6. 误区：“等价就是相等。”原因：把“同类”当成“同一个元素”。检验：相等是最细的，全集关系是最粗的；商集把类变成新的相等。
7. 误区：“代表元可以随便选，结果总是一样。”原因：把良定义当成自动。检验：在商上定义运算或函数时必须验证代表元无关性；否则换一个代表元结果会变。
8. 误区：“所有群在群同构下是一个等价关系。”原因：忽略真类与集合的差别。检验：等价关系按定义是某个集合 $X$ 上的关系；要谈同构类，先把群限制在一个集合中，或用群胚语言。
9. 误区：“$x\sim y$ 表示 $x$ 与 $y$ 很接近。”原因：把等价关系与度量接近混淆。检验：等价关系只有“是/否”，没有误差大小；几乎处处相等与逐点相等也不同。

<!-- mcs-section:summary -->
## 思想与方法总结

思想：

- “把相同相对化”：等价关系是按标准同类；商集把“同类”变成新的相等。
- “三条性质、一个划分、一个核”：等价关系、划分、商映射的核是同一结构的三种写法。
- “先分类，再下降”：商上的函数或运算必须先验证常值或相容；代表元无关性是商构造的通行证。

方法（注明使用位置）：

- 验证三条：用于定义与逐条件分析；反例说明每条不可省。
- 划分法：用等价类构造划分，或用划分构造关系（论证 1–2）。
- 核与商法：把关系写成某个函数的核，用商映射与通用性质（论证 3–4）。
- 生成法：取交或链式闭包得到最小等价关系（论证 5）。
- 相容性检查：商运算前验证代表元无关性（论证 6）。
- 预序商：预序 → 等价关系 → 偏序（论证 7）。
