# 对偶恒等式：格与布尔代数中的镜像

<!-- mcs-section:overview -->
## 对象与任务

> 一句话：对偶恒等式是把一个恒等式中的 $\wedge$ 与 $\vee$ 互换、$0$ 与 $1$ 互换、$\le$ 与 $\ge$ 互换后得到的“镜像”恒等式；在格与布尔代数中，原式成立则对偶式也成立。

#代数 #布尔代数 #格 #对偶

对象是格/布尔代数中的对偶律与对偶恒等式。本篇任务是：给出格、有界格、分配格、布尔代数的定义；定义项的对偶与恒等式的对偶；陈述并证明对偶律（duality law）；列出常见的对偶恒等式对（幂等、交换、结合、吸收、分配、单位、零律、补律、De Morgan）；说明对偶律的适用边界（补元、分配性、完备性）；用集合代数、命题逻辑、开关电路解释；把线性空间的零化子对偶作为“同型现象”放在联动中，而不是混为一谈。

阅读价值：对偶律是一条“证明减半”的元定理。只要证明了一个恒等式，就能免费得到它的镜像；集合的并与交、逻辑的且或、电路的串联并联、序的上下，都服从同一面镜子。把“对偶交换什么、不交换什么”“哪些结构才有对偶”“对偶式与原式是否等价”分清，才能正确使用对偶，而不是把“取反”误当“对偶”。

说明：本篇按“对偶恒等式”的通常含义，讲格/布尔代数中的对偶律；线性空间的零化子恒等式是另一种对偶现象，放在“推广与联动”中作为入口。历史：本篇不做史料断言；布尔代数、对偶律的历史与人物不在本篇核验范围内（NOT-CLAIMED）。

<!-- mcs-section:background -->
## 背景与约定

本篇的舞台是偏序集、格与布尔代数。

- 偏序集：$(P,\le)$，满足自反、反对称、传递。
- 格：偏序集，任意两个元素 $x,y$ 都有最大下界 $x\wedge y$（meet）与最小上界 $x\vee y$（join）。
- 有界格：有最小元 $0$ 与最大元 $1$。
- 分配格：满足
  $$
  x\wedge(y\vee z)=(x\wedge y)\vee(x\wedge z)
  $$
  的格；在格中，这一条与它的对偶分配律等价。
- 布尔代数：有界分配格，且每个 $x$ 有补元 $\neg x$ 满足
  $$
  x\wedge\neg x=0,\qquad x\vee\neg x=1.
  $$
  补元在布尔代数中唯一。
- 项的语法：由变量、常数 $0,1$、二元运算 $\wedge,\vee$、一元运算 $\neg$ 构成的表达式；本篇的恒等式指“对所有变量取值都成立”的等式。
- 对偶项：把 $\wedge$ 与 $\vee$ 互换、$0$ 与 $1$ 互换，变量与 $\neg$ 保持不变，递归得到的项。对偶恒等式：把等式两边分别取对偶。
- 对偶序：把 $\le$ 反向得到 $\ge$；在对偶序下，原格的下确界/上确界互换。
- 对偶律（metatheorem）：格论/布尔代数中，任何由公理推出的命题，在对偶化后仍成立；对恒等式就是“原式成立则对偶式成立”。
- 自对偶：一个项或恒等式在对偶下不变（或与自身对偶等价）。
- 集合解释：$\wedge=\cap$、$\vee=\cup$、$0=\varnothing$、$1=X$、$\neg=$ 补集、$\le=\subseteq$。
- 逻辑解释：$\wedge=\text{AND}$、$\vee=\text{OR}$、$0=\text{false}$、$1=\text{true}$、$\neg=\text{NOT}$；序对应蕴含（在命题逻辑的 Lindenbaum 代数中）。
- 线性代数的零化子：有限维空间中 $U\mapsto U^{0}$ 反向包含；$(U+W)^{0}=U^{0}\cap W^{0}$、$(U\cap W)^{0}=U^{0}+W^{0}$。这是“反序对偶”的同型现象，但不是本篇的布尔代数恒等式（入口）。

## 历史与动机：引入

现代重构，四条需求：

1. 证明减半。格与布尔代数的公理在对偶下保持；证明了一个恒等式，镜像恒等式自动成立。
2. 统一不同语言。集合的并与交、逻辑的且与或、电路的串联与并联、序的上下界，都是同一组公理的不同解释；对偶律让它们共享定理。
3. 化简表达式。布尔表达式的对偶式在化简、卡诺图、逻辑综合中成对出现；De Morgan 律是最常用的对偶对。
4. 看清边界。对偶不是“取反”：变量不取反，$\neg$ 不交换；不是每个格都有补元，不是每个格都分配；无限并交需要完备性。

核心困难不是“把符号换一下”，而是四件事：对偶交换什么、不交换什么；恒等式与条件等式的区别；格/布尔代数/完备布尔代数的层级；线性代数零化子对偶与布尔对偶的区别。把这四件事分清，对偶律才是可靠的证明工具。

历史：本篇不做史料断言；布尔代数、对偶律、De Morgan 律的历史与人物不在本篇核验范围内（NOT-CLAIMED）。

## 历史与动机：构造

胚子：集合的并交。$A\cap(B\cup C)=(A\cap B)\cup(A\cap C)$ 与 $A\cup(B\cap C)=(A\cup B)\cap(A\cup C)$ 成对出现；把 $\cap$ 与 $\cup$ 互换，就得到另一条。

序的构造：把偏序 $\le$ 反向，得到对偶偏序 $\ge$。在原序中的最大下界，在对偶序中变成最小上界；于是 $\wedge$ 与 $\vee$ 互换，$0$ 与 $1$ 互换。

代数构造：把格 $L$ 的运算改为 $x\wedge^{d}y=x\vee y$、$x\vee^{d}y=x\wedge y$；得到的 $L^{d}$ 仍是格（对偶格）。若 $L$ 是布尔代数，补元 $\neg$ 在 $L^{d}$ 中仍是补元（因为补律的两条在对偶下互换），故 $L^{d}$ 也是布尔代数。

语法构造：对项递归定义对偶 $t^{d}$：变量不变，$(s\wedge t)^{d}=s^{d}\vee t^{d}$，$(s\vee t)^{d}=s^{d}\wedge t^{d}$，$0^{d}=1$，$1^{d}=0$，$(\neg s)^{d}=\neg s^{d}$。恒等式 $s=t$ 的对偶是 $s^{d}=t^{d}$。

对偶律的证明思路：格/布尔代数的公理集在对偶下不变；因此任何从公理出发的证明，把每一步对偶化，仍是合法证明。语义版本：任何格 $L$ 的对偶格 $L^{d}$ 仍是格；原恒等式在 $L^{d}$ 中成立，翻译回 $L$ 就是对偶恒等式。

历史边界：以上是现代重构，不主张历史上的发现按此顺序发生。

## 直觉

图景一（镜子）：把格倒过来看；上下颠倒，$\wedge$ 与 $\vee$ 互换，$0$ 与 $1$ 互换。原命题的镜像就是对偶命题。

图景二（集合）：交与并互换；空集与全集互换；补集不变。De Morgan 律是一对镜像。

图景三（逻辑）：AND 与 OR 互换；false 与 true 互换；NOT 不变。对偶式就是“把且或对调”的公式。

图景四（电路）：串联与并联互换；常开与常闭互换；对偶电路实现对偶函数。

失效边界：

- 对偶不取反变量：$x\wedge y$ 的对偶是 $x\vee y$，不是 $\neg x\vee\neg y$。
- 对偶不交换 $\neg$：补运算保持；但补律的两条互换。
- 对偶只对“在对偶下封闭”的结构（格、布尔代数）成立；一般环、模、序半群不一定。
- 格不一定有补元；没有补元就没有 De Morgan 律的完整版本。
- 格不一定分配；分配律的对偶在非分配格中不成立（原式也不成立）。
- 无限并交的 De Morgan 律需要完备性；一般布尔代数只有有限运算。

检验：$x\wedge(y\vee z)=(x\wedge y)\vee(x\wedge z)$ 的对偶是 $x\vee(y\wedge z)=(x\vee y)\wedge(x\vee z)$。迁移：把 $x\wedge\neg x=0$ 对偶化，得到 $x\vee\neg x=1$。

## 精确内容

### 一句直觉与标准形式

直觉：对偶恒等式是“把格倒过来”后得到的恒等式；交换 $\wedge/\vee$、$0/1$、$\le/\ge$，变量与 $\neg$ 不动。

定义（DEF）：设 $t$ 是由变量、$0,1,\wedge,\vee,\neg$ 构成的项。对偶项 $t^{d}$ 递归定义为：

$$
x^{d}=x,\quad 0^{d}=1,\quad 1^{d}=0,\quad
(s\wedge t)^{d}=s^{d}\vee t^{d},\quad
(s\vee t)^{d}=s^{d}\wedge t^{d},\quad
(\neg s)^{d}=\neg s^{d}.
$$

恒等式 $s=t$ 的对偶恒等式为 $s^{d}=t^{d}$。

### 对偶律

定理（PROOF）：在格（或布尔代数）中，若恒等式 $s=t$ 对所有取值成立，则 $s^{d}=t^{d}$ 也对所有取值成立。更一般地，格论/布尔代数中由公理推出的命题，对偶化后仍成立。

- 对序：$x\le y$ 的对偶是 $y\le x$。
- 对运算：$\wedge$ 与 $\vee$ 互换；$0$ 与 $1$ 互换；$\neg$ 不变。
- 对恒等式：两边同时取对偶。
- 自对偶：$x\wedge(y\vee x)=x$ 与 $x\vee(y\wedge x)=x$ 互为对偶；若一个命题与自身对偶等价，称自对偶。

### 常见对偶恒等式对

| 原名 | 对偶名 | 证据 |
| --- | --- | --- |
| $x\wedge x=x$ | $x\vee x=x$ | DEF |
| $x\wedge y=y\wedge x$ | $x\vee y=y\vee x$ | DEF |
| $(x\wedge y)\wedge z=x\wedge(y\wedge z)$ | $(x\vee y)\vee z=x\vee(y\vee z)$ | DEF |
| $x\wedge(x\vee y)=x$ | $x\vee(x\wedge y)=x$ | PROOF |
| $x\wedge1=x$ | $x\vee0=x$ | DEF |
| $x\wedge0=0$ | $x\vee1=1$ | PROOF |
| $x\wedge(y\vee z)=(x\wedge y)\vee(x\wedge z)$ | $x\vee(y\wedge z)=(x\vee y)\wedge(x\vee z)$ | PROOF |
| $x\wedge\neg x=0$ | $x\vee\neg x=1$ | DEF |
| $\neg(\neg x)=x$ | 自对偶 | PROOF |
| $\neg(x\wedge y)=\neg x\vee\neg y$ | $\neg(x\vee y)=\neg x\wedge\neg y$ | PROOF |
| $(x\wedge y)\vee(x\wedge\neg y)=x$ | $(x\vee y)\wedge(x\vee\neg y)=x$ | PROOF |

### 结构层级与适用条件

- 格：只有 $\wedge,\vee$ 与序；对偶律成立；没有 $0,1,\neg$ 时，只对格语言中的项对偶。
- 有界格：加入 $0,1$；对偶交换 $0,1$。
- 分配格：分配律与它的对偶等价；对偶律仍成立。
- 布尔代数：加入补元 $\neg$；补元唯一；De Morgan、补律、双重否定成立。
- 完备布尔代数：任意并交存在；无限 De Morgan 律成立；一般布尔代数只有有限并交。
- 非分配格：分配律不成立，其对偶也不成立；对偶律仍保证“若原式成立则对偶式成立”，但原式本身不成立时就无从谈起。

### 逐条件分析

下表检查关键条件的作用；不是每条都必要，但改变后会得出不同结论。

| 条件或选择 | 作用 | 改变后的结果或反例 | 证据 |
| --- | --- | --- | --- |
| 格结构 | $\wedge,\vee$ 对偶 | 非格偏序集没有成对的 meet/join | DEF |
| 有界 | $0,1$ 可交换 | 无界格没有 $0/1$ 对偶 | DEF |
| 分配性 | 分配律及其对偶 | 钻石格 $M_3$ 中分配律失败 | PROOF |
| 补元存在 | De Morgan/补律 | 三元素链有界分配但中间元无补元 | PROOF |
| 布尔代数 | 补元唯一、对偶封闭 | 一般分配格不够 | DEF |
| 完备性 | 无限 De Morgan | 一般布尔代数不保证无限并交 | 入口 |
| 对偶方式 | 只换运算/常数 | 取反变量会得到不同式子，不是对偶 | DEF |
| 条件等式 | 假设也要对偶 | 由 $x\le y$ 推出的命题，对偶需假设 $y\le x$ | PROOF |

### 典型例

- 集合代数：$X=\{1,2,3\}$，$A=\{1\}$、$B=\{2\}$、$C=\{3\}$；分配律与对偶分配律都成立。DEF。
- 幂集布尔代数：$\wedge=\cap$、$\vee=\cup$、$0=\varnothing$、$1=X$、$\neg=$ 补集；De Morgan 律成对。PROOF。
- 命题逻辑：$\wedge=\text{AND}$、$\vee=\text{OR}$、$0=\text{false}$、$1=\text{true}$；De Morgan 律成对。PROOF。
- 二元素布尔代数 $\{0,1\}$：所有恒等式可用真值表验证；对偶式逐行对应。PROOF/FINITE。
- 开关电路：串联=AND、并联=OR；对偶电路把串并联互换、常开常闭互换。ILLUSTRATION。
- 三元素链 $0<a<1$：有界分配格，但 $a$ 无补元；补律不适用。PROOF。
- 钻石格 $M_3$：$0<a,b,c<1$，$a,b,c$ 两两不可比；分配律失败：
  $$
  a\wedge(b\vee c)=a\wedge1=a,\qquad
  (a\wedge b)\vee(a\wedge c)=0\vee0=0.
  $$
  故分配律及其对偶都不成立。PROOF。
- 自对偶：$x\wedge(x\vee y)=x$ 与 $x\vee(x\wedge y)=x$ 互为对偶；双重否定 $\neg\neg x=x$ 自对偶。PROOF。
- 线性代数零化子（同型现象）：有限维空间中 $(U+W)^{0}=U^{0}\cap W^{0}$，$(U\cap W)^{0}=U^{0}+W^{0}$；这是反序对偶，不是布尔代数恒等式。ILLUSTRATION。

### 非例与反例

- 把“对偶”理解成“全部取反”：$x\wedge y$ 的对偶是 $x\vee y$，不是 $\neg x\vee\neg y$。
- 三元素链：有界分配格，但不是布尔代数；中间元无补元，De Morgan 律无定义。
- 钻石格 $M_3$：分配律失败，故分配律的对偶也失败；说明“对偶律”不等于“所有格都分配”。
- 非格偏序集：不是任意两个元素都有 meet/join；对偶运算无从定义。
- 在一般环中把 $+$ 与 $\cdot$ 互换：不一定得到环公理；对偶律不适用。
- 无限集合的 De Morgan 律对集合成立，但一般布尔代数不一定有无限并交；不能无条件推广。
- 把条件 $x\wedge y=0$ 的对偶写成 $x\vee y=1$ 是语法上正确的，但它不是恒等式；若把它当假设使用，必须同时说明对偶假设。

## 论证、证明或解题

### 1. 对偶格（PROOF）

设 $L$ 是格。定义 $L^{d}$ 的序为 $x\le^{d}y\iff y\le x$。则：

- 自反、反对称、传递由原序继承。
- $x,y$ 在 $L^{d}$ 中的最大下界是 $x\vee y$（原 join），最小上界是 $x\wedge y$（原 meet）。验证：$x\vee y\le^{d}x,y$ 因为 $x,y\le x\vee y$；任何 $z\le^{d}x,y$ 即 $x,y\le z$，故 $x\vee y\le z$，即 $z\le^{d}x\vee y$。对偶类似。
- 故 $L^{d}$ 是格，且 $\wedge^{d}=\vee$、$\vee^{d}=\wedge$。

### 2. 对偶律（PROOF）

格的公理（幂等、交换、结合、吸收）在对偶下逐条不变或互换；因此若一个恒等式由这些公理推出，把证明中每一步对偶化，仍是从公理出发的合法证明，得到对偶恒等式。

语义证明：任取格 $L$。原恒等式在所有格中成立，特别在 $L^{d}$ 中成立；把 $L^{d}$ 的运算翻译回 $L$，就是 $L$ 中的对偶恒等式。因此对偶式在任意 $L$ 中成立。

布尔代数：补元 $\neg$ 在对偶格中仍是补元。因为 $x\wedge^{d}\neg x=x\vee\neg x=1=0^{d}$，$x\vee^{d}\neg x=x\wedge\neg x=0=1^{d}$；补元唯一，故 $\neg$ 在对偶中保持不变。于是布尔代数公理在对偶下封闭，对偶律成立。

### 3. 常见对偶对的验证（PROOF）

- 吸收律：$x\wedge(x\vee y)=x$。对偶：$x\vee(x\wedge y)=x$；由对偶律直接得到。
- 分配律：$x\wedge(y\vee z)=(x\wedge y)\vee(x\wedge z)$ 的对偶是 $x\vee(y\wedge z)=(x\vee y)\wedge(x\vee z)$；在分配格中二者等价。
- 补律：$x\wedge\neg x=0$ 的对偶是 $x\vee\neg x=1$；这是布尔代数两条补律。
- De Morgan：$\neg(x\wedge y)=\neg x\vee\neg y$ 的对偶是 $\neg(x\vee y)=\neg x\wedge\neg y$；可由补元唯一性证明。
- 双重否定：$\neg\neg x=x$ 自对偶；在布尔代数中由补元唯一性证明。

### 4. De Morgan 律的证明（PROOF）

要证 $\neg(x\wedge y)=\neg x\vee\neg y$。只需证 $\neg x\vee\neg y$ 是 $x\wedge y$ 的补元（补元唯一）。计算：

$$
(x\wedge y)\wedge(\neg x\vee\neg y)
=(x\wedge y\wedge\neg x)\vee(x\wedge y\wedge\neg y)
=0\vee0=0,
$$

$$
(x\wedge y)\vee(\neg x\vee\neg y)
=(x\vee\neg x\vee\neg y)\wedge(y\vee\neg x\vee\neg y)
=1\wedge1=1.
$$

故 $\neg(x\wedge y)=\neg x\vee\neg y$。另一条由对偶律或对称计算得到。

### 5. 非分配格反例（PROOF）

钻石格 $M_3$：元素 $0,a,b,c,1$，其中 $a,b,c$ 两两不可比，$a\vee b=a\vee c=b\vee c=1$，$a\wedge b=a\wedge c=b\wedge c=0$。则

$$
a\wedge(b\vee c)=a\wedge1=a,\qquad
(a\wedge b)\vee(a\wedge c)=0\vee0=0,
$$

故分配律失败；其对偶 $a\vee(b\wedge c)=(a\vee b)\wedge(a\vee c)$ 也失败（左边 $a\vee0=a$，右边 $1\wedge1=1$）。这说明“对偶律”并不保证分配律本身成立；它只保证原式与对偶式同真同假。

### 6. 条件等式的对偶（PROOF）

若从假设 $x\le y$ 推出某个结论，则对偶证明需要假设 $y\le x$。因为对偶把 $\le$ 反向；不能保留原假设而只对偶结论。对恒等式（无假设）没有这个问题；对条件命题，假设与结论要一起对偶。

## 应用

直接应用：集合恒等式。并与交、空集与全集、补集的恒等式成对出现；De Morgan 律、分配律、吸收律可直接对偶，减少记忆与证明。

直接应用：命题逻辑与布尔表达式。AND/OR、true/false 对偶；De Morgan 律用于否定范式、逻辑化简、可满足性转换（入口）。

直接应用：数字电路。串联/并联、常开/常闭对偶；对偶电路实现对偶函数；CMOS 门电路中的上拉/下拉网络对偶（入口，NOT-CLAIMED 工艺细节）。

间接应用：格论与序理论。任何格定理都有对偶版本；分配格、模格、Heyting 代数的对偶命题成对出现（入口）。

间接应用：数据库与查询优化。并/交/差、全集的补集；查询重写常用 De Morgan 与分配律的对偶（入口）。

间接应用：程序验证与形式化。布尔代数恒等式用于化简断言；对偶律减少证明工作量；SMT/BDD 中的对偶化简（入口）。

间接应用：线性代数零化子（同型现象）。有限维空间中 $(U+W)^{0}=U^{0}\cap W^{0}$、$(U\cap W)^{0}=U^{0}+W^{0}$ 是反序对偶；与布尔对偶共享“反转序、交换并与交”的结构，但不是同一组公理（入口，详见 [[线性空间]]、[[内积]]）。

条件匹配：使用对偶前确认结构是格/布尔代数/完备布尔代数；确认是否有 $0,1,\neg$；确认是恒等式还是条件等式；确认无限并交是否存在；不要把线性代数零化子与布尔恒等式混为一谈。

## 推广与联动

- 与格论：对偶格 $L^{d}$；对偶律是格论元定理；分配格、模格、有界格各有对偶版本（入口）。
- 与布尔代数：补元唯一；De Morgan、补律、双重否定成对；Stone 表示定理把布尔代数表示为集合域（入口）。
- 与集合论：幂集布尔代数；并与交、空集与全集、补集的对偶；无限 De Morgan 需要任意并交。
- 与命题逻辑：AND/OR、true/false 对偶；De Morgan 律；否定范式；对偶式与对偶函数。
- 与数字电路：串联/并联、常开/常闭对偶；对偶电路；逻辑综合中的对偶化简。
- 与范畴论：反范畴 $C^{op}$ 是“对偶”的范畴版本；对偶律是“把箭头反向”的特例（入口）。
- 与线性代数：有限维空间中零化子 $U^{0}$ 反向包含；$(U+W)^{0}=U^{0}\cap W^{0}$、$(U\cap W)^{0}=U^{0}+W^{0}$；与布尔对偶同型但不同对象（详见 [[线性空间]]、[[内积]]）。
- 与投影几何：点/线互换的对偶原理；与格对偶共享“交换对偶对象”的思想（入口）。
- 与线性规划：原问题/对偶问题；弱对偶/强对偶；这是另一套“对偶”，不要与布尔对偶混淆（入口）。

## 误解、试错与启发

以下为常见误区的校准，不含某位学习者的个人经历；个人试错待作者补充。

1. 误区：“对偶就是全部取反。”原因：把对偶与否定混淆。检验：$x\wedge y$ 的对偶是 $x\vee y$，不是 $\neg x\vee\neg y$；变量不变。
2. 误区：“对偶要交换 $\neg$。”原因：把补运算当成普通运算。检验：$\neg$ 保持不变；补律的两条互换。
3. 误区：“对偶时不等号方向不变。”原因：忽略序的反转。检验：$x\le y$ 的对偶是 $y\le x$。
4. 误区：“任何格都有 $0,1,\neg$。”原因：把布尔代数当成格的定义。检验：三元素链有界但中间元无补元；无界格没有 $0/1$。
5. 误区：“De Morgan 律对任何格都成立。”原因：忽略补元存在。检验：没有补运算的格中，$\neg$ 无定义；补律不适用。
6. 误区：“分配律对所有格都成立。”原因：把分配格当成格。检验：钻石格 $M_3$ 分配律失败。
7. 误区：“对偶式与原式总是等价。”原因：忽略条件/假设。检验：条件命题的假设也要对偶；$x\le y$ 下的结论与 $y\le x$ 下的对偶结论对应。
8. 误区：“对偶恒等式是新的独立定理。”原因：忽略元定理。检验：对偶式由对偶律自动推出，不需要重新证明。
9. 误区：“$x\wedge y=0$ 的对偶是 $x\vee y=1$，所以它总是成立。”原因：把语法对偶当成恒等式。检验：$x\wedge y=0$ 不是恒等式；只有满足该条件的 $x,y$ 才有对偶条件 $x\vee y=1$（在布尔代数中）。
10. 误区：“布尔代数与布尔环的运算符号可以随意互换。”原因：忽略 $+$ 是 symmetric difference，不是 join。检验：布尔环中 join 是 $x+y+xy$，meet 是 $xy$；对偶需要翻译，不能只换 $+/\cdot$。
11. 误区：“无限 De Morgan 律对任何布尔代数都成立。”原因：忽略完备性。检验：一般布尔代数只有有限并交；无限版本需要完备布尔代数。
12. 误区：“线性代数零化子恒等式就是布尔对偶恒等式。”原因：同名“对偶”但不是同一结构。检验：零化子反序、交换子空间和与交；布尔对偶交换 $\wedge/\vee$、$0/1$；两者是同型现象，不是同一条定理。

<!-- mcs-section:summary -->
## 思想与方法总结

思想：

- “对偶 = 镜像”：交换 $\wedge/\vee$、$0/1$、$\le/\ge$；变量与 $\neg$ 不动。
- “对偶律 = 元定理”：证明一个恒等式，免费得到镜像；格/布尔代数的公理在对偶下封闭。
- “结构层级决定可用符号”：格、有界格、分配格、布尔代数、完备布尔代数逐层增加 $0,1,\neg$、分配性、无限并交。
- “对偶不是否定”：不要把变量取反；不要把条件假设丢掉。
- “同型不等于同一”：线性代数零化子、投影几何点线对偶、线性规划对偶都是“对偶”，但对象与定理不同。

方法（注明使用位置）：

- 对偶项递归：语法层面交换运算/常数（精确内容）。
- 对偶格：语义层面反转序（论证 1）。
- 公理对偶：证明对偶律（论证 2）。
- 补元唯一：证明 De Morgan/补律（论证 3–4）。
- 反例法：三元素链、钻石格（精确内容、论证 5）。
- 条件对偶：假设与结论一起对偶（论证 6）。
- 跨领域解释：集合、逻辑、电路、零化子（应用、联动）。
