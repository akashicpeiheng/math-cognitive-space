## 性能实测

Windows、本机 Node 24、Chromium headless；一次本机观测，不代表所有设备上的性能承诺。混合测试使用两个库共 900 篇笔记及 100 个公共节点，包含笔记引用、目录索引和刷新恢复。

| 观测 | 实测 |
| --- | --- |
| 混合图布局与索引（含测试中的导航、刷新及就绪等待） | 7,214ms |
| 混合图缩放与圆点就绪 | 606ms |
| 笔记聚焦到悬停可见（含悬停延迟） | 532ms |
| 静置 1.2 秒 | 坐标相同，长任务 0 |
| 原有 400 节点性能回归：首次铺开 | 5,238ms，预算内 |
| 原有性能回归：重新布局 | 584ms，预算内 |
| 原有性能回归：增量加入 | 1,138ms，预算内 |

大于 600 节点的自由布局使用确定性的连通分量遍历和网格摆位，以限制布局成本；小图保留原有限迭代布局。动画结束后停止更新。截图 `tmp/network-mixed-preview.png` 已人工查看；它展示圆点网络和可移入的笔记说明。

## 尚未验证

- 未在实体触屏设备、Safari 或 Firefox 上操作；双指与窄屏覆盖来自 Chromium 自动化，不能代替实体设备验收。
- 未对 2,000 节点做浏览器性能基准；上限与超限拒绝已测，大规模实测为 1,000 节点。
- PostgreSQL 语义与 SQL 路径由 PGlite 覆盖，未验证远程 PostgreSQL 的网络中断、连接池及运维恢复。
- 未把两端均来自私人笔记的新投稿实际发布到用户的公共站点。隔离测试覆盖候选衔接与假发布拒绝，真实发布与回滚由已有四案例端到端夹具覆盖。
- 没有进行所有笔记摘录与原文对应、所有公共动机文本和全部译文质量的人工数学审校。界面保留来源、未译状态、人工对应确认及未判定，不能将浏览器通过或有限模型检查表述为一般数学证明。
