# MCS 数学地图概念星座验收 · 2026-11-16

## 1. 目标与范围

在数学地图放大到专题内的对象层时，把对象标签升级为**概念星座**：

- 核心概念居中；
- 相关概念成组；
- 可见对象之间画出主要的 M 层数学关系；
- 右侧详情列出该对象的主要关系（含跨专题），可跳到对方或在对象网络查看完整证据。

本次以「微分形式与外微分」为精选示例，同时提供通用关系布局；不新增形式对象、不修改 M/L 关系、不改变对象身份与对象网络。

## 2. 事实基线

- 专题节点：`atlas:object:obj:tdg:topic-exterior-calculus`，9 个对象子节点：`forms`、`exterior`、`hodge`、`insertion`、`d-squared`、`curl-grad`、`div-curl`、`formal-adjoint`、`vector-realization`。
- 专题 12 个成员（含 `gradient`、`divergence`、`curl`，主要归属在其他专题）；专题内部 21 条关系。
- 9 个可见子节点之间的主要关系（deduction/application）共 5 条：
  - `rel:tdg:apply-exterior-curl-grad`：application，`exterior → curl-grad`
  - `rel:tdg:apply-exterior-div-curl`：application，`exterior → div-curl`
  - `rel:tdg:deduce-d-squared-exterior`：deduction，`exterior → d-squared`
  - `rel:tdg:derive-vector-realization-exterior`：deduction，`exterior → vector-realization`
  - `rel:tdg:derive-vector-realization-hodge`：deduction，`hodge → vector-realization`
- 可见子节点内部关系度：`exterior` 4、`vector-realization` 2，其余各 0–1；含外部关系时 `exterior` 10。核心取 `exterior`（外微分 d）。

## 3. 设计

### 3.1 精选星座

新增 `shared/mcs-atlas-relations.mjs`：

- `MCS_ATLAS_CONSTELLATIONS` 只放稳定、关系充分的专题；当前是「微分形式与外微分」：
  - 核心 `obj:tdg:exterior`；
  - `d2-zero`「d² = 0 家族」：`d-squared`、`curl-grad`、`div-curl`；
  - `form-ops`「形式运算」：`forms`、`hodge`、`insertion`；
  - `vector-analysis`「向量分析」：`vector-realization`、`formal-adjoint`。
- 分组标题是阅读导航，不是数学分类；缺成员/缺核心时逐项跳过，核心回退到关系度最高者。
- 其他专题：`constellationFor` 返回 null；`arrangeConstellation` 用通用布局（核心 + 按关系种类分扇区）；没有主要内部关系时返回 null，保留 `scatter`。

### 3.2 布局

`createMcsAtlas` 只对「子节点全部是正式对象」的父节点尝试星座；先按原 `scatter` 比例确定子节点尺寸，再应用星座位置：

- 核心 `(0.5, 0.46)`；
- `d2-zero`：`(0.26, 0.78)`、`(0.50, 0.86)`、`(0.74, 0.78)`；
- `form-ops`：`(0.18, 0.28)`、`(0.34, 0.18)`、`(0.14, 0.46)`；
- `vector-analysis`：`(0.78, 0.22)`、`(0.86, 0.44)`。

子节点盒尺寸不变，全部在父盒内；对象数组/成员反转后布局逐字相同；每个正式对象仍只出现一次。

### 3.3 关系层

`relationEdgesForObjects` 只取 `deduction / application / scaling / duality`，端点都在当前可见对象集合内；同一有向对去重，保留最强 kind，最多 12 条：

- 当前专题 5 条；颜色：推导红、应用金、放缩蓝、对偶品红（浅/深两套）；
- 二次贝塞尔曲线 + 箭头；`pointer-events:none`、`aria-hidden`；
- 只在「包含视点中心、对象子节点齐全、屏幕至少 220×160px」的最深父节点上启用；专题盒超过视口约 1.6 倍后收起；
- 底部图例只在关系层可见时出现；不常驻边标签，完整关系名在详情里。

### 3.4 详情与手机

- 右侧详情新增「主要关系」：该对象全部 M 关系（含跨专题），最多 6 条；点击对方飞到对应对象；完整证据仍走「打开对象与关系」。
- 详情固定停在底部工具条之上，长内容在面板内滚动。
- 390px：隐藏分组标题与图例；只保留核心名、可点的对象点与箭头；点对象打开详情读名称与关系。
- 核心标签带「核心概念」标记；专题自身的区域名在星座模式下隐藏，避免压住分组。

## 4. 数据边界

- 精选分组与关系层属于 D 层导航：不新增形式对象、成员关系或数学关系，不进入 L 阅读库，不写 E。
- 地图只画专题内部主要关系；跨专题关系只在详情中列出并跳转，不复制节点。
- 没有主要内部关系的专题保持原有散布；关系层不改变对象身份、`contentHash`、`objectVersion`。
- 8 领域、26 交叉入口、亲和面积、`field/4` 分享协议未改。
