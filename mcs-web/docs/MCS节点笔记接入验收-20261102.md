# MCS 节点笔记接入

MCS 圆点通过明确登记的对象 ID 接入网站现有的节点笔记。单击保留对象与关系查看；双击圆点或按 N 直接阅读，F 聚焦，专题双击继续展开。详情提供可点击的阅读入口，窄屏使用同一入口。

64 个非组织对象均有阅读入口：36 个优先使用已有 NodeRecord 笔记，其余使用精确版本引用的公共阅读节点。覆盖范围较大的笔记标为章节；仅覆盖特例的笔记放在相关内容中，例如协变张量场不能替代一般张量场，紧 Hausdorff 推出仿紧的旧笔记不能替代一般紧空间的结论。

`mcs-note-links/1` 是 API 新增的只读导航投影，不表示形式同一性、证明或先修关系。不修改正式 M/L 内容、既有身份或形式哈希。目标笔记缺失或正文为空时回落到已登记公共讲解，不按标题猜测关联。

笔记页与普通／Master 阅读模式提供返回入口；同一会话保留原图地址、层级、相机、筛选、选中项与拖动坐标。旧分享和本机状态继续沿用原迁移机制。

验收记录在 `_ops/records/mcs-notes-20261102-*`，包括构建、接口／单元、浏览器、候选与正式域名检查。结构和导航验证不代表笔记数学内容已人工审阅或证明通过。
