# Master 阅读模式

2026-10-19。入口在全站顶栏「阅读 → Master」，选择「普通」恢复完整阅读。

## 使用与边界

- 模式适用于公共节点、形式对象、独立阅读节点、列表和网络预览。个人笔记不参与压缩。
- 默认普通模式；偏好保存在当前浏览器 `mcs-reading-mode-v1`，跨页面、语种和刷新保持。存储不可用时仍可在当前页面切换。
- Master 以形式表达、条件、等价表达和紧凑证据状态为主体。鼠标悬停 `i`、键盘聚焦或触屏点击可查看一句直觉；Escape 或点击外部关闭。
- 教学章节与节点页的学习操作不挂载。Master 节点页也不挂载普通阅读的学习控制器，因此不会推进路线进度、发起学习确认或保存笔记。
- 同名对象的登记变体分别展示。不同约定不视为等价；证明节点保留目标、开放假设和已登记证书状态。
- 已核对的重复登记可在 `MASTER_REDUNDANT_REGISTRATIONS` 中折叠；来源继续合并保留，旧 ID 仍由本体别名解析。紧致性的重复开覆盖定义和流形的相同约定登记采用此规则，不自动判定任意两段文字等价。
- 缺少完整形式的条目标记「登记摘要 · 待核验」。原有数学表述、来源及机器检查的真实性仍需按既有证据范围判断。

## 内容与接口

内容起草可使用 [大师模式节点 AI 写作提示词](../../MCS_vault/MCS/template/MCS大师模式节点AI写作提示词.md)，支持已有节点压缩和新节点待审稿。提示词输出需经审阅与登记，不会自动导入展示投影。

`data/master-content.mjs` 是公共展示资料的编辑入口，包含条件敏感条目的覆盖规则、精确对象锚点的数学记法、短直觉、按稳定 ID 指定的正文节与条件选择。修改这些资料后需提升 `MASTER_CONTENT_VERSION`。

`shared/master-view.mjs` 生成 `mcs-master-view/1`：主表达、条件、已有等价式、一句直觉、状态、来源、缺口和准确对象引用。正文选择经过 Markdown AST，只读取登记的正式小节，不包含其后的子节，也不收集证明中的全部公式。「等价表达与类别」仅选明确标记为等价表达的条目，类别说明不自动变成等价式。

自由文本 `note` / `boundary` 经常混有证明概括、删条件的教学反例及推广，不能整块当作必要条件。投影保留类型化假设、声明中的符号定义，以及登记表明确选取或压缩的必要语境。旧 Markdown 的不规范公式分隔符也不能使选段越过下一标题。

旧节点详情新增 `node.master`，旧列表和图接口的节点新增紧凑 `master`；新对象和阅读列表条目新增 `master`，详情在响应顶层新增 `master`。旧字段继续有效。展示缓存按原版本、语种、压缩资料版本及稳定身份区分；不改 M/L Markdown、形式摘要、对象版本或个人数据。
