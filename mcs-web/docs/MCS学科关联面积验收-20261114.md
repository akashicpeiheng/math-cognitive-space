# MCS 学科关联面积 · 2026-11-14

后续子级交叉领域的方向布局和 `field/4` 见 [交叉领域邻接布局验收](MCS交叉领域邻接布局验收-20261114.md)。本页保留 `field/3` 面积分配版本的实现与验收。

## 行为

切换核心子学科时，外围学科按与新核心的关联权重重新分配面积。核心保持突出，外围强关联扩大、弱关联相对缩小，同一个外围区域的位置与宽高沿现有阻尼动画连续变化。色域仍相互交融，子项仍是局部地标，弱关联入口保持可见。

例如，以代数为核心时，数论的外围区域比概率统计大；切换为分析核心时，概率统计从较小区域连续扩大。该示例描述当前地图设定，不是对全数学的固定关联排名。

## 标定与边界

- 权重由 `shared/mcs-atlas-affinity.mjs` 集中配置，对现有 26 个交叉入口作首版导航标定。强、一般、弱分别取 `1.8 / 1 / 0.55`，未标定取 `0.85`；同一领域对使用对称权重。
- 权重是可调整的 D 层展示设定。来源支持交叉方向的存在与内容，不直接支持这些强弱等级或数值。没有把已收录对象的多少当作关联强度；现有内容集中在少数学科时，其他区域也不会因此消失。
- 未登记交叉入口的配对不推断为弱关联；保留未标定状态、正的基准面积，且不编造交叉内容。悬停外围学科可见等级及已有交叉入口名，交叉详情也显示等级。
- 核心包围框保持 `1080 × 740`。设外围数量为 n，分配总预算 `B = n × 120000`，第 i 个外围包围框面积为 `A_i = B w_i / Σw`。宽高分别按面积权重平方根缩放，强/弱包围框面积比约为 `3.27∶1`；渐变色域重叠，实际视觉面积不作精确计量。
- 增大的区域适度向内靠拢，并保持导航包围框在地图范围内。横竖布局使用相同权重；成员身份、顺序、正式哈希、M/L、个人学习记录及关系备注均不由这些权重改写。镜头与核心选择仍按地图自身协议保存在本机。
- 分享与保存升级为 `field/3`。旧 `focus/1` 和 `field/2` 保留核心选择并适配新全景，避免用旧镜头坐标误定位；当前版本继续保留往返、刷新和跨屏分享行为。

作为首版标定的交叉背景，核对了 [MIT 代数与代数几何](https://math.mit.edu/research/pure/algebra.html)、[MIT 几何与拓扑](https://math.mit.edu/research/pure/geometry.html) 及 [Oxford 随机分析](https://www.maths.ox.ac.uk/groups/stochastic-analysis) 等公开介绍。每个交叉入口的具体来源仍在 `shared/mcs-crossfields.mjs`。上述介绍说明相应研究方向如何衔接，不提供全领域的强弱测量。
