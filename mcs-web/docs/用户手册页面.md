# 用户手册页面（2026-10-13）

学习者的操作说明放在 `/manual`（英文 `/en/manual`），游客可直接阅读。

## 结构

| 位置 | 内容 |
| --- | --- |
| `web/src/manual-content.ts` | 正文（中英成对，纯数据，不引入 React、不读接口） |
| `web/src/pages/ManualPage.tsx` | 渲染：五段结构（解决什么问题 → 从哪里进入 → 怎样操作 → 会得到什么 → 容易误解什么）+ 证据标签表、网络手势表、路线入口表、进阶卡、FAQ |
| `web/src/styles.css`（`manual-*` 段） | 桌面「正文 + 右侧吸附目录」，窄屏顶部可展开目录；章节 `scroll-margin-top` 避开吸顶栏 |

入口共五处：侧栏「按需查阅」首位、开始学习页顶部、网站介绍页按钮、手册首屏的两个页内入口
（跟着案例上手 / 按功能查阅）。

## 约定

- **不写数量、配额与服务在线状态**：正文只描述「在哪里看、怎么用」，数字以页面现场提示为准。
- **操作名称按当前界面逐条核对**（2026-10-13），例如节点菜单里是「从视图移出」、
  路线页是「沿此路线阅读」与「看结构回放」、笔记库是「选择 Obsidian 库」「重新扫描」
  「上传到我的账号」「导出笔记库」。界面改名后手册要同步改，否则 `tests/manual-page.mjs`
  与 i18n 扫描都不会替你发现措辞漂移。
- **锚点即契约**：章节 id 是 `manual-<section.id>`，中英共用同一批 id；
  切换语言由 `switchLocalePath` 保留 hash，因此换语言后仍停在同一章。
- **手册不写任何记录**：页面不请求写接口，阅读、点目录、展开 FAQ 都不产生学习事件。

笔记库一节已同步创作入口、章节引导、全文/预览、暂存与版本、三种提示词、旧稿复制及账号工作副本；中英正文来自同一结构。详细操作与失败恢复见[创作使用与迁移说明](writing/创作使用与迁移说明.md)，实际验收和剩余边界见[创作环境交付与验收记录](writing/交付与验收记录.md)。

## 验证

```
npm run build
npm run check
node tests/manual-page.mjs                     # 入口、锚点、双语、窄屏、不写记录
node scripts/i18n-ui-scan.mjs --path /en/manual # 英文页无未标注中文
npm test
```

未覆盖：文案质量与数学表述的人工复核仍归人工；页面上引用的功能行为由各功能自己的测试守护，
手册只核对入口、锚点与承诺（不写记录）仍然成立。
