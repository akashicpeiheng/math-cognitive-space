## 全量测试的明确限制

默认全量在“Lean 登记、真实证明、持久化任务与进程树取消”阶段，首个真实登记重放约 123 秒后失败。保留日志后停止了这次已失败的运行及其子进程，未继续等待该阶段的其他长时间负例。全量结果不能写成全部通过。

随后单独运行：

```powershell
node --test --test-concurrency=1 --test-name-pattern='real Lean: all registrations replay' tests/lean-live.test.mjs
```

单项复现相同失败：lean-group-injective 的 target_audit 返回 EVIDENCE_RESOURCE_EXHAUSTED，reason=timeout；约 123.4 秒。它属于资源时限，不是命题被反驳。本轮没有改动 Lean 工程、登记、核验逻辑或生产时限，也没有为此延长证明验收预算。

全量前段日志位于 runtime/mcs-qa-full-test.log，单项原因位于 runtime/mcs-qa-lean-isolated.log。MCS 主流程与连续操作分别输出 runtime/mcs-qa/acceptance.json、review.json。
