# MCS 数学地图验收 · 2026-11-13

## 连续色域与动画（2026-11-13 版本）

后续新增的核心关联面积分配、`field/3` 与对应验证见 [2026-11-14 关联面积验收](MCS学科关联面积验收-20261114.md)。本页保留连续地图底图及此前版本的验收过程。

用户要求取消“一块块”的分区，以及少数内容平分整个区域的表现。当前版本用相互渗透的渐变色域展示学科；下方早期验收中的矩形分区、严格接壤和 `focus/1` 是历史实现，已被本节取代。

- 八个粗领域仍可选核心，外围保持可达；子分支与已收录对象作为局部地标，不占满父区域。单个子项的导航包围框不超过父框边长的 36%，全部子项包围框面积之和低于父框的 49%；这些是留白约束，不是数学覆盖率。
- 色域边缘渐变到透明，容许重叠。相关分支根据已有交叉入口朝对应领域偏移；此布局没有声称拟合了经过测量的“数学距离”。26 个有来源的交叉入口仍可打开，窄屏文字避让，空间不足时显示标记。
- 核心切换对同一对象的位置、尺寸使用临界阻尼过渡；滚轮使用对数尺度阻尼，并在每帧保持指针锚点。拖动直接跟手，单指释放使用指数减速；双指缩放或取消手势不触发惯性。新输入可立即打断镜头；静置停止动画。
- 动态监听系统减少动画偏好，开启后完成当前过渡，后续定位即时生效。保存与分享升级为 `field/2`；旧 `focus/1` 视角保留核心选择并回到新布局全景。
- M/L 原文、正式对象身份、成员引用、形式哈希以及 E 层个人关系备注未由此改动。布局单测仍核对公共输入不变和每个正式对象只出现一次。

## 交付行为

`/mcs` 和 `/en/mcs` 默认展示数学地图。全景为八个粗领域；滚轮围绕指针连续缩放，分支区域和其中的真实专题、对象逐层变大、展开。支持拖动、原生双指缩放、点击深入、返回上层、搜索、键盘操作及分享。

手机使用竖向分区，旋转和跨屏分享转换镜头中心。缩放控件单独留出空间，短横屏仍在可视区域内。点击正式对象可进入原对象网络，浏览器返回保留地图视角。

原对象网络入口为 `?view=objects`。旧 `#mcs=` 分享及笔记返回协议保持兼容；新增 `#atlas=` 仅包含公开地图的相机、窗口尺寸和布局方向。

## 数据边界

- 导航属于 D，仅供探索，不声称数学领域分类完整、唯一或互斥；分区面积不表示重要性。
- 正式对象只按精确 ID 和有效成员引用连接。现有 77 个正式对象各出现一次，交叉关系仍在原对象网络查看；未知对象保留独立入口。
- 没有收录对象的分支明确说明状态。导航分区不计作正式数学对象，不生成数学关系。
- 未修改公共 M/L、形式哈希、内容版本或个人关系备注存储。
