问题是可选写作资源，不是必填正文。完整指完成本篇承诺；缩短篇幅不能牺牲数学精确性。

## 学习节点、形式对象与个人笔记

L 组织阅读目标和讲解，M 固定形式声明与五级尺度。一个节点可以跨尺度引用多个对象，同一对象可以有多篇讲解。方法论节点可用 objects: []，但不能提供对象层的形式证据。

公共接口为一个顶层 mcs-node JSON 块：schema=mcs-node/1、id、version、title、goals、objects，可选 prerequisites。ObjectRef 包含 id、version、anchor、formalHash；anchor 使用稳定声明锚点或代表整个对象的 $。不得从标题猜测引用；从内容库取得准确引用，形式修订经核对后由维护工具更新摘要。

“精确内容”负责忠实复述并定位引用的声明及假设，不重新定义 M。尚未登记的数学材料如实注明，不能虚构对象引用。证明讲解与机器证明分别标注证据状态。

可复制文件见[模板目录](../../../mcs-content/templates/README.md)。公共新稿须使用独立身份和准确版本；占位符草稿留在 objects/、nodes/ 之外，填写模板不等于获得认证。

mcs-learning-node-template 及其版本描述写作约定，不是文档 ID 或协议版本。旧 mcs-object-note 标识继续可编辑；现有私人创作保留 YAML 与章节标记，不自动添加 mcs-node 块或公共身份。个人经历与写作进度留在 E；显式升级先预览并保留原文。

## 先判断适用性，再检查完成度

默认四项核心义务：对象与任务、背景与约定、精确内容、依据与边界。角色可以组合。展开模块可以指向已有段落、加入、省略或保留适用性疑问；深度长文选择完整资源库，并不把每个建议变成配额。

- 适用
- 不适用
- 本篇不展开
- 尚未确定

不适用简述理由，正文可不留空标题；本篇不展开可给引用入口；尚未确定保留具体问题。适用性与写作／自检状态独立。核心义务及已作出的数学承诺不能豁免，可以指向同篇其他章节避免重复。“已有内容”仅度量文字覆盖。

本节点尚无完整的专用检查。当前仅核对数学核心及已选角色，不代表覆盖全部数学义务。请检查代表元或辅助选择依赖、“相同”的等价层次，以及定义、猜想和已证结果是否混合；可补充本对象独有的问题、组合角色或拆分节点。

识别旧标题与章节标记。升级先预览，保留原文，仅补选中的缺失内容；旧“不适用”按范围决定读取。ima 生产流水线仍使用独立固定标题契约，本指南不切换生产配置。

## 共同原则

- 本模板组织公共学习节点 L 的讲解；定义、定理、证明等是呈现角色，不决定数学尺度。私人创作继续属于 E，不自动生成公共身份。
- 精确内容须忠实复述并定位所引用 M 的声明，保留全部相关假设。保留给定对象 ID、版本、声明锚点和形式摘要，不编造或猜测引用；缺失时明确列为待补。
- 公共 L 不收录个人经历、掌握状态或私人写作进度；个人试错仅能在 E 中基于本人材料记录。自检状态不等于机器证明或人工对应审阅。
- 完整指完成本篇承诺：对象与任务、背景与约定、精确内容、依据与边界不可缺；可由同一段正文承担多项义务，不按栏目数量认证数学。
- 先用简洁自然语言说明问题与价值，再给精确内容；动机可只有一句。历史、多路径、生长链、直觉、应用、迁移和总结按需展开，不强制数量、独立章节或第二种证法。
- 选中章节中的提问仍是写作资源，无需逐题回答；数学核心与实际作出的断言必须交代，不能把可选深化变成新的完成门槛。
- 不能通过省略改变数学含义。定义约定标 DEF；构造的存在与良定义、宣称的唯一性须另有依据，说明相等、同构等意义。
- 条件分析是调查：允许反例、冗余、相互依赖、表达失去意义或待查；不预设每个充分条件必要。反例须满足其余前提并否定精确目标。
- 关键断言标 DEF / PROOF / REF / FINITE / ILLUSTRATION / NOT-CLAIMED，并给核对入口。未知可保存，不自动认证定义、定理、构造或算法；个人不会证明不等于公开问题。
- 尊重结构化写作范围；不适用或本篇不展开的模块不补写、不作为缺章，尚未确定时只提出针对性问题。豁免栏目不能豁免已作出的数学承诺。
- 所选角色可以组合，模板不能保证覆盖陌生对象；发现正文中额外的数学承诺时指出检查缺口，不静默更改角色或套入完整长文。
- 历史与现代教学重构分开，生长过程允许分叉与竞争定义。直觉可以是局部对应，不能替代证明或默认成为等价。
- 不编造文献、人物年份、证明、验证记录和学习者经历。个人试错仅来自本人材料，无材料就省略；未知只保留实际存在的疑问。
- 输出完整 Obsidian Markdown，公式和段落不截断，不用整篇代码围栏，正文无文献角标；实际使用的参考文献集中在文末，不为凑数编来源。
- 私人成稿不自动写公共本体关系、学习者掌握记录或一般教学效果结论。

## 可组合的角色与数学义务

### 通用：暂未分类

先明确对象与任务。尚无完整专用检查时显式提示缺口，可组合角色或补充本对象独有的问题。

说明本篇任务与已有角色，尚未识别的角色保持未定。

### 定义

分析每个条件的作用，允许约定、冗余或待查；按需选择典型例、非例与等价表达；宣称的等价须有依据。构造型定义另核查存在与良定义；若宣称唯一，说明等同关系，约定标 DEF。

能逐条读回定义；没有用动机代替良定义或存在唯一性。

### 定理

写清量词、背景、联合假设与结论，给出证明或可定位引用。展开证明时先概括机制，再给细节与条件使用位置。逐条件删减可按目标深化，记录反例、冗余、依赖、表达失去意义或待查，不预设必要性。

前提与结论精确，证明或引用可定位；条件作用的未知不冒称查明；若给反例，验证其余假设。

### 公理

说明所属理论、公理还是模式、希望约束什么，将采用的约定与关于理论的断言分开。模型、删改后的结构、相容性、独立性与冗余性按目标展开；若作断言，各自给证据，未知不能当作已证明。

没有把采用公理写成普遍真理；若讨论独立性与相容性，分别说明证据状态。

### 性质

明确承担对象、参数与性质谓词；区分性质谓词与已证性质命题；说明所用判据、变换及证据。谓词的非例不能冒充已证命题在全部前提下的反例。

若声称变换保持性质，写明变换及证据；没有把名称“不变量”当作保持性证明。

### 推论

定位上游结果，逐项匹配假设，写出代入、限制、组合等动作与简短推导。可引用上游动机和证明资源，无需另写历史、应用或效率比较。

上游结果与条件匹配可定位；写清产生推论的动作。

### 习题

先写题目、目标、可用条件。若给解答，先概括策略再展开，并核查答案满足原题；未解草稿保留卡点。按需比较失败路线、保底方法或提炼技巧，不编造经历。

解答与未解部分区分；已给出的解答须有依据，个人失败经历只来自本人材料。

### 技巧

给出任务、操作步骤、合法条件与适用范围。识别线索、首选路线、保底手段和迁移任务按学习目标选择；记录已知失效场景或未知，不假定总有保底方法。

步骤与合法条件可核查；局部有效不冒称通用，未知边界如实保留。

### 具体对象 / 概念

给出可辨识或可重现的对象规格、参数及约定，区分对象与关于它的命题。

名称不能替代对象规格；性质断言另给证据。

### 记号 / 约定

写明含义、作用域、参数和与其他约定的差别；命名标 DEF，不要求独立历史或应用。

区分记号约定与数学存在断言。

### 构造

说明输入与输出规格，核查存在性、良定义与选择依赖；若宣称唯一，说明是相等、同构还是其他意义。

商上的运算须核查代表元无关性；未知可保存探索稿，不能声称构造已建立。

### 证明

定位目标命题、背景、开放假设和引用资源；先概括机制再给论证或准确引用。

省略细节须标明，不能省略改变命题的假设；不强求第二条证法。

### 例子

给出可重现的对象，定位它例示的定义或命题，验证相关条件，区分典型特征与偶然特征。

例子本身的满足性可证明；单个例子不证明一般命题。

### 反例

写出被否定的精确句子和量词，重现对象，验证其余前提，给出结论失败的具体见证。

非例不自动是反例；说明未否定的范围，不要求独立历史和应用。

### 算法 / 计算方法

写明输入输出、合法步骤和适用范围；若宣称终止、正确、复杂度或误差保证，分别提供证明或引用。

区分精确与近似、部分与全定义；试跑成功不证明终止或一般正确性。

### 猜想

写清候选命题、量词与背景，区分支持例、已证部分和未知；不要求补出完整证明。

猜想不是已证定理；“我不会证明”不等于公认公开问题。

### 问题

写清任务、约束、解的规格及已知进展；公开状态有来源与核验日期，个人疑问另列。

保留未知与可检验的下一步，不强迫给出解或虚构失败经历。

### 表征 / 类比

说明表示什么、对应关系、保持与丢失的信息，以及使用范围；局部直觉不要求覆盖全部形式要素。

不能默认对应是双射、同构或等价；若有此断言须另证。

### 理论综述

界定组织范围、语言与基本约定，给出主要对象、命题、关系及引用入口，不把整个理论写成单一对象的证明。

目录不穷尽理论后果；联系注明方向与依据。
