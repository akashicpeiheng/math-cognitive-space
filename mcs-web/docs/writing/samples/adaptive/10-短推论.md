# 整数范围内的平方不等式

<!-- mcs-section:overview -->
## 对象与任务
把相邻样稿的实数结果直接用于整数，不另写发现史。

<!-- mcs-section:background -->
## 背景与约定
取整数 n，且 n 大于等于 2；把整数看作实数。

<!-- mcs-section:form -->
## 精确内容
结论：n 的平方大于 1。上游命题为本组样稿《删条件不一定产生反例》中“实数 x 大于 1 则平方大于 1”。

<!-- mcs-section:argument -->
## 论证、证明或解题
概括：检查前提并代入。整数 n 大于等于 2，故 n 大于 1；令上游命题中的 x 等于 n，立即得到结论。上游证明可在同组第二篇的论证节定位，无需在此重复。
