# 节点模板适配记录

日期：2026-10-15（Asia/Shanghai）。版本：`mcs-object-note@2026-10-15.1`。

## 行为与边界

新建稿默认四项数学核心，按角色选取论证资源；角色可组合。历史、直觉、迁移等作为按需展开资源保留，深度长文可以使用全套。适用性与写作状态独立，文字覆盖分核心与选中展开统计，不代表数学认证。

AI 整篇起草、章节辅助、审校均尊重不适用与不展开；未知只触发具体问题。角色义务不会因省略栏目而消失。章节辅助携带完整数学上下文，避免只读简介而漏掉命题条件。审校区分数学缺口、证据缺口与可选深化。

同篇承载可以复用已有章节，缺失、重复、循环引用不计完成。陌生角色和未知章节标识保留并提示检查范围不足。作者可补独有问题，模板不宣称自动识别所有数学承诺。

## 案例与证据

`samples/adaptive/` 包含记号、冗余条件、混合例反例、商上的构造、个人问题、候选猜想、算法、表征、陌生角色、短推论和理论组织，共 11 篇。

- 记号与组织范围是 DEF；小型数学推导的证据在各篇正文，不冒称机器证明。
- 算法样稿分别交代取余合法性、不变量、整数下降终止与结果正确性；未主张复杂度界。
- 猜想样稿明确只有有限样本；个人问题不宣称公开未解。
- 全部数学公式经 Markdown 数学语法提取及 KaTeX 渲染；这属于格式验证，不能替代数学复核。
- 未为这些样稿检索新外部来源，未加入历史优先权断言；教学效果及独立专家审校未验证。

## 兼容与接口

保留原 `mcs-type` 及稳定章节 ID；新增 `mcs-roles`、`mcs-depth`、`mcs-applicability-*`、`mcs-reason-*`、`mcs-covered-*`、`mcs-custom-checks`。字段写入 Markdown，沿用现有草稿事务和账号保存接口，无数据库迁移或新增公共 API。

原六篇 v1 校准稿保持原字节；生成器遇到已有不同样稿会拒绝覆盖。旧 T0–T7 原文及哈希保留，仅供追溯。旧标题可定位，旧状态 `na` 兼容读为适用性决定。旧稿升级预览仅补选中缺失内容，全文和自定义 YAML 保全。

AGENTS 与理论第 10 章同步了适用性约定，未改变公共数学本体或学习者状态。ima 生产模板、固定标题校验、配置、账本和归档策略保持原版本；生产迁移须另验模板、校准签名、恢复与归档流程，不能直接替换模板。

## 验证入口

- `npm run templates:check`：双指南镜像及新旧样稿一致性。
- `node --test tests/writing.test.mjs tests/writing-adaptive.test.mjs`：正文保全、适用性、角色、承载、未知边界与提示词。
- `node tests/writing-page.mjs`：最小笔记、范围持久化、组合角色、未知提示、桌面与手机布局，以及原有暂存、保存、冲突、上传与恢复闭环。
- `npm run build`、`npm run check`、`npm test`：构建、仓库检查与全站回归；本次执行结果在交付时追加。
