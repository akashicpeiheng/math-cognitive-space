# MCS：沿数学结构放缩

主导航的 **MCS** 打开 `/mcs`，英文入口为 `/en/mcs`。页面直接展示当前正式数学对象库：远看是节点，放大正在观察的对象，其内部成员逐步展开，父对象转为区域轮廓；缩小时重新合拢。

## 从哪里开始

首次打开呈现全库概览。点「群论尺度链」聚焦已有的子学科—话题—单元—表达片段，再滚轮或点「＋」逐层观察。这个例子只覆盖右单位结构中的左乘与单射性，不表示完整群论。

- 拖动画布空白处平移；滚轮、双指或「＋／−」放缩。
- 单击对象查看公式、成员、证据与相关讲解；双击聚焦。键盘 Tab 选中对象，Enter 或空格查看，F 聚焦；画布获得焦点时方向键平移。
- 拖动对象改变摆放，拖动区域标题带动其内部成员。内部成员的位置相对父区域保存。
- 详情的「展开／合拢」固定当前对象的显示选择；「自动尺度」解除手动固定，恢复随缩放变化。
- 「适配视野」改变镜头；「重置布局」恢复自动摆放。两项操作分别提供。

对象大小随镜头变化，标签保留可读字号。分裂和聚合沿同一位置过渡；系统设置为减少动画时直接显示结果。手机详情在底部展开，可以关闭后继续观察画布。

## 滤镜如何组合

内容分组、对象尺度、证据标签与关键词共同筛选对象：同一项内多选取并集，不同项之间取交集；未选择表示全部。数学关系筛选只改变连线，孤立对象仍保留。

关键词匹配对象标题、ID 和已有声明文本。群论、拓扑—微分几何及三个局部预设来自已登记的对象集合；这些分组是浏览入口。

不匹配的对象隐藏，匹配对象需要的父级轮廓保留并展开上下文。父级标明直接成员及自声明的「匹配数／总数」，筛选不重写成员归属。边上的小连接点可以点击或用键盘打开关系详情；在局部放大或选中相关对象后显示关系标签。

归属以区域表达，引用和导入以虚线表达，数学关系使用独立连线。聚合后的关系标 `R∃`，表示成员间存在联系。推导的 `AND` 连接点保留共同前提；有前提被筛选隐藏时显示 `+N ?`，点击可查看全部前提、条件和来源。

## 当前内容与证据边界

2026-10-26 的源库包含 65 个正式对象、92 条 M 层关系。群论 8 个对象贯通五种尺度；57 个拓扑—微分几何对象是单元，它们目前使用内部声明，尚未登记上层话题和下层成员。

页面只沿已登记成员展开，也可打开对象内部的声明与公式。内部声明沿用「对象 ID＋声明锚点」身份，引用入口定位原对象。单元可以直接包含原子与分子；没有层级的对象不生成临时数学聚合。

`DEF`、`PROOF` 等标签按源声明登记，结构合法、数学论证、机器重放和人工对应审阅分别查看。「完整对象与证据」可进入已有详情；返回 MCS 会恢复视图。英文界面中的中文对象如实标记尚未翻译。

## 保存、分享与恢复

滤镜、镜头、展开选择、当前对象及手动位置自动保存在当前浏览器。点「分享视图」复制公共视图链接；剪贴板不可用时可以在提示框手动复制。链接包含相同视图状态，不需要账号，也不包含个人笔记、掌握记录或登录凭据。

恢复顺序为分享链接、本机记录、默认概览。源版本变化后保留仍有效的引用，对失效项显示恢复记录；损坏链接或本机记录会提示并回退。浏览器禁止存储时可以继续浏览并用分享链接保留视图。

## 工程入口与验证

`GET /api/v2/ontology/mcs-view` 公开只读，返回全库形式对象、精确引用、五级成员、声明、M 层原关系和浏览分组，绑定 `objectVersion`。本机和云端共用接口注册。页面状态使用独立的 `mcs-view-state/1`，本机键为 `mcs-view-state-v1`；分享状态存 URL fragment。

纯函数投影与布局位于 `shared/mcs-space.mjs`，根对象使用现有确定性网络布局，成员位置不随筛选重排。展开／合拢阈值为基准包围盒投影的 240／180 px，过渡约 220 ms，均为工程设计值。浏览、拖动和筛选不写公共 M/L 或学习事件。
