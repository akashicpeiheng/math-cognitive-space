# MCS：数学地图、应用数学索引与对象网络

`/mcs` 与 `/en/mcs` 默认进入数学地图：全景可选一个子学科作为中心，其他领域围绕，交界处显示交叉入口；继续放大后，细分支、已收录专题与数学对象逐步显现并占据视野。地图、应用数学索引和对象网络共用正式数学对象库；索引只按原书目录导航，不新增对象。

## 数学地图

- 全景包含分析、代数、几何、拓扑、数论、离散数学、概率统计、基础与计算八个导航领域。它们是展示层 D 的导航安排，不声称完整、唯一或互斥的数学分类，也不是新增的正式对象或数学关系。
- 全景以一个可选子学科为核心，其余领域环绕；色域以渐变相互渗透，没有矩形分块或互斥边界。点击外围领域或顶部“核心子学科”选择框切换中心；点击当前核心深入。切换时，同一批学科连续移动、伸展到新位置并回到全景；同一核心下缩放、平移不重排布局。
- 外围区域的面积随与当前核心的关联权重变化：强关联扩大，弱关联相对收缩，切换核心时连续过渡。核心保持突出，外围总导航面积固定，弱关联仍保留入口。首版权重是以已有交叉入口为依据的可调整导航标定，不是数学关联的实证测量，也不按已收录对象数量计算；未标定关系保留基准面积。具体规则见 [关联面积验收](MCS学科关联面积验收-20261114.md)。
- 交界处显示有来源支持的交叉学科入口，例如代数几何、几何分析、解析数论。点击可查看具体介绍、来源及相关分支。当前注册 26 个交叉入口，不穷尽所有领域配对；相关入口不代表该交叉专题已完整收录，也不产生正式数学关系。
- 放大进入子学科时，已登记交叉方向在两侧各有一个子级导航入口。代数内部的代数拓扑朝外围拓扑靠拢，拓扑内部的同一方向则朝代数靠拢；交叉区域沿父域中心到对应邻域的方向在内侧边缘展开，并混合双方颜色。原有同名导航按明确 ID 复用；普通分支在内部留出间距。点击这些入口打开已有交叉介绍及来源，不把导航入口视为新增数学对象。规则与验证见 [子级交叉领域布局](MCS交叉领域邻接布局验收-20261114.md)。
- 当核心子学科放大到约 125%、进入子学科层级时，核心区域中央浮现该学科的中英短简介；回到全景或继续深入到分支层级后自动收起。简介属于导航展示层 D，不替代正式对象或阅读内容。
- 分支是色域内的局部地标，不把整个父区域平分给少数子项；只有一个已收录对象时也保留周围的空间。已登记交叉入口会影响相关分支的方向；位置与色彩浓度仍是导航安排，并非数学距离、重要性或收录覆盖率。
- 滚轮围绕指针以阻尼动画缩放，拖动直接跟随指针，释放后惯性减速；触屏支持双指缩放。点击分支平滑定位，放大时下一层渐显，缩小时收回。新操作可随时接管镜头；静置后停止动画，系统“减少动态效果”偏好会立即结束过渡并关闭惯性。
- 顶部路径与“返回上层”帮助保留方向，“数学全景”回到最粗领域。搜索可以定位领域、分支和已收录对象。
- 手机使用竖向布局，保留同一成员树；旋转屏幕或跨屏打开分享时，视野中心随布局转换。交叉入口标签避让学科文字，放不下时保留可点击标记，点击仍可阅读完整介绍及来源。键盘方向键平移，`+` / `-` 缩放，`Home` 返回全景。
- 手机的子学科概览优先保留交叉领域名称；普通分支先显示可点击地标，继续放大后名称渐显。中央简介显示时，外围领域名称暂时收起以留出空间，顶部选择框仍可切换核心。标签避让仍须保持在对应邻居方向，减少动画偏好关闭避让补间。
- 地图视角保存在本机 `mcs-math-atlas-v1`；分享链接使用 `#atlas=`，带相机、窗口尺寸、横竖布局、核心领域及 `field/4` 布局版本，不含个人记录。旧 `focus/1`、`field/2`、`field/3` 记录保留核心选择、重新适配全景，不直接套用旧坐标；对象网络仍使用独立的原有保存协议。
- 只有真实对象 ID 对应的内容才提供“打开对象与关系”入口。未收录内容的分支保留导航身份，明确显示内容尚未收录；它们不计入正式数学对象数量。
- “对象网络”打开 `/mcs?view=objects`（英文 `/en/mcs?view=objects`），保留原有专题、声明、关系、个人备注及阅读入口。旧 `#mcs=` 分享链接继续直接进入对象网络。

## 深缩放：概念星座与主要关系（2026-11-16）

把一个专题放大到对象层时，地图从“散落的标签”切换为该专题的概念星座：核心对象居中，相关对象按阅读分组靠拢，可见对象之间画出主要的 M 层关系。当前精选示例是「微分形式与外微分」：

- 核心：`外微分 d` 居中；`d² = 0`、`curl grad f = 0`、`div curl F = 0` 放在同一扇区，标为「d² = 0 家族」；`微分形式 / Hodge 星 / 内乘` 为「形式运算」；`欧氏三维向量分析的外微分实现 / 梯度与负散度的形式伴随` 为「向量分析」。
- 关系层只画 `deduction`、`application`、`scaling`、`duality` 四类，箭头指向目标，颜色区分类型（推导红、应用金、放缩蓝、对偶品红，浅色/深色各一套）；图例只在关系层可见时出现。当前示例画出 5 条：`外微分 d → d²=0`、`→ 欧氏三维实现`、`Hodge 星 → 欧氏三维实现`（推导），`外微分 d → curl grad`、`→ div curl`（应用）。
- 关系层按“包含视点中心、对象子节点齐全、屏幕上至少 220×160px”的最深父节点启用；专题盒超过视口约 1.6 倍后自动收起，避免选中对象后还拖着整张关系网。全景、子学科、普通分支保持原样。
- 精选分组是 D 层阅读导航，不是数学分类，不新增对象或关系；其他有内部主要关系的专题走通用布局（核心取加权度最高者，按关系种类分扇区）；没有主要内部关系的专题保持原来的留白散布。
- 点击任一对象，右侧详情新增「主要关系」：列出该对象的所有 M 关系（含跨专题的 `curl`、`gradient` 等），点击对方可飞到那个对象；完整前提、证据与个人备注仍在「打开对象与关系」的对象网络。
- 390px 下隐藏分组标题与图例，只保留核心名、可点的对象点和箭头；点对象打开详情读名称与关系。桌面保留分组标题、核心标记与图例。
- 每个正式对象在 atlas 中仍只出现一次；跨专题关系只在详情里跳转，不复制节点。关系层是 `pointer-events:none` 的装饰层，`aria-hidden`；详情关系列表是可访问入口。

## 对象网络

对象网络的首屏为九个专题入口，沿“子学科 ⇄ 专题 ⇄ 对象 ⇄ 内部表达”同步切换整个画布的显示层级。下面的对象身份、关系与保存说明针对这一视图。

## 应用数学索引（2026-11-16）

`/mcs?view=applied` 是第三种浏览方式，把 Nicholas J. Higham 编《The Princeton Companion to Applied Mathematics》（Princeton University Press, 2015；ISBN 978-0-691-15039-0）的 8 编 186 个编号小节做成阅读索引。

- 八编计数：I 6、II 36、III 31、IV 40、V 21、VI 18、VII 25、VIII 9；合计 186。英文标题照录目录，中文标题与一句导读为本站译写；页码为原书印刷页，不换算本机 PDF 页。
- 左栏按编与 MSC 主题码筛选，可只看有地图入口的条目；中栏搜索节号、标题、导读、别名与 MSC（`FFT`、`PDE`、`TSP`、`IV.18`、`iv18`、`湍流` 等）；右栏显示导读、原书位置、主题码、地图入口、相邻/相关条目与可复制引用。
- 顶部工作流条据 I.1（pp. 1–2）：建模 → 分析 → 算法 → 软件 → 计算实验 → 验证；桌面默认展开，手机默认折叠，折叠状态保存在本机。
- URL 参数：`part`、`msc`、`branch`、`q`、`entry`、`mapped`；筛选/搜索用替换历史，选中条目用新增历史，浏览器 Back/Forward 可用。分享按钮复制当前视图链接。
- 地图叶子分支详情显示「本书条目」，可打开索引；索引里的地图入口回到 `/mcs?branch=<leaf id>`。框架抽屉的 12 个未映射 MSC 组（70/74/76/78/80/81/82/83/85/86/92/93）都显示「应用数学索引 · N 节」，不再是无处可去的死路。
- 数据是 D 层导航：不生成形式对象、成员关系或数学关系，也不进入 L 阅读库；MSC 码只是站内检索标签，不是原书分类。英文标题与页码来自原书目录；导读为本站译写，不摘录原文；本站不收录原文、图表或习题。
- 应用模式不请求 `/ontology/mcs-view`，接口不可用时索引仍可读；切到数学地图/对象网络才走既有接口。页面只读写本机的折叠状态与公开 URL，不写 M/L/E。
- 窄屏 ≤860px 用「列表 ↔ 详情」切换；390px 无横向溢出；深色/浅色共用 token。桌面三栏、平板详情抽屉；`/en/mcs?view=applied` 使用英文标题与导读。
- 索引条目不是形式对象，也不是 L 阅读节点；把书目条目升级为阅读内容需另立内容任务。地图仍是八个导航领域，应用数学是横跨视角，不是第九个领域。

## 数学框架索引（2026-11-15）

工具栏「框架」打开右侧抽屉：默认「学科分类」列出 63 个 MSC 2020 二位组与 32 个 arXiv math 分类；「形式结构」列出五级尺度、M 层关系类型和证据状态。来源为 AMS MSC 2020 与 arXiv Mathematics，核验于 2026-11-15；英文标题照录来源，中文名为本站显示译名。

- 每个领域/普通分支有明确分类关联或「未标定」；交叉入口取双方领域的并集。映射属于 D 层检索对照，可调整，不声称穷尽或官方归类；未映射的应用与交叉码单列，并在行内链接到应用数学索引。
- 搜索匹配代码、英文名、中文名和 arXiv 码。对象数大于 0 的分类可点击筛选地图：只降低非匹配节点的透明度与交互，不移动相机、不改变几何；没有已收录对象的分类直接定位到关联分支或领域，并显示现有空分支提示。
- 「只看已收录」隐藏零对象分类；「在图上显示分类号」在领域标签显示 `MSC ×N`、在分支标签显示首个代码，标签宽度不足时只保留详情卡中的代码。地图与分享保持 `field/4`，新增可选 `codes` / `framework` 字段；旧链接缺省关闭，不套用旧相机。
- 分支详情显示 MSC 2020 与 arXiv 码；对象详情显示尺度、声明类型与状态、M 层关系计数、证据状态和成员归属。所有计数来自当前 `mcs-view` 与对象结构纯函数，不是静态写死的数字。
- 分类号不生成对象、成员关系或数学关系；一个对象可关联多个分类号，计数不是互斥分区；对象身份、`contentHash`、`objectVersion` 与 E 层记录不变。
- 形式结构页只读公开 M：92 条 M 关系的类型分布、77 个对象的五级尺度、声明与关系证据状态。L 层阅读先修/类比不在本图，也不计算传递闭包；PROOF 是登记标签，不等于本次机器重放通过。

## 内容与身份

2026-11-02 新增八个话题、三个子学科组织对象及 Jacobi 矩阵单元。当前共 77 个正式对象、61 篇阅读、92 条 M 层关系。原有 65 个对象的形式摘要保持不变。

新增话题为局部变化、拓扑结构与连续性、分离与可数性、紧性与覆盖、坐标与流形、切空间与张量、微分形式与外微分、向量场与流。微分学、点集拓扑、微分几何与已有群论构成四个上层入口，均只表示当前有限内容。

成员来自 mcs-content 中的正式 Markdown。话题只含单元，子学科只含话题；允许交叉成员，不由共同归属生成推导或学习先修。局部变化围绕一阶近似及其信息提取；不把梯度、散度、旋度都说成全导数的等价表示。

每个对象只有一个画布实体，交叉归属使用可定位同一对象的引用入口。展示配置明确主要父级及顺序，不改数学成员关系。未来未分类对象保留独立入口。图卡是局部坐标图的搜索别名；Jacobi矩阵、雅可比矩阵、Jacobian 均可检索。

## 浏览

- 自动模式以专题全景适配为 100%；进入阈值 80%／180%／360%，回退阈值 60%／140%／280%。这是工程初值，不声称教学效果。
- 工具栏可固定整个画布的层级。双击聚焦并进入下一层；回到概览恢复九专题。
- 对象与内部表达层使用圆点，专题保留淡分区。只有一条声明的单元以一个声明圆点显示；对象整体引用也连到同一点，拖动带动整个单元。公式、条件与证据从详情查看。
- 默认“关联优先”：专题概览选中后显示相关连线；对象／内部表达层显示淡背景网络，选中对象或声明后高亮其真实关系。也可切到全部或隐藏。内部关系以计数或对象详情查阅；汇总保留原关系 ID，AND 前提组独立，隐藏前提如实提示。数学关系用箭头，引用／导入用点线。无可见端点的非选中关系不绘制，原关系仍可查阅。
- 搜索保持折叠，父级显示命中数。选择结果进入对应层级；清掉关键词，保留其他筛选。
- 同话题内已登记的数学关系使用固定屏幕宽度的粗箭头，按推导、放缩、应用、对偶等真实类型配色，分类文字浮在箭头上方并避让圆点和其他标签。同对节点的不同关系、反向登记与不同 AND 前提组分别占用通道；共同归属本身不生成数学关系，引用与导入继续使用细点线。
- 点击箭头或关系文字查看方向、联合前提、条件和来源，可选择添加、修改或取消个人备注。有备注的箭头文字带 ✎ 标记。备注复用个人账号的 E 存储，本机模式保存在本机数据库；备注不改公共 M/L，也不进入分享视图链接。
- 拖动空白平移，拖动对象调整位置，区域拖动带动成员；布局不随关键词或缩放重排。标签避让，220 ms 过渡，支持减少动画。
- 窄屏概览采用可滚动双列专题入口，单击查看、双击深入；进入对象层后使用同一个缩放画布。详情在底部显示。

## 接口、保存与兼容

`GET /api/v2/ontology/mcs-view` 保持 mcs-view/1，在原有对象与关系之外提供版本化 presentation：主要父级、顺序、双语标题、概括与检索别名。展示配置属于 D，不是新的数学关系。

本机使用 mcs-view-state-v2／mcs-view-state/2，记录全局层级、自动或固定模式、连线模式、筛选、镜头、选择和位置。分享仍用 URL fragment。恢复顺序：当前历史项、分享链接、本机记录、默认概览。

兼容读取 v1 本机记录与旧分享链接，将局部展开转换成全局层级，保留有效筛选和对象引用。组织结构变化时重置旧坐标并围绕选择重新适配，显示恢复说明；不覆盖 v1 存储。浏览与拖动不写公共 M/L 或学习事件。
