# MCS 框架细化验收 · 2026-11-15

## 请求与范围

用户要求「根据主流的数学框架，细化 MCS 界面」。本轮把「主流数学框架」落实为两层可核对结构：

- 外部标准分类：MSC 2020（AMS）与 arXiv math；
- MCS 内部形式框架：五级尺度、M 层关系类型、证据状态。

范围是 `/mcs` 与 `/en/mcs` 的数学地图、工具栏「框架」抽屉、地图分类号、分类筛选与对象结构摘要。**不新增地图分支或对象，不重排几何，不改变八个领域、26 个交叉入口、`field/4` 分享协议或 M / L / E 数据。**

## 交付行为

### 框架抽屉

- 工具栏新增「框架」按钮；桌面为右侧抽屉，手机为底部 sheet，`role="dialog"`、`aria-label`、Escape 关闭并恢复触发器焦点。
- 「学科分类」标签页列出 63 个 MSC 2020 有效二位组与 32 个 arXiv math 分类；来源链接为 AMS MSC2020 与 arXiv Mathematics，核验于 2026-11-15。
- 中文名为本站显示译名，官方英文标题照录来源；未映射的应用与交叉码（70, 74, 76, 78, 80, 81, 82, 83, 85, 86, 92, 93）单列为「未映射到本图」。
- 搜索匹配 MSC/arXiv 代码、官方英文名、中文显示名与关联分支名；搜索后自动滚动到首个结果。
- 「只看已收录」隐藏对象数为 0 的分类；「在图上显示分类号」在领域标签显示 `MSC ×N`、在分支标签显示首个代码（标签不足 120px 时只保留详情卡）。
- 分类行对象数大于 0 时点击切换地图筛选：只把非匹配节点透明度降到 18% 并移除交互，不移动相机、不改变几何；对象数为 0 时点击定位到关联分支/领域。
- 筛选 chip 显示 `MSC 53 · 微分几何` 并可清除；分享链接与旧 `focus/1`、`field/2`、`field/3`、`field/4` 兼容，新增可选 `codes` / `framework` 字段。

### 形式结构标签页

- 五级尺度阶梯：子学科 4 / 话题 9 / 单元 59 / 分子 3 / 原子 2（运行时计算；本轮快照）。
- M 层关系：推导 39 / 放缩 26 / 应用 26 / 对偶 1；只统计公开 M 层，L 层阅读先修与类比不在本图。
- 证据状态：对象声明 `DEF 43 / PROOF 20`，关系证据 `DEF 2 / PROOF 90`；注明 `PROOF` 是登记标签，不等于本次机器重放通过。
- 总量：77 个对象、92 条 M 关系、77 个地图实体。

### 对象与分支详情

- 叶子分支显示 MSC 2020 与 arXiv 码；代码可点击打开抽屉并高亮。
- 对象详情显示：尺度、声明类型与状态、M 层关系总数与按种类计数、关系证据状态、成员归属（主归属 + 其他归属处数）。
- `McsInspector` 在对象网络中也显示同一份 `objectStructure` 摘要；两个视图共用纯函数，不各写一套。

## 数据与边界

- 新文件 `shared/mcs-framework.mjs` / `.d.mts` 为 D 层纯数据与纯函数；不进入 `data/manifest.mjs`、`contentHash` 或 `objectVersion`。
- 分类号不生成对象、成员关系或数学关系；一个对象可关联多个分类号，计数不是互斥分区。
- 领域/分支到分类号的关联是编辑对照，可调整，不声称官方归类或穷尽；中文名不是官方中文标题。
- 地图筛选只读 `createMcsAtlas` 与 `mcs-view` 的只读结果，不写 E，不改变 M / L。
- 当前 77 个对象集中在微积分、群论、微分几何、点集拓扑四个分支；其余分类如实显示 0。

### 全量回归

`npm test` 本轮在「性能观测（227 节点视图）」阶段形成失败终态，后续阶段未执行：

- 423 节点一次铺开 **8967 ms**，超过 8000 ms 预算；
- 加一个节点 **1814 ms**，最长阻塞 **1022 ms**，超过 800 ms 单次阻塞门槛。

该阶段不在本轮修改范围；本轮同时运行了构建与定向测试，性能数值可能受本机负载影响。不把失败归因于框架改动，也不把它记成全量通过，更不临时放宽门槛。此前阶段全部通过，包括本轮的框架纯函数与框架浏览器组、MCS 地图/画布/关系/分享、拓扑—微分几何、Master、API、i18n 与账号组；Lean 组 3 项真实重放跳过、账号组 1 项真实 Lean 检查跳过，均未计为证明通过。全量测试因此**不是全绿终态**，后续阶段也未运行。

## 未验证与未声称

- 未做真实学习者实验；分类索引和筛选不声称教学收益。
