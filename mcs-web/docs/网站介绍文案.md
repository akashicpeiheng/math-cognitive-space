## 首屏

# 数学认知空间 MCS

## 把"一路读下去"换成"知道为什么这样走"。

数学学习真正的困难，很少是书上的字不认识。更多是这样的时刻：

读到第三章，才发现卡在第一章某个没真懂的地方；定理的每个条件都背下来了，却说不出去掉哪一个会塌；
同一份材料换一本书讲，说法全变了，不知道哪条才是真正的那条依赖；读完了一整章，
说不清自己到底是"读过了"还是"懂了"。

MCS 做的事只有一件：**把数学内容拆成有身份、有版本的知识节点，把节点之间的依赖、推广、特例、
类比、对偶做成有类型的连接，让每个断言带着自己的证据状态**。于是一条学习路线可以说清楚：
它从哪里进、用了哪些假设、哪几步是必需的、哪几步只是类比。

**不承诺学得更快。承诺的是：你随时能查到——这一步凭什么、它依赖什么、换一条路会怎样。**

## 一、现在这样学，卡在什么地方

### 1. 知识是线性的，依赖其实是网络的

教材按顺序讲，但"顺序"和"依赖"常常不是一回事。两种同样自然的进入方式——从正三角形的
旋转与翻折进入群，从模 5 的剩余类乘法进入群——没有任何一条线性叙述能同时容纳。
更麻烦的是最典型的那一处：**极限与实数互相定义**。教材通常选一边先讲，
读者被迫接受这个选择，也失去了"这里本可以换一条路"的意识。

线性叙述还会悄悄改变人的判断：把"在书里排在前面"当成"逻辑上必须在前面"。

### 2. 教材是过来人写的，动机和生长过程被省掉了

写在纸上的内容是凝练的，相对于作者脑海里的内容，省掉了那些**自然但不必要**的想法：
最初为什么需要这个对象，它最初的粗糙形态（胚子）长什么样，中间经历了哪些变形。

于是常见的一幕是：读者能一步步推导出定义，却说不清为什么必须有这个定义。
（"防自学"这个吐槽，大概就源于此。）

我自己有过一次典型的翻车。求 $\lim_{x\to 0}\frac{\tan x-\sin x}{x^3}$ 时，
我把 $\tan x\sim x$、$\sin x\sim x$ 代进去，得到 $x-x=0$，极限是 $0$。
错在等价无穷小替换在加减法中不能逐项替换——丢掉的是高阶无穷小的信息。
这次错误暴露了我一个深层惯性：**把"等价"当作"相等"随意迁移**。
这类记录比正确答案值钱得多，但教材里没有它的位置。

### 3. 换一种讲法，条件就悄悄丢了

材料在改写、作图、压缩时会发生两种无声的偷换：**把"提到了某个概念"当成"证明依赖它"，
把"换了一种表达"当成"条件没有丢"**。读者看到的是长得差不多的连线，
可这些连线可能是"两者都必需"、可能是"任选其一"、也可能只是"讲法不同"。

而条件从来不是累赘，它是护栏。中值定理拿掉"闭区间连续"，
$f(x)=1/x$ 在 $[-1,1]$ 上就立刻给出反例——条件不是要背的，是**从反例里长出来的**。

### 4. 学习者被安排在同一个入口进来的

有的学习者想理解群，却更适合从图形的对称开始；另一个熟悉模运算，
从 Units₅ 开始会快得多。这两种路径最终都要走到同一组公理，但没理由从同一页开始。

同样重要的是：系统说"你必须先学 A"时，它检查了哪些路线？有没有一条经过 B 的替代入口？
大多数时候没人回答这个问题。

### 5. "读过了"和"懂了"混在一起

读过、听过、复述得出、能独立用、能独立造——这是**五种不同的状态**，
却常常被同一条进度条表示。

### 6. 你个人那一层，无处安放

你当时是怎么错的、卡在哪、用什么检验手段发现自己错了——这些是最有复用价值的信息，
但它们通常只活在一本会被换掉的笔记本里。

**这六条的共同点**：都不是"内容不够"，而是**结构丢了**。
知识之间的依赖、材料里的动机与证据、学习者带着的个人状态——这三样东西在每次阅读里都存在，
但没有被记录下来，所以既不能检查，也不能重用。

## 二、我的工作做了什么

**一句话**：我把数学知识从"文本里的段落"变成"有身份、有连线、有证据状态的节点"，
让这些资源可以被检查、被重组、被派生——然后才谈得上给不同的人规划不同的路。

构造链是一条直线：**条目与连线 → 成组输入和替代行动 → 带证据与来源的资源 →
外置个人评价的事件路线 → 针对具体模型的独立检验**。

### 1. 先分清三份记录：什么属于所有人，什么只属于你

| 层 | 放什么 | 谁能写 |
| --- | --- | --- |
| **M** 公共本体 | 数学节点及版本、条件、证明与证据状态、公开行动 | 随版本公开修订，学习过程中**只读** |
| **E** 外部模型 | 你的确认、作答、个人笔记、误区记录、学习事件 | 只在这里写；换档案即换一套个人状态，M 不动 |
| **D** 派生 | 视图、候选路线、推荐、继续学习网络 | 由 M + E 现算，不落库 |

**这一层分离解决了两个具体问题**：你的遗忘不会改变一条定理的内容；
公共知识的修订也不会悄悄改掉你的学习记录。规范记作
$D = D(M, E, s, g, b, \rho)$——目标是 $g$、预算是 $b$、偏好是 $\rho$。

### 2. 连线是有类型的，不是一种"关联"

"必须先用它""讲法不同""这个类比有帮助"是三件完全不同的事。
我按**认知成本**给每条边定权重，越硬的数学断言画得越重、在布局里吸得越紧：

| 关系 | 权重 | 含义 |
| --- | --- | --- |
| 硬前置 hardPrereq | 1.00 | 不用它就推不下去 |
| 硬泛化 hardGeneralization | 0.95 | 一方是另一方的特例 |
| 特化 specialization | 0.90 | 反方向，成对登记 |
| 应用 application | 0.72 | 概念被用到具体对象上 |
| 跨域 crossDomain | 0.68 | 两条理论线之间的接口 |
| 对偶 duality | 0.62 | 两个空间按配对互相确定 |
| 桥梁 bridge | 0.56 | 两种表述之间的等价 |
| 类比 analogy | 0.40 | 启发用，先让步、不充当证明 |

同一个数同时决定**线宽、颜色、推荐理由的强弱顺序和力导向图里的吸引强度**——
所以不会出现"画得很粗却几乎不吸"这种自相矛盾。

### 3. 每个断言都带着自己的证据状态

`DEF`（定义或约定）· `PROOF`（有正文证明）· `REF`（引用来源，核验范围另记）·
`FINITE`（有限检查，只覆盖列明片段）· `ILLUSTRATION`（示例，不承担证明）·
`NOT-CLAIMED`（明确不声称）。

**"觉得自然"不是证明**；暂时证明不了，就退成例子并标注。
这条纪律直接改写了界面的措辞：微分几何案例的 36 条证据全部是正文级、
机器检查状态是"未运行"，所以界面只写义务清单，**不写"已核验"**。

### 4. 把图缩小的时候，条件不跟着消失

局部视图可以隐藏远处的内容，但必须留下边界：隐藏了哪一节、属于哪个版本、
依据在哪儿能找到。**"在图上隐藏"不允许变成"在论证里删除"**——这是整件事的底线。

### 5. 路线是候选集，不是唯一答案

规划器只吃三个输入：目标、背景、事件界。吐出来的是**带条件的候选路线**，
每条写明它用了哪些假设。不同背景的人进入同一个目标，得到不同路线——这是设计目标，不是缺陷。

### 6. 你的状态外置，公共本体保持干净

标记已读、我还不懂、确认已掌握、自检作答——每一次状态变化都是 E 里的一条事件。
其中只有"确认已掌握"能进入可用性声明；
**读过不等于懂了，这是数据结构层面的规定，不是文案上的提醒**。

**一个贯穿例子：极限的两种表述。** 实数与极限的循环依赖在这里不是被"绕过"，
而是被登记成带条件的资源与候选路线：节点可以分版本，路线可以替换，
每次替换都留下它用了什么假设。

## 四、我不声称什么

这一节放在介绍里而不是附录，因为它决定了前面每一段该怎么读。

- **不声称提升学习效率。** 没有做过对照实验，也没有测量过学习效果。
  任何"学得更快更轻松"的说法都超出当前证据。
- **不声称首创知识网络。** 论文给出了等信息增强图编码，同一片段上两种表示得到相同分类——
  这是"不更差"，不是"更强"。
- **不声称完整机器认证。** 检查器自身的一般正确性、以及全部案例的机器认证，仍是开放问题。
- **不给掌握度百分比，不做间隔重复与到期日排序。** 本体与外部模型里都没有校准过的认知模型，
  伪造一个数字会误导学习者；掌握只能由你自己确认。
- **不声称现在就能照做。** 这是一套规范和有限实现，不是成熟产品，也不是课程。

## 五、从哪里进

四条入口，对应四种读法：

| 入口 | 适合谁 |
| --- | --- |
| **数学对象** | 想按对象读：挑一个概念，看它的条件、反例与证据 |
| **组建网络** | 想按结构读：看关系怎么连、哪条边更硬 |
| **学习路线** | 想按路线读：给目标和背景，比较候选路线各自的假设 |
| **研究台** | 想按证据读：覆盖清单、局部化算子、证据重放——给复核用 |

## 收束

**思想：条件带着走，入口可以选。**
一个数学对象可以有很多条进入的路，但它成立的条件必须跟着它一起走。

**方法**：给知识建身份与版本；给关系分类型并标认知成本；给每个断言标证据状态；
把学习者状态外置到公共本体之外；让每条路线把它的假设写在明面上。

**留着的一个问题**：如果一条路线替你省了事，你能说出它省掉的是哪一步、
以及因此欠下了什么吗？
