# 连接条件与个人备注 / Connection explanations and personal notes

## 使用方式

放缩线旁直接说明特殊端到一般端的变化。例如光滑图册与 Cᵏ 图册之间显示
“放宽正则性：所有阶 → 有限 k 阶（同一图册）”。节点详情列出逐条件对照，
同时保留原适用范围、见证引用和证据等级。

右键连接线，在菜单中选择具体连接后添加、编辑或取消备注。同一对节点的多种
连接会分别列出；已经核验的同一放缩命题的正反读法共用备注。键盘可聚焦连接线，
用 Shift+F10、菜单键、Enter 或空格打开菜单；Esc 或点击外部关闭菜单。
节点详情的连接列表也提供操作入口。

个人内容始终标为“我的备注”。画布常驻显示前两行，点击展开全文，支持 Markdown
和数学公式。同一条合并线上的多份备注分别显示，缩小画布或选中其他节点不会隐藏
备注。网络详情、节点关系、关联预览、推荐、研究页和维护页复用同一份备注。

取消成功后有 10 秒撤销入口。保存失败保留编辑器和输入；遇到修订冲突，可重新载入
最新内容，核对后再次保存。撤销使用删除时的修订号，不能覆盖其他页面的新修改。
进入页面和窗口重新获得焦点时重新读取，同页写入立即同步。

备注属于账号，而不是学习者档案。切换档案、视图或语言继续共用，文字保持原文。
本机归属为 `local`；公网归属由服务端登录身份决定，访客有登录入口，登录后返回
原页面。退出或换账号立即清空原账号的展示，并取消过期请求。

## 公共说明与数学边界

公共关系的可选字段为：

```json
{
  "scalingExplanation": {
    "summary": "放宽正则性：所有阶 → 有限 k 阶（同一图册）",
    "changes": [
      {
        "condition": "过渡映射的正则性",
        "special": "C^∞：所有阶导数存在且连续",
        "general": "C^k：只要求至有限 k 阶"
      }
    ]
  }
}
```

14 条有明确端点的现有放缩记录补充了中英说明，来源是各记录的正文、范围和见证。
实例限制说明具体载体与运算怎样放开；遗忘光滑结构说明所遗忘的附加结构；张量的
表征对应明确写为“不是删去条件”，其条件对照为空。11 条方向未核验的旧记录显示
“放缩条件待核验”；已知方向但未登记说明的新关系显示“条件说明未登记”。

这些文字是对既有内容的展示说明，不提供新的证明，不提升 `DEF / PROOF / REF /
FINITE / ILLUSTRATION / NOT-CLAIMED` 等原证据状态。公共说明属于版本化本体 M，
个人备注属于外部用户数据 E；备注不修改关系强度、前置或派生结果 D 的数学判据。

## 存储与维护

| 接口 | 内容 |
| --- | --- |
| `GET /api/v2/me/connection-notes` | 当前用户的全部未取消备注 |
| `PUT /api/v2/me/connection-notes/:key` | `{ body, baseRevision }`；首次创建修订号为 0 |
| `DELETE /api/v2/me/connection-notes/:key` | `{ baseRevision }`；返回删除后的修订号 |

登记关系按稳定关系 ID 匹配；有明确端点且模式、见证引用、命题和条件一致的放缩
正反读法共用标识。行动契约按行动 ID 与有序端点，其他结构连接按连接族与规范化
无序端点匹配。标识不含语言、视图或本体版本。

SQLite 与 PostgreSQL 均附加创建 `connection_notes`，按归属与连接标识联合索引。
修订号由单条 SQL 的条件写入校验。取消会清空正文，保留递增修订记录，以阻止删除、
重建后旧输入或旧撤销覆盖新备注。撤销正文只在当前页面保留 10 秒。

整库备份含备注：SQLite 使用物理备份，PostgreSQL 使用逻辑备份的 `connectionNotes`。
旧备份缺表或缺字段时恢复为空集合。单个学习者档案的导出不包含账号级备注。

可复现检查：

```text
npm run build
npm run check
npm run check:i18n
npm test
```

定向入口为 `tests/connection-notes.test.mjs`、`tests/connection-notes-page.mjs`、
`tests/auth.test.mjs` 与 `tests/https-public.mjs`。浏览器测试使用独立临时数据库；
PostgreSQL 测试使用 PGlite，公网浏览器测试使用本机 TLS 和身份服务桩。
这些检查不等同于真实公网、多台实体设备或外部身份服务的运行验收。

## English

Scaling labels describe changes from the special endpoint to the general endpoint, such as
“Relax regularity: all orders → finite order k (the same atlas)”. Details show individual
conditions alongside the existing scope, witness reference and evidence status. Fourteen
directed records have bilingual explanations; eleven legacy records say “Scaling conditions
awaiting verification”. New directed records without an explanation say “Condition explanation
not registered”. Representation correspondence is explicitly distinguished from removing
conditions. These descriptions make no new proof claims.

Right-click any connection, or focus its hit region and press Shift+F10, the context-menu key,
Enter or Space. The menu lists the specific connections represented by a merged line. Add,
edit or remove a personal note; equivalent verified forward and reverse readings share one
note. Lists provide the same controls. Escape and outside clicks close the menu.

“My note” remains separate from public explanations. The canvas displays its first two lines
at a readable screen size through zoom and selection changes; click to read the full text.
Specific connections retain their own notes in merged lines and association previews. Notes
also appear in network details, node relationships, recommendations, research and maintenance.
Markdown and mathematical formulas are supported; user text is never translated.

Notes belong to the signed-in user and are shared across that user's learner profiles, views,
languages and devices. Local mode uses the existing `local` identity. Visitors can sign in and
return to the original page. Account changes clear the previous user's notes immediately and
cancel obsolete requests. Page entry and window focus reload notes; successful writes update
the current page immediately.

Failed saves retain the editor and draft. Revision conflicts provide an explicit reload before
retrying. Successful removal offers ten seconds to undo; undo cannot overwrite a newer change
from another page. Both database drivers use additive migrations and atomic revision checks.
Full backups include notes, and older backups without them restore an empty collection. Personal
notes are E data and never change public M or mathematical evidence and prerequisite rules.

The reproducible commands and targeted test entry points above exercise temporary databases,
PGlite and a local HTTPS server with a test identity provider. Real public deployment and multiple
physical devices require their own operational verification.
