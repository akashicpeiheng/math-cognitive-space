## 方向与证据边界

`direction.general` / `direction.special` 表示一般端与特殊端；`reading: expand` 表示放，`reading: contract` 表示缩。

同载体关系中，「特殊端到一般端的放读法」与「一般端到特殊端的缩读法」使用同一份特殊性质蕴含一般性质的证据。逆命题需要另一份证明；合并类型不证明逆命题，不倒转跨载体映射，也不提高 `REF` / `FINITE` 等原有证据等级。

自动发现保留原来的缩读法存储约定：`from = general`、`to = special`。候选枚举和发现结算均按有序方向、目标与条件区分证据；精确匹配某条命题的反例不排除逆命题或不同条件下的候选。

候选 ID 与输入哈希也包含这份命题身份。重放只接受当前登记中方向、目标和条件均匹配的命题；原条件或目标已变化时标为 `stale`，不回退为同端点的另一条关系。

## 放、缩方向锥

LC10 是放向锥，LC11 是缩向锥。原有 `nodeId` 调用继续可用：同载体、跨载体、实例三种模式分别从同一种子计算闭包，再合并显示节点。不能用一种模式到达的节点继续另一种模式的路径。

可选参数 `scalingMode` 固定为 `same-carrier`、`cross-carrier` 或 `instance`。结果的 `scaling.projections` 保留各模式的节点、关系 ID 和边界；未知方向写入 `unresolvedRelations`。这些结果是登记关系上的导航，不新增组合证书。
