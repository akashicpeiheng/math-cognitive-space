# 游客规划与 Obsidian 笔记库

游客可打开 `/plan`，选择一个或多个目标、声明背景、比较路线、沿路线阅读和查看结构回放。个人学习档案仍须登录。背景的「已确认可用／条件性假设／未知入口」保留原语义；游客声明只用于规划，登录不会把它们自动写成掌握记录。目标、背景和参数保存为当前浏览器的草稿。

## 带入已有笔记

打开 `/library`（英文 `/en/library`），点击「选择 Obsidian 库」，选中 vault 根目录。网站先扫描、显示目录及文件选择、附件数量和大小、跳过原因，再预览变更并导入。Obsidian 原文仍在 Obsidian 中编辑；网站可「复制为创作稿」，在独立的私人创作库改写，并保留来源与可解析附件。

## 在网站创作笔记

点击「新建笔记」选择标题、类型和读者基础；节点页也可「围绕此节点写笔记」。进入后左边是章节与状态，中间写作或阅读预览，右边是当前节的目的、问题、示例和自检。窄屏用「章节目录」「本节写作引导」展开相应内容。正文语言在创建时确定，网站语言切换保留原稿。

草稿自动暂存当前浏览器；只有「保存笔记版本」才生成库修订。即使未完成、标待核验或不适用，仍可保存。每次保存保留旧版本，单篇可下载 Markdown，整库历史与附件仍用原有备份导出。只有主动上传才传到账号。「取回本机继续写」下载完整账号库与附件，保留云端基线；冲突保全本机文字，不静默覆盖。

创作台可以复制整篇、当前章节和审校提示词，复制失败时在提示词预览中手动复制。它不会直接调用模型。写作覆盖与“已自检”是结构和作者状态，不能代替数学或史料核验。详细流程、版本升级与空间不足的恢复见[创作使用与迁移说明](writing/创作使用与迁移说明.md)。

优先使用只读目录句柄，并将句柄保存在 IndexedDB。浏览器不支持目录访问接口时使用文件夹选择。重新扫描时检查授权；授权失效或不再保留句柄时重新选择目录。配置、历史与依赖目录 `.obsidian`、`.git`、`.trash`、`.hg`、`.svn`、`node_modules` 排除。目录选择与授权机制依据 [Chrome 官方目录访问文档](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)。

支持全文搜索、目录树、Markdown、公式、常见 frontmatter 的标题／别名／标签、Wiki 与 Markdown 相对链接、标题和块定位、反向链接。链接有多个可能目标时列出候选。嵌入最多展开三层，循环或达到上限时提供跳转。链接语法依据 [Obsidian 内部链接文档](https://obsidian.md/help/links)。frontmatter 是常见标量与列表属性的轻量解析，不是完整 YAML 引擎；插件、Dataview、脚本与原始 HTML 均不执行。

只导入选定笔记实际引用的附件。支持常见 PNG／JPEG／GIF／WebP／AVIF／BMP 图片、PDF、MP3／WAV／OGG／M4A／FLAC 音频和 MP4／WebM／MOV 视频。图片内嵌，音视频使用浏览器播放器，PDF 提供打开和下载。未导入、缺失和浏览器无法解码的附件有提示；文件扩展名不能保证设备支持实际编码。

每篇笔记可手动关联多个已有数学节点，节点页和沿路线阅读时显示「我的相关笔记」。关联是私人参考资料，不成为规划输入、不创建数学前置关系，也不产生掌握确认。公共本体 M 与笔记库保持分离。

## 更新、上传与恢复

「重新扫描」先比较相对路径与 SHA-256，列出新增、修改、缺失和唯一内容匹配的改名。导入生成新的修订；修改保留历史，源文件缺失保留旧副本并标记。只有唯一内容匹配的改名延续原 ID 和关联。同名或同内容的多个候选不自动合并。浏览器保存实际字节，源文件随后编辑或删除不会使历史副本失效。

本地导入与更新不上传笔记正文或附件。「上传到我的账号」是独立操作，成功后保留本地副本；下次扫描仍需再次主动上传。云端库按账号归属，跨学习档案共用；本机服务使用本机身份。账号切换取消旧读取／上传请求，清除旧账号界面状态和附件 URL；主动导入的浏览器库独立保留。

上传清单和附件均分块传输，附件每块 512 KiB，小于现有请求上限。中断后再点击上传会恢复待完成批次；哈希不符、取消或冲突不切换旧修订。多设备修订采用乐观锁，冲突后应重新载入账号副本再扫描。附件下载校验账号归属，支持 HTTP Range 和浏览器播放器拖动进度。

默认限额：Markdown 每篇 2 MiB、附件每个 100 MiB、每库 10,000 篇笔记和 500 MiB、每账号 1 GiB。内容不同的历史版本计入额度，相同哈希内容复用。服务配置 `vaultLimits` 可调整容量和数量，`chunkBytes` 是固定存储格式。浏览器另检查可用空间，最终写入失败会回滚事务。

「导出笔记库」下载 `mcs-private-vault/1` 的 JSONL 文件，包含索引、所有修订与分块内容；不混入单个学习档案导出。整库 SQLite 物理备份包含新增表；PostgreSQL 逻辑备份产生主 JSON 和同目录的 `.vault-chunks.jsonl` 附件文件，**须一起保存**。两部分来自同一重复读快照，恢复会重新核对内容哈希。旧备份没有笔记库表／字段时恢复为空库。

## 接口与验证入口

`GET /api/v2/vault-capabilities` 返回限额。`/api/v2/me/vaults` 接口族覆盖库列表、创建、移除、历史、文件读取、导入清单分段、附件分块、提交／取消、节点关联和独立导出；云端所有读写检查归属，写请求沿用来源与 CSRF 校验。

游客规划和学习方案预览使用匿名 HttpOnly Cookie 派生的服务端归属；不向前端返回归属标识。游客只可查询／取消自己的任务。带 `profileId` 的请求仍要求登录和档案归属校验；`sync` 不对游客开放，所有游客任务进入原有有界队列。

自动验证：`tests/vault.test.mjs`（解析、更新、修订、重试、哈希、额度、SQLite／PostgreSQL 与旧备份）；`tests/vault-page.mjs`（真实 Chromium 文件夹导入、源文件改动后历史、媒体、循环、搜索、关联、主动上传、中英和窄屏）；`tests/auth.test.mjs` 与 `tests/https-public.mjs`（归属、CSRF、游客规划与 HTTPS 浏览器）。证据为 FINITE，具体本次执行结果见 `VALIDATION.md`；不是所有浏览器／媒体编码的兼容性证明。

隔离验收将 `MCS_WEB_TEST_STATIC_DIR` 指向候选构建目录，数据库和端口由测试创建；`MCS_WEB_REQUIRE_BROWSER=1`、`MCS_WEB_REQUIRE_TLS=1`、`MCS_WEB_REQUIRE_LEAN=1` 要求实际执行对应验证。慢速 Windows 验证环境可设置 `MCS_WEB_TEST_LEAN_TIMEOUT_MS=300000`，只延长隔离测试的资源预算，不改变证明接受条件或正式服务的超时配置。最初默认 120 秒的完整回归在 Lean 断言核对阶段超时，须与随后执行结果一并记录。
