# MCS 子级交叉领域的邻接布局 · 2026-11-14

## 交付行为

以代数为核心放大时，代数拓扑作为代数的子级交叉入口出现，区域中心朝向外围拓扑，在代数区域内靠近这一侧的边缘。以拓扑为核心时，原有代数拓扑导航入口则靠向代数。其余已登记交叉方向使用同一规则。

- 现有 26 个交叉方向在双方各提供一个入口，共 52 个 D 层入口。按明确导航 ID 复用已有的代数几何、代数拓扑、解析数论和算术几何分支，其他侧建立指向同一交叉方向的局部入口；不按标题猜测或合并数学身份。
- 交叉子域沿父域中心到对应邻域中心的射线安排，在父域内靠近边缘。展开过程中，其中心从较内位置向最终边缘位置连续移动；切换核心时，位置与尺寸继续沿现有阻尼运动过渡。
- 交叉子域渐变混合双方颜色，桌面标签注明邻居方向。普通分支使用内部独立槽位，优先贴近已有相关方向，保持留白；不让多个工具堆到同一点。
- 手机优先展示交叉名称，普通分支保留可点击地标，继续放大后名称渐显。标签避让同时限制方向与向外距离，避免为了排版把代数拓扑等文字移回中心。外围学科文字作为较轻的方向提示；当前位置栏不被标签挡住。
- SVG 容器不再截获空白处的触摸，只有实际按钮接收点击。交叉入口点击打开已有介绍、来源和相关分支，不展示普通“尚未收录对象”的空详情。
- 保存与分享升级为 `field/4`；旧 `focus/1`、`field/2`、`field/3` 保留核心并适配新全景。

这些入口与几何布局均属于导航 D。一个交叉方向可在两侧出现导航入口；正式 M 对象仍各出现一次，原成员引用、形式哈希、M/L、个人学习记录及关系备注不因此改变。入口不表示交叉领域已完整收录或已完成 MCS 化。
