日期：2026-10-15。范围：第一程四个主节点与配套 Gauss 消元法，网站公开本体 M；学习者记录 E 保持独立。

## 交付内容

第一程现在以同一个方程组 `x+y+z=2, 2x+3y+z=5` 串联四站，
主目标为“解的情况”。推荐按域、行变换、换元、分类阅读；
也可从行变换直接看分类证明。每站先给问题和直觉，再写条件、
形式陈述、证明或操作，最后有反例、联动、具体自检和回看问题。

这五个节点显式设置 `teaching.readingFirst=true`。节点页先呈现动机与正文中的具体例子，
再提供独立形式摘要；DOM 与屏幕阅读顺序一致。未选择此项的节点维持既有顺序，
英文正文回退也保留该顺序。本次没有把抽象公式删去或折叠。

| 节点 | 实际修改 | 证据边界 |
| --- | --- | --- |
| 域的公理 | 展开运算和量词，证明零乘法、消去律及逆元唯一性，验证 F₂ 模型 | 定义 DEF；页内推导 PROOF；条件作用分析不声称整套公理逐条独立 |
| 初等行变换 | 定义解集、三类整行操作和阶梯形；正反方向证明同解；逐数演算 | PROOF；行最简形唯一性不在本程证明 |
| 线性换元 | 先由重复组合构造新变量，直接给逆公式；证明双射限制到解集仍为双射 | PROOF；不预借矩阵乘法、逆矩阵或行列式；全局双射不说成某个特定解集的必要条件 |
| 解的情况 | 给出任意域上的自由坐标双射及回代证明，分开有限域与无限域 | PROOF；一般证明不依赖秩不变性或换元；有限域有 q^(n−r) 个解 |
| Gauss 消元法 | 明确找主元、换行、跳过整零列、检查常数列、回代及终止性 | 方法步骤 DEF；正确性与终止性命题另记 PROOF；需要可执行的精确域运算和零判断；不提供数值误差保证 |

方法自身的 `ev-jiang-method-elimination` 为 DEF；正确性与终止性命题单列为
`ev-jiang-elimination-correctness`，状态 PROOF，避免把操作步骤当成定理。
含多条矛盾行时，若输出完整增广阶梯形，还需在常数列留下一个主元、消去其下常数；
这不增加未知量。有限枚举同时检查含常数列的阶梯形条件。

没有编写学习者的个人经历，没有把“读过”或“载入路径”写成掌握事件。
第一程的 9 道主节点自检与 1 道方法自检接入原有接口，作答仍按既有规则写入 E，
不会由本次内容修订自动判对或确认掌握。

## 关系与契约

| 两端 | 新登记 | 理由 |
| --- | --- | --- |
| 域 → 行变换 | hardPrereq / definitional-dependency / DEF | 本程方程组的系数和操作参数取自 F，逆操作使用非零元的逆 |
| 域 → 换元 | hardPrereq / definitional-dependency / DEF | 用域中的系数、加乘定义各分量 |
| 行变换 → 分类 | hardPrereq / proof-dependency / PROOF | 正文用同解性把阶梯形的回代结果带回原方程；ref 指向同时列出端点的 ev-jiang-solution-cases |
| 行变换 ↔ 换元的阅读联系 | analogy / ILLUSTRATION | 一端保持原坐标中解集相等，一端通过还原映射保持双射，不互称数学必要前置 |
| 换元 ↔ 参数化的阅读联系 | analogy / ILLUSTRATION | 都检查存在与唯一，但参数集合一般为 F^(n−r)，不是全部 F^n |

原 `rel-jiang-pre-rowops-substitution`、`rel-jiang-pre-substitution-cases` 的 ID 和端点保留，
种类改为类比并补充边界；新增域到换元、行变换到分类两条关系。
行动契约同步：换元的输入为域与函数背景，分类输入为行变换。
分类单独规划只需三个事件；第一程四个里程碑仍恰好四事件，七程整体保持可规划。
