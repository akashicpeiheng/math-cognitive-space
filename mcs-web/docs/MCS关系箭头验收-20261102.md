# MCS 同话题关系箭头与个人备注

2026-11-02，本机实现与验收；同日发布到正式站点。

## 行为

- 同一显示话题内的已登记关系使用 5.5 px 箭杆及 16 px 箭头；高亮为 6.5 px，随缩放保持屏幕尺寸。
- 推导、放缩、应用、对偶分别使用对应颜色与文字；应用同时保留虚线。分类取自公共关系记录，共同归属不生成关系。
- 同话题判据同时检查正式成员关系和画布中的话题归属；跨显示话题的关系保持细线，避免其他分区的关系穿过当前话题形成粗线束。
- 推导保留 AND 汇合、独立前提组和缺失前提提示。不同类型与反向登记分开占用通道，方向沿原记录。
- 类型文字常显在箭头上方，以屏幕坐标避让圆点、节点名称及其他类型文字。点击文字或箭头可查看完整条件、前提和来源。
- 个人备注复用现有账号隔离、修订冲突、删除与撤销机制；本机模式写本机数据库。新增公开形式关系的合法连接校验，拒绝未登记关系。备注不进入 M/L 或分享链接，已有备注以 ✎ 标识。
