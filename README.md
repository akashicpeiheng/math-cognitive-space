# 数学认知空间 MCS

把数学知识节点化、关系网络化，让学习者沿自然思维线索规划学习路径。

这个仓库是 MCS 网站的公开版本：一个从零重建的数学学习与研究一体工作台。
源码仓库：[akashicpeiheng/math-cognitive-space](https://github.com/akashicpeiheng/math-cognitive-space)。
当前已公开源码，并完成本机自托管 + 临时 HTTPS 隧道的首次上线检查；
固定地址、长期托管与完整双账号使用流程仍待验收，状态见 `mcs-web/RELEASE-READINESS.md`。
它把研究专稿里的理论形式直接落在数据模型、算法与界面上——公共本体只读，
学习者状态外置，视图与路线由两者派生。

## 三层结构：M / E / D

| 层 | 是什么 | 存在哪 |
|---|---|---|
| **M**（公共本体） | 节点、证据、行动契约、硬关系；随版本公开修订 | `mcs-web/data/`，装配时算 SHA-256 作为版本 |
| **E**（外部模型） | 学习者档案、事件、作答、误区实例、个人笔记 | 本机 SQLite（`mcs-web/runtime/`）；公网 PostgreSQL |
| **D**（派生结果） | 局部化视图、候选路线、复习位置、检查结果 | M + E 现算，不写回 M |

学习过程中的任何动作都只是 E 里的一条事件，界面是它的投影。
「标记已读」不代表掌握；只有学习者自己显式确认，节点才会进入可用背景。

## 快速开始

需要 Node.js 22.12+（开发机使用 Node 24）。证书重放需要 Python 3；
没有 Python 时重放会如实报「无法启动检查器」，不会伪报通过。

    cd mcs-web
    npm ci
    npm run build
    npm run check      # 本体形成检查、证书重放、局部化算子、覆盖清单
    npm test           # 全部验收（内核 / API / 浏览器 / 无障碍 / 动效 / 性能）
    npm start          # http://127.0.0.1:3784

浏览器验收需要本机装有 Chrome / Edge / Chromium，或用
`npm install --no-save playwright && npx playwright install chromium`。
找不到时脚本会打印安装方法并**跳过**；CI 里设 `MCS_WEB_REQUIRE_BROWSER=1`
之后跳过会变成失败。

## 内容规模

公共本体包含六组贯通案例（极限与连续、C^k 与光滑流形、张量与张量场、群、
微分几何 30 个核心节点、两套教材凝练路径），每个节点带形式负载、证据状态与边界声明。
每一条关键断言都标注证据状态：`DEF / PROOF / REF / FINITE / ILLUSTRATION / NOT-CLAIMED`。

## 部署形态

服务有两种互斥形态，由 `publicMode` 区分，默认是**本机工作台**：只监听回环，
写入口只接受本机来源，没有账号概念——每台机器一份自己的 SQLite。

公网模式（`publicMode: true`）需要显式配全：https 站点地址、服务域名白名单，
以及账号体系（`auth.mode = "supabase"`，GitHub OAuth 与邮箱密码）。
任一项缺失或不合格都会**在监听端口之前拒绝启动**，而不是启动成一个谁都能写的服务。

身份与权限都在服务端判定，不靠隐藏入口：

- 访客只能读公共本体与它的派生结果；写请求要登录，且公网下还要带 CSRF 令牌与同站来源；
- 个人档案、事件、笔记、视图、任务、辅导会话按账号归属，越权访问与"不存在"同形（404）；
- 入库 / 发布 / 撤回 / 全站备份恢复只给管理员，管理员按认证服务用户 id 显式配置；
- 计划任务有界排队（默认并发 1、队列 20、每账号 1 运行 + 1 排队、单任务 60 秒）。

配置项与验收清单见 `mcs-web/README.md` 的「部署形态」一节；
本版本已有 PostgreSQL 学习数据与会话存储、登录页面和服务端权限检查。
既有实测已记录自托管 HTTPS 与 GitHub 登录；真实云端 PostgreSQL、长期托管、
完整双账号使用与备份恢复仍需验收。自托管例外可显式使用独立 SQLite，见部署清单第 7 节。
邮箱注册与找回需要发信服务；未配置时应关闭邮箱入口对应的服务能力。

Vercel 部署还需处理本地 SQLite 编写库、文件发布目录、内存任务状态与证书重放环境。
仅发布 Vite 构建目录无法提供完整的 API、登录或学习记录功能。
详细条件见 [GitHub 与 Vercel 发布说明](mcs-web/docs/GITHUB-VERCEL.md)。

## 第一次打开会看到什么

站点按「先定方向、再看材料」组织，建议的顺序与实际入口一一对应：

1. **首页 `/`**：六幕叙事，说明这个空间要解决的问题与它的三层结构（M / E / D）。
2. **开始学习 `/start`**：三个问题定方向（想学什么、什么节奏、从哪进），
   答完给出一份「你的起点」——每个入口都写明为什么给它。偏好只写本机浏览器。
3. **介绍与方法 `/intro`、`/method`**：网站的方法论与带简介的方法库。
4. **数学对象 `/nodes` → `/nodes/:id`**：以当前版本的节点清单为准，节点页有形式负载、
   证据状态、条件反例与学习动作；页面上可以标记已读、记录「还不懂」、写个人笔记。
5. **组建网络 `/network`**：把节点按关系族连成图，保存/载入自己的视图。
   连线区分已登记关系与辅助线索；目前没有经校准的认知成本或学习时长权重。
6. **规划 `/plan`**：给出目标与预算，规划器在事件界内搜索最少事件路线；
   搜索被截断时如实报 `Unknown`，不把「没搜到」说成「无解」。
7. **我的学习 `/profile`**：进度、复习队列、自检任务、数据导出。
8. **研究台 `/lab`、网站维护 `/maintenance`**：公开问题、专稿覆盖、证据义务、
   局部化算子与关系运算的对照表。
9. **辅导 `/tutor`**：可选接入 DeepTutor；没有配置时如实显示「未连接」，不伪造可用。
   自动关联 `/authoring` 是把对象写成受限形式语言、自动发现关系并审阅入库的维护入口。

学习者状态写入 E 层（本机 SQLite / 公网 PostgreSQL），学习操作只读公共本体 M；
「标记已读」不等于掌握，只有你自己显式确认过的节点才会进入可用背景。
