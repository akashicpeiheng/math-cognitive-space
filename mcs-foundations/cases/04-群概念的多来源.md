# 案例 04　群：几何、置换与模乘法的汇合

## 1　同一数学目标与三个入口

公共群节点 Group 的对象为 (G,·,e,inv)，满足结合律、左右单位及左右逆。使用此带运算签名可以直接表达公理；非空由常元 e 保证。交换律不属于群的定义。

| 入口节点 | 对象与证明 | 与抽象群的联系 |
|---|---|---|
| Perm(X) | X 上双射，运算为复合，单位为恒等，逆为逆映射 | 复合结合且双射封闭，直接满足群公理 |
| TriangleSym | 平面中保持一个给定等边三角形的刚性对称 | 复合/逆仍保持图形，属于变换群 |
| Units5 | {1,2,3,4} 的模 5 乘法 | 2 的幂依次为 1,2,4,3，形成循环四元群 |
| Group | 上述公理的抽象结构 | 三个入口分别给出例子/抽象路线 |
| Cayley | 每个群嵌入其底集的置换群 | 严格汇合桥梁，不只是相似度 |

Units5 中以 2^i·2^j=2^{i+j mod4} 验证闭合与结合，单位为 1，逆由指数取负给出。三角形对称可通过其对三个顶点的作用作置换表示；有三个旋转和三个反射，作用忠实。局部几何图像提供动机，不替代群公理检查。

## 2　Cayley 桥梁的完整证明

对群 G 的每个 g，定义 L_g:G→G，L_g(x)=gx。L_{g⁻¹} 是其逆，故 L_g 是双射。并且对所有 x，

\[
(L_g\circ L_h)(x)=g(hx)=(gh)x=L_{gh}(x).
\]

故 g↦L_g 是群同态。若 L_g=L_h，在单位元 e 处取值得 g=h，故同态单射。像是 Perm(G) 的一个子群，因此每个群同构于某个置换群的子群。∎

结论不是“每个群都是有限对称群”，也不是“每个群与某个完整的 S_n 同构”。当 G 无限时，其底集置换群也相应无限。

非交换反例取 S₃：按右侧先作用约定，(12)(23) 与 (23)(12) 对 1 的像分别为 2 与 3，故不相等。Units5 的交换性因此不能推广到所有群。

### 2.1　抽出单射步骤：为什么右单位已经足够

上面的证明在不同位置使用了不同条件。为看清单射步骤真正依赖什么，先暂时只保留二元运算和右单位，把群中的这一步放到更宽的结构里检验。

**PROOF。** 设 \(G\) 为载体，\(\mu:G\times G\to G\)，\(e\in G\)，并满足 \(\forall x\in G,\ \mu(x,e)=x\)。定义

\[
\lambda:G\longrightarrow G^G,\qquad
\lambda(g)=L_g,\qquad L_g(x)=\mu(g,x).
\]

则 \(\lambda\) 单射。概括证明是在同一个特殊点 \(e\) 处读取函数等式：若 \(L_g=L_h\)，则

\[
g=\mu(g,e)=L_g(e)=L_h(e)=\mu(h,e)=h.
\]

这里证明的是“不同的 \(g\) 给出不同的左乘函数”，并未声称每一个 \(L_g:G\to G\) 都单射。后者在群中成立，但需要另用群条件。例如取 \(\mu(x,y)=x\)，每个元素都可作右单位，\(g\mapsto L_g\) 仍单射；只要载体至少有两个元素，每个 \(L_g\) 就是非单射的常值函数。∎

**条件调查。** 删除右单位律，在 `Bool` 上取恒为 `false` 的运算：`false` 与 `true` 不相等，左乘函数却相同，而且不存在右单位。删除 \(L_g=L_h\) 假设，仍在 `Bool` 上取 \(\mu(x,y)=x\)、\(e=\mathrm{false}\)：右单位律成立，两个不同元素的左乘函数不同，因而不能无条件断言 \(g=h\)。两个见证分别保留另一前提，说明被删除的条件不能从该推断中直接去掉。

### 2.2　Lean 中实际证明了哪四个目标

形式化先在 [Expected.lean](../lean/MCS/Expected.lean) 中固定命题，再用 [Group.lean](../lean/MCS/Proofs/Group.lean) 提供证明，最后由固定目标包装接受它。一般单射目标为：

```lean
def rightUnitInjective : Prop :=
  ∀ (G : Type u) (mul : G → G → G) (e : G),
    (∀ x, mul x e = x) → ∀ g h,
      (fun x => mul g x) = (fun x => mul h x) → g = h
```

其证明恰好实现“在右单位处取值”，在工程的 `MCS.Proofs` 命名空间中为：

```lean
theorem rightUnitInjective : Expected.rightUnitInjective.{u} := by
  intro G mul e rightUnit g h same
  have atUnit := congrFun same e
  simpa only [rightUnit] using atUnit
```

| 已登记目标（统一前缀 `MCS.Verified.`） | 数学内容 | 与本案例的对应 |
| --- | --- | --- |
| `rightUnitInjective` | 任意右单位结构中 \(g\mapsto L_g\) 单射 | §2.1 的一般命题 |
| `groupSpecialization` | 群中的同一结论 | 把群的 `mul_one` 代入一般命题 |
| `missingRightUnit` | 存在无右单位、左乘函数相等而元素不同的结构 | 恒 `false` 运算的删条件反例 |
| `missingEquality` | 存在满足右单位律、元素不同且左乘函数不同的结构 | 左投影运算的删条件反例 |

这些目标的证明属于 **PROOF**。两个反例虽取有限载体，交付的是存在命题的 Lean 证明项；它们与仅枚举若干实例的 **FINITE** 检查分开登记。登记号为 `lean-group-injective`，见[运行报告](../lean/reports/lean-group-injective.json)和[验收边界](../15-验证与完成标准.md#159lean-接口的验收入口)。

**覆盖边界。** 左乘双射、复合同态、像子群及完整 Cayley 桥梁尚未纳入此 Lean 登记；原文对应也仍待独立人工审阅。第 2 节的完整正文证明与这里的局部机器证明各有范围，不能由单射步骤通过推断完整桥梁已经机器认证。

**思想与方法。** 将长证明拆出一个条件更弱的局部结论，再把特例放回原证明；在本节使用“特殊点求值”与“逐条件反例”核对依赖。自检时应分别回答：保证 \(g\mapsto L_g\) 单射和保证每个 \(L_g\) 双射，各用了哪些条件？

## 3　概念支持与公开行动

Group 的选定定义支持为 {集合,二元运算,结合律,单位,逆}；Perm 的支持为 {映射,复合,双射,恒等,逆映射}；Cayley 的证明支持是群公理、左乘映射及单射。三个支持族的交和差提供路线比较，C_all 不承担这个功能。

| 行动 | 输入 I | 输出 O | 见证类型 |
|---|---|---|---|
| g_perm | 映射、复合、双射 | Perm 例子 | 公理逐项检查 |
| g_geom | 刚性变换、三角形 | TriangleSym 例子 | 对称闭合及顶点作用 |
| g_mod | 同余、模乘法 | Units5 例子 | 幂表及群律 |
| g_abs_p | Perm 例子、抽象规则 | Group 呈现 | 从例子提炼同一公理模板 |
| g_abs_g | TriangleSym 例子、抽象规则 | Group 呈现 | 相同公理模板 |
| g_abs_m | Units5 例子、抽象规则 | Group 呈现 | 明确不保留偶然交换性 |
| g_cayley | Group、映射、双射 | Cayley | 上节证明 |
| g_noncomm | Perm 三元素例子 | NoncommExample | 两个复合的显式计算 |

三个 g_abs 行动认证的是一个共同定义的呈现与例子对应，不认证“看过一个例子就学会所有群”。要证明 Cayley 仍需其声明输入。

公共方法节点包括“从特例切入”“抽象共同运算”“寻找不变量”和“构造反例”。以 Units5 的偶然交换性为失败边界，以 S₃ 为反例；抽象时既记录保留条件，也记录丢弃条件。

## 4　外部模型、局部化与路线

E_A 确认几何对称及图形操作，符号复合待诊断；E_B 确认同余计算，图形操作未知。A 获得 g_geom→g_abs_g，B 获得 g_mod→g_abs_m。若 E_C 确认函数复合，则可选 g_perm→g_abs_p。公共 M 的三条路线始终同时存在。

从同一目标 Group 回溯，LC13 保留三种 OR 入口；LC25 的共同核心主要是抽象规则与目标接口，不因此声称零背景可学；LC26 显示几何、模算术和映射的专用支持；LC27 标明三路输出是同一 Group 引用。Cayley 另构成严格桥接，并不使三个入口的认知状态相等。

对固定某一路线，事件 e_entry<e_abs<e_cayley；e_cayley 的映射/双射输入若不在背景，就由额外事件先提供。NoncommExample 可以在相应置换资源可用时执行，用来修正 E_B 的外部交换性误推断。该误区不是 Group 节点的属性。

历史来源是 Stillwell 第 19 章 §19.1（印刷 291–292 / PDF 307–308），讨论几何、数论和方程论的多来源。此处路线为现代重构，不宣称复现历史顺序，也不把历史先后设为硬先修。

## 5　模板与验收

Group 概念模板填写定义、典型例、非例、变体、动机、支持、自检和路线；Cayley 使用定理与证明模板；S₃ 使用反例模板；“从特例切入”使用全局方法模板。开放问题式任务可问“给定有限运算表是否为群”，检查有限表的群公理可判；这不意味着任意无限结构群性质都可判。

自检：①在 Units5 中求 3 的逆；②写出 L_g 为双射的逆；③指出 Cayley 单射证明为何使用 e；④解释为什么模乘法例子的交换性不是群公理。
