## 已落实的学术修改

1. 将完整专稿改写为有摘要、问题、相关工作、主结论、案例、实验边界与讨论的英文论文。
2. 用极限的两种表述贯穿正文，给出普通数学证明、动作端口表和事件图。
3. 明确三个主结果的假设：概念出现饱和、带来源资源的组合保持、有界搜索的相对完备性；附录逐项审查失效边界。
4. 区分公共数学资源 M、外部学习者模型 E、派生路线 D，保留未知状态和隐藏资源边界。
5. 加入等信息增强图基线，并如实保留与 MCS 相同的结果。
6. 将实际通过的常值函数局部证书接入一条证明资源路线；完整极限桥梁仍标为正文证明。
7. 收录可复现代码、输入哈希和结果。新增案例包含 11 个拒绝测试，以及两个明确标为假设的学习者画像。
8. 参考文献限定为核对过元数据和相关段落的五个来源；披露 AI 辅助范围。

## 本地复现

从本目录执行：

    python anc/run.py --output replay-new

输出目录须不存在。三组原验证在临时副本中执行，随后运行新路线案例。Python 3.10 是语法与依赖目标；实际运行环境为 Python 3.14.7，未声称验证所有中间版本。

已有 TeX 环境中编译论文：

    python build.py

生成并解压检验一个新包：

    python package.py --output dist/mcs-arxiv-source-new.zip

打包脚本使用文件白名单，不收录编译缓存、历史稿、中文内部说明或个人目录。它从解压目录重跑四份稳定报告并逐字节比较，再使用包内 main.bbl 独立编译。ZIP 已存在时拒绝覆盖。原始上游文件由 anc/upstream-manifest.json 固定。
