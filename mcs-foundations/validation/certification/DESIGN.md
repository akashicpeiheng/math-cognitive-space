# 最小认证内核：范围、构造与保持义务

#MCS #数理逻辑 #认证 #研究工程

## 总览、前置与动机

本实现检查一份已给出的有限证书，输出指定理论及开放假设下的结论。它是第 02 章的一个规则子集，**没有实现完整 HOL 助理，也没有获得检查器自身的机器可靠性证明**。数学内部需要它来区分“表达相同”和“推理合法”；学习应用需要它来区分“展示材料”和“提供了可使用的证明”。两条需要共同导出构造链：保存表达 → 保存逐步理由 → 重算理由所依赖的假设 → 将版本、理论和结论绑定到公开行动。此链是设计重构，不是历史描述。

必备：简单类型、函数应用、有限树、假设推导。辅助：λ 绑定和自然推演。拓展：Henkin 模型、LCF、解释保真证明。低层阅读可把证书看成带类型的工序单；高层对应定义 2.13 的有限推导见证。工序单的类比只解释检查接口，不能证明规则可靠。

## 两套语法与规范编码（DEF）

JSON 对象项采用 `v / c / logic / app / lambda`。类型为基本类型名或 `['->',域,值域]`。`source` 将命名抽象转成 `lam` 与 de Bruijn `b` 索引；自由变量保留名字与类型。规范序列化为 ASCII 转义、排序对象键、无空白的 JSON；自由参数按完整规范变量代码的字典序排序。类型、节点身份与逻辑等价分别处理。

认证项额外允许 `lift`，其中完整 α 规范抽象是符号身份，实参列表才参与一阶替换。哈希用于文件追踪和登记索引；提升符号是否相同仍比较完整结构。认证公式只允许 `eq / false / and / or / imp / all / ex`；对象真值项不是认证公式。最终对象结论须重算为 `(p# = true)` 并与根结论匹配。

变量同名异类型在同一自由语境中拒绝，变量名不得与该签名中的非逻辑常元名重叠；量词/公理模式内部使用的变量名也受此保守检查约束。此语法限制可能拒绝可改名表达，不会扩大可接受证明。对象项先单独形成、再绑定，不能通过混入认证连接词绕过类型核对。

λ 提升按完整自由参数表和规范抽象重建。嵌套抽象先以新变量打开外层，再递归生成内层提升符号。**翻译与替换一般只可证相等，不保证字面相同**（2.15预备引理）；本实现不把二者不相同当成自动相等。示例所用 β 步均由实际抽象公理实例得出。

## 公理与规则白名单（DEF）

背景模式实现2.11的两值、四个连接词、各已声明类型上的等式/全称/存在、函数外延和抽象解释。每个实例先从模式名及参数生成完整全称闭公式，再比较证书结论；证书没有自行声明 HΣ 成员的入口。模式参数本身同样检查类型。

实现规则：假设、蕴含引入/消去、合取引入/两侧消去、等式自反与指定自由变量上下文的等式替换、全称引入/消去、存在引入/消去。弱化以允许未使用的假设实现；对称和传递由等式替换展开。背景有限理论、公理成员见证、旧闭项定义、递归重放的无开放假设定理引用另有明确入口。

未实现：析取引入/消去、假消去、经典反证、一般派生规则自动展开、规格定义、无限理论枚举成员见证、任意外部助理证书与证明搜索。JSON可表示某些未有推理规则的公式，不代表相关规则已经实现。Choice、Inf不隐式添加；若用户另给有限理论，它的全部句子和版本须随公共契约声明，不由内核保证理论一致。

证明图的所有提交步骤（包括未用步骤）都检查有限性、无环和引用闭合。跨定理引用递归重放登记原证书，并检查版本、理论和内容哈希；开放定理引用暂不支持。最终开放假设由实际叶和解除规则计算，必须与自报字段完全相同。理论公理必须闭合，个人观察和答题记录没有特殊公理入口。

默认资源界：输入文件最多4,000,000字节；JSON树最多150,000项、深度100；整个证书包最多2,000步骤，递归栈额外受Python运行时约束。退出码分别为0接受、1非法、2未支持、3资源不足、4损坏输入。后四者不表示被讨论命题为假。

## 条件删去会怎样（PROOF：具体反例；实现检查另记FINITE）

证明总思路：每条规则只传递在同一赋值下成立的条件；量词引入需要能任意改变见证变量而不改变剩余前提。由此前件解释每道检查。

| 被删除的条件 | 保留其余条件的失败输入/反模型 | 结论如何崩溃 |
|---|---|---|
| 全称引入变量不自由于假设 | 从 y=x 推出 ∀y.y=x；二元素域，x=y=0 | 假设真，但量化y=1使结论假 |
| 存在消去变量不泄漏到结论 | 从 ∃x.x=c，在分支y=c后直接得y=c；c=0、y=1 | 存在式真，但结论依赖未指定见证 |
| 开放叶重算 | 群片段保留L_g=L_h叶却自报空假设 | 把条件性单射步骤错写成任意g=h |
| 提升参数顺序 | 两个同类型自由参数互换，仍宣称原抽象方程 | 返回第一个参数与返回第二个参数混淆 |
| 捕获避免 | 将自由x替换为y进入λy.x | 错把常值函数改成恒等函数 |
| 理论成员见证 | 未登记的“桥梁成立”作为theory叶 | 把目标直接变成公理，失去推导内容 |
| 依赖无环 | 根引用自身 | 没有有限推导树，循环标签不能给出证明 |
| 行动的证据与版本匹配 | 展示记录冒充证书，或旧节点版本引用新负载 | 输入资源未满足公共契约 |

这些例子不是对所有检查条件独立必要性的证明。冗余条件不强造反例；本实现的大小界是可调整的工程限制，不是数学定理成立的必要条件。

## 保真与翻译证明义务

详见机器可读 [obligations.json](obligations.json)。2.8–2.9、3.5、3.7–3.9已有正文论证；其中经典一阶完备性另依赖引用。实现审查只是把函数与规则对照，并有有限反例检验；本轮没有机器元证明。删减规则的实现不继承3.9的完备性，有限枚举不验证一般Henkin完备性。

可信基础包含JSON解析、类型/绑定、替换、λ提升、公理重建、规则核对、Python解释器与运行环境、所选公开理论/节点文件及其来源。外部模型、UI、LLM生成器与缓存标签不签发结论。内核认证的是相对于输入理论的推导；理论可满足性和文件发布者真实性须另行判断。

## 语义方向与原典复核（PROOF / REF）

标准模型满足Henkin模型条件并额外要求全函数域，所以Henkin后承蕴含标准后承。例3.16中“对任意a,b存在从真值到个体的分支函数”在所有标准模型成立，在给出的Henkin模型失败；它反驳的是逆方向。建议中的“标准语义失效句子不能提升”不予沿用。

S01原文印刷83页列选择设施，84页给解释及一般模型定义，85页Theorem 1给出其演算的一致闭公式集的模型结论。本稿未默认选择，因此仍需自己的模型/翻译论证，不能直接将原定理贴在实现上。S07本轮核对摘要和§2的局部文本，未审阅全部证明或版本化源码。详细核对层次见 [sources-audit.json](sources-audit.json)。

## 有限验证与真实发现

独立参考求值器不导入内核。枚举3种结果类型、AST大小1–5、绑定深度≤2、自由变量x,y:i、基本域大小1与2的所有列出项/赋值；这是35个项、175次比较。另核对11个背景模式实例、四案例的42个赋值及两个量词反模型。一般函数域闭合、任意深度和所有模型不在该枚举内。

真实修正记录：最初“省略提升参数”的负例误删了外围项，虽被拒绝，却只触发一般语法错误；复查拒绝原因后，已改为定位 `lift` 并清空其参数表，使失败确实来自提升元数。对存在消去又补了实际使用见证分支的合法证明。不能用一条“测试失败”代替核对它为什么失败。

**思想：条件随证据行走。** 证明能被复用，前提是其理论、假设、类型与版本也被一起带走。方法：规范绑定用于语法节；删条件反例用于规则节；独立语义和受控缺陷用于有限验证；结构比对用于行动适配。

**回看问题：** 若换一个证明生成器，哪些保证仍由检查器承担？若换一个检查器实现，哪些已接受证书必须重放？
