# C　记号、类型与方向

## C.1　基本判断

| 记号 | 类型/含义 | 位置 |
|---|---|---|
| ZFC | 元理论工作背景；不假设 V=L；相对一致性结论分别声明元理论、相关理论及实际假设，不把一致性与传递模型存在混同 | 01 |
| Σ、𝒯 | 有类型符号签名、句子集理论（公理集或其演绎闭包），不指某一结构的真理论 | 01–03 |
| 字体约定 | 高层对象用花体：ℒ_Σ 对象语言、𝒦 模型类、𝒯 理论、ℳ 本体。结构层对象用哥特体：\(\mathfrak A\) 模型（满足对象语言的结构，第 03 章）、\(\mathfrak C_M\) 概念函数（第 05 章）；认知扩展 x 不是这一意义上的模型，而是状态空间与接口的规格。对象层的具体项（数学对象、学习节点、状态、参数）与集合论层级 L 保持普通字体。𝒟 已用于分解规则，派生结果类型记为 DerivedResult。花体与普通体表示不同对象：𝒦 是模型类，K_Σ 是登记概念域 | 01 起 |
| Ξ | 类型环境，形如 x:σ | 02 |
| Γ、Γ₀、Γ_P | 公式假设族；与类型环境不同 | 02、05、06 |
| Ξ⊢Σ t:τ | 良类型项判断 | 02 |
| Γ⊢𝒯 φ | 固定认证演算的推导；Ξ 需要时另列 | 02 |
| t#、φ̂、F_Σ、H_Σ | λ 提升的多排序项/公式翻译、认证语言及背景公理 | 02 |
| A,v⊨φ | 模型与赋值下的满足 | 03 |
| ⊨H、⊨std | Henkin 与全函数标准语义；两者不混用 | 03 |
| Check_𝒯 | 对显式有限实际假设检查证书；理论公理及任意大假设族的成员资格须有可判依据或见证 | 02、06 |

类型 σ→τ 是函数类型，箭头右结合；谓词 α→o 也可作为变量取值并被量化。关系类型 Record→Record→o 不同于承载该关系的记录代码。

## C.2　本体、生成与概念

| 记号 | 含义 | 注意 |
|---|---|---|
| ℳ、R_ℳ、∂ℳ；L、N_L | 数学本体、形式对象域、环境边界；独立公共阅读内容与节点域 | M 与 L 分别版本化，均不含具体学习者 |
| r=(id,k,d) | 不可变知识记录（旧称节点记录） | 逻辑等价不决定身份；旧记号 n、N_ℳ 的迁移见接口迁移表 |
| n=(id,v,Q,B,R,P,g) | 公共学习节点 | 精确对象引用、正文、先修、目标；属于独立 L（04、09） |
| Goals、Competence_L | L 的公共学习目标域及能力维度子域 | 能力维度是公共目标；某学习者是否具备某能力由扩展评价（04、07） |
| G=(语言版本,Σ,Ξ,Δ,Π)、c_G、Atom_G、Molecule_G | 知识构造语法、复合次数、语法原子与分子判断 | 相对固定语法；与外部认知原子 Atom_x 分别命名（02 §2.10） |
| σ | 五级形式尺度标签 0–4：原子、分子、单元、话题、子学科 | 形式组织类型，不推出难度或规模；节点不是成员（09） |
| I_U、I_T、I_S | 成员关系：形式表达→单元→话题→子学科 | 类型合法、无环、允许交叉归属；节点不是成员（09） |
| a_θ、阈值簇 | 候选组织的关联聚簇技术 | 候选簇不自动构成话题或单元（09） |
| U_Σ、F、U_n | 生成候选全集、有限元规则、有限生成阶段 | 下标 n 是自然数，不是任意可计算序数 |
| Payload、Rep、Cert | 正式负载、公开表征、证据档案 | 自然语言证明与已检查代码分标签 |
| K_Σ、κ | 登记概念域、有限代码到概念锚定 | 每个形式概念有闭表示 t_c |
| C_occ | 直接语法出现函数 | 扫描归约前代码 |
| C_all | 全等价形式概念并集 | 条件下等于 K_Σ；不是集合自映射闭包 |
| Θ、S_exp、S_def、S_prf、S_rte | 指定变换规则及四种带见证支持 | 各记录自己的来源与用途 |
| Info(A) | Unknown 或 Known(a)，a∈A | 一般带标签值域 |
| ISet(K)=Info(𝒫(K)) | 概念集合的未知/精确已知值域 | Known(∅) 不等于 Unknown |
| Supp^bounds、α | 部分支持界接口及其到 ISet(K) 的保守投影 | 仅在 L=U 时投影为 Known(L)，否则为 Unknown |
| (L,U) | 可能集合的上下界 L⊆A⊆U | 不是把未知变为假 |
| MinSupp_u(n) | 指定用途的包含极小充分支持族 | 一般非唯一，可为空 |
| Cn_𝒯 | 固定理论下有限前提演绎闭包 | 不是掌握状态更新 |

L_α 与下界记号 L 只在第 01 章及局部公式作为集合论背景比较出现，均由上下文明示，不能据同字母推断两者有关；L 保持普通字体，不写成花体 ℒ，以免与对象语言 ℒ_Σ 混淆。公共阅读内容记为 L，节点域记为 N_L；它们不同于集合论 L_α 和局部下界。

## C.3　关系与路线

| 记号 | 类型/方向 |
|---|---|
| Ded(P,n,p) | 有限带标签前提族 P、结论记录 n、证明代码 p 的三元认证关系 |
| Λ_ℳ、a=(id,I_a,O_a,w,mode) | 公共行动库及有限联合输入/输出契约（端点为记录引用） |
| Rte_ℳ(B,G) | 给定背景 B 与目标 G 的结构路线族；定义先于个性化规划 |
| P_r、act、h_src、ζ | 事件集、行动标记、输入来源、目标生产者 |
| Req_r(g) | g 活跃事件所需的输入资源并集；与概念支持不同 |
| HardPre_r、HardPre_ℛ | 单路线义务、非空指定路线族的共同义务 |
| NewPre_r | 由事件提供而非背景直接给定的活跃输入 |
| HScale_T(a,b,d,m,w) | 硬放缩统一接口：来源 a、目标 b、放/缩方向 d、同载体/结构模式 m、见证 w；反向读取不翻转蕴含或提供逆映射 |
| g≽_H s | 同载体硬放缩中 g 比 s 一般，由 P_s⇒P_g 认证；对应 s→g 的放方向与 g→s 的缩方向 |
| Scale(c,放)、Scale(c,缩) | 固定背景及同载体模式后，放缩两个方向的集合值函数；分别收集更一般概念与更具体子类，不保证单值 |
| R⁰_ℳ、Eval_x、Soft^π_x,s | 公共软关系描述、外部评价、由明确判据激活的结果 |
| S∘R | 先 R 后 S；中介节点存在量化 |
| R^smile、R* | 逆关系、自反传递闭包 |
| F:ℳ→ℳ' | 带语法及证据输送的认证空间态射 |

## C.4　外部认知、局部化与规划

| 记号 | 含义与归属 |
|---|---|
| LearnerRecord、Rec、Project(Rec) | 个人事件记录、其实例及重放投影（7.24） |
| PlanContext、Ctx | 实际请求中的目标及可选条件（7.25） |
| ExtensionPackage、Ext、x、X_x、s | 包类型、本次启用的包及状态族、其中一个包、其状态空间及一个状态（7.26、7.8） |
| Obs_x、Trans_x；O_x、K_x | 观察/转移关系；可选概率核 |
| Anchor_x⊆Item_x×(R_ℳ⊔N_L)×Competence_L | 条目、数学对象或学习节点、能力的多对多观测锚定 |
| Atom_x(s,n;g,ℛ,𝒟) | 相对于目标、表征和分解规则的认知原子性；此处 ℛ 是表征族，n 是学习节点或节点组；与语法原子 Atom_G 分别命名 |
| Inst_x(s,p) | 该状态与公共误区模式的关联判断 |
| DerivedResult | 基础候选、扩展筛选与排序、署名片段和输入版本（12.2） |
| Flat | 单元/话题/子学科到学习节点域的展开；同展开不合并身份（09） |
| g_n、Ctx.goal | L 的公共目标与一次请求的目标，比较方案须注明可用证据及未决候选 |
| Loc_λ(ℳ)=(V,∂V,τ,Pres) | 可见结构、隐藏义务、溯源、逐项保持声明 |
| Project(Rec)、adapt_x | 事件投影与扩展适配器，后者只读声明的输入切片（7.26、11.4） |
| Plan₀、Plan | 前者生成基础候选，后者按显式规则选取见证并投影到有限偏序同构类型（12.1–12.2） |
| Π、χ、ℓ、ev | 完整规划包、排程约束、通过的线性扩张、事件关注节点 |
| h | 事件数量/规划时域上界；与来源函数 h_src 不同 |

符号 ℛ 在硬先修章节表示路线族，在 Atom 的显示式中按用户原式表示表征族；每次都带类型声明。可实施编码中应分为 RouteFamily 与 RepresentationFamily 两个类型，不能共用未分型变量。

证明长度、所用公理数量等结构量可以在 ℳ 中；个人感知难度、预测时长和预期收益由扩展评价。原始数学代码、知识节点、图形显示点与学习事件是四种不同对象。

L 为公共阅读内容，N_L 为阅读节点域；旧 L_M 仅在历史六级模型中使用。I_U、I_T、I_S 分别连接表达到单元、单元到话题、话题到子学科。Flat 展开到形式表达层。
