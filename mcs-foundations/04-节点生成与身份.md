# 04　数学对象、公共学习节点与稳定身份

数学对象规定数学内容，学习节点组织阅读与理解。对象本体 M 与公共学习内容 L 分别版本化；个人事件和明确声明组成 `LearnerRecord`；目标、预算、偏好和策略组成 `PlanContext`；精细认知判断属于可选 `ExtensionPackage`；视图和路线属于 DerivedResult。两类 Markdown 通过准确引用连接，关系多对多并允许跨尺度。旧六级模型及旧学习者接口的迁移见[接口迁移表](publication/接口迁移表.md)。

## 4.1　整个本体的结构签名

**定义 4.1（本体与阅读内容版本）。** 数学本体记为

\[
M=(\Sigma,T,R_M,Payload,Rep^{form},Cert,Supp,\Lambda_M,R_M^0,Agg,\partial M).
\]

这十一个公开坐标依次为语言签名、背景模块、形式对象引用域、形式负载、形式表征规格、证据登记、支持接口、形式行动契约、数学关系、形式模块组织与环境边界。全部不读取学习目标或个人状态。原子、分子以及单元、话题、子学科属于 R_M；数学对象可以含尚未证明的命题，但其语法、类型和引用必须合法。

公共学习内容另记 L=(N_L,Body,Refs,Goals,Pre,Templ,Λ_L,R_L)：阅读节点域、正文、对象引用、学习目标（能力维度是其子域）、学习先修、模板、教学行动及讲解关系。L 不是 M 的一个坐标。一般方法论、动机、比喻与误区讲解属于 L；明确形式化的对应部分可另建 M 对象。数学结构视图读取 M；阅读视图和学习路线按声明读取 M、L 及实际调用的个人输入。**（DEF）**

Record 与 LearnNode 是互异的引用类型；表达、证书和事件另外分型。对它们的有限代码作内部描述，不产生覆盖自身语言的无条件真理谓词。旧 NodeRecord 是兼容协议，不据名称转换为 Record。

**定义 4.2（合法本体与公共内容条件）。** **（DEF）**

| 条件 | 精确要求 |
|---|---|
| 身份功能性 | 同一 ID、版本只有一份负载；同一库不接受重复 ID；发布后的修订显式增版 |
| 形式良构 | 符号、类型、语境、表达和透明定义通过第 02 章的形成检查 |
| 引用封闭 | 对象引用携带 ID、版本、声明锚点和形式摘要；引用环境另显式登记；M 不引用 N_L |
| 组织合法 | 第 09 章的成员类型与导入条件成立；定义依赖和模块导入无环 |
| 证据分离 | 结构合法不推出命题有证明；命题有证明不自动完成接口关系或 HOL—Lean 对应审阅 |
| 行动独立 | 形式行动 Λ_M 不调用个人规划与掌握估计；启发性教学行动属于 Λ_L |
| 支持有型 | 表达/证明/路线支持与输入资源分开；Unknown 不等于精确空集 |
| 阅读合法 | N_L 按定义 4.12 独立校验；解释不取得对象形式负载的权威性 |
| 个人隔离 | 事件、上下文或扩展状态的更新不写入 M 或公共 L；公共修订须走显式版本化入口 |

合法本体不要求存储全部语法候选或全部真后果。有效解析失败的对象文档可以留作草稿，但不能进入本版正式对象库。协议子集未实现的完整理论构造必须明确标为未支持。

## 4.2　知识记录：构造与形成证据

**定义 4.3（不可变知识记录）。** 记录为

\[
r=(id,k,d),\qquad d\in Data_k.
\]

其中 **Data_k 是定义 4.4 中 k 型构造的有限描述负载所成的域**，每份负载描述有限，域本身可以无限；id 是版本内的唯一标识符，k 是构造类型，d 是有类型负载，映射 id ↦ (k,d) 在一个版本内**函数式**（这正是定义 4.2 的身份功能性）。同一有限描述可以有不同来源记录；固定 id 不允许同时指向不同 k,d。若有形式表达，背景记录为 (T,Ξ,Γ,τ)：Ξ 为类型环境，Γ 为公式假设，τ 为表达类型。记录与服务它的学习节点是多对多：一条证明记录可以在多个学习节点中出现，学习节点不复制记录、也不改变记录的身份与负载。

**定义 4.4（内容角色的形式准入条件）。** 下表保留旧构造名称供迁移；只有给出可解析形式规格的行或部分进入 M，首版协议支持程度见 mcs-content 说明。

| 构造类型 | 有限负载 | WF 条件（以及哪些留给另行认证） |
|---|---|---|
| Symbol | 声明、类型、签名版本 | 声明合法；不要求它已有特定真实解释 |
| Term | (T,Ξ,t,τ) | Ξ⊢t:τ；不要求 t 处于某逻辑正规形 |
| Concept | 对象类型、参数、谓词 P | P 类型正确；参数经明确 λ 闭合形成概念表示 |
| Definition | 新符号、旧项、扩张记录 | 默认使用第 03 章的旧语言项定义；更广规格另附实现/闭合证书 |
| Claim | (T,Ξ,Γ,φ) | φ 为 o 型；合法不等于可证 |
| Proof | 目标 Claim、有限证书代码 | 代码语法合法；是否 Check=1 是另一个认证字段 |
| Example | 概念引用、对象规格、满足断言 | 类型及引用正确；满足性另证，不能假称任意模型都可判 |
| Counterexample | 精确目标、对象规格、失败见证 | 引用和量词类型正确；确实反驳另需证书 |
| Problem | 输入输出、目标规格、约束 | 任务接口类型正确；是否已解决另有公共来源记录 |
| Theory | 语言、演算、公理呈现/模块引用 | 有限呈现代码或明确的环境理论引用；公理一致性不由 WF 保证 |
| Construction | 输入输出、步骤规格、验证目标 | 有限步骤及引用类型正确；正确性及终止性分别认证 |
| Method | 启发性方法属于 L；只有形式规格进入 M | 严格部分使用 Construction 或 Claim，不以自然语言启发体充当形式负载 |
| Representation | 形式表达及有类型对应规格 | 非形式图解和比喻属于 L；等价或保真另行认证 |
| MisconceptionPattern | 误区讲解属于 L；形式错误规则可另登记 | 形式部分按 Claim/Counterexample 检查；个人是否出现过相关观察属于 `LearnerRecord`，模型解释属于扩展 |

公理、定理、性质是 Claim 的角色：公理角色需要相应理论的成员见证；定理角色需要认证证明或清楚标记的引用证据；性质角色说明用途。全局方法和局部方法是 L 中 Method 的范围标签。上述公理、定理、性质角色是 Claim 的标签，**不改变构造类型 k**；其他构造也可拥有各自的合法角色，例如第 05 章的概念与符号锚定。角色可以重叠，但不把不同构造类型混成一个无型记录。学习节点不是表中的第 15 种构造类型：记录描述数学内容，学习节点描述一次学习的组织（定义 4.12），两者不互相替代。

**命题 4.5（良构与真理分离）。** 在有效呈现及有限形成见证条件下 WF 可判，但**仅由 WF(r) 不能推出**记录命题为真或可证（WF 再加上相应的认证字段可能给出更多，见定义 4.4 各行的区分）。**（PROOF）**

**证明。** 表格中的 WF 只执行有限解析、类型、引用与证书格式检查；理论成员需要可判的引用见证。Claim 构造允许任一良类型 φ，因此也允许 φ 与 ¬φ；它不可能仅凭语法就同时认证二者为数学真理。∎

对任意无有效呈现的理论仍可定义语义记录，但不能沿用本命题的算法承诺。记录可以只承载一次已核对的计算或一个失败见证；学习节点（定义 4.12）能否满足一次学习目标，是另一件事，不由本命题回答。

## 4.3　有限生成与自动枚举

**定义 4.6（候选宇宙）。** 固定有效可数符号表、有限字符串编码、规则表与公开理论呈现集合。种子 S 包含符号声明、有限描述原子及背景模块代码。自动生成所用的种子、规则索引与理论引用须有有效枚举，成员调用携带有限形成或枚举见证；仅有可数性不足以保证可枚举。F 是单调的有限元构造规则族（X⊆Y ⟹ F(X)⊆F(Y)），实例通过可判形成见证核验。置

\[
U_0=S,\qquad U_{n+1}=U_n\cup F(U_n),\qquad
U_\Sigma=\bigcup_{n<\omega}U_n.
\]

每份记录描述是有限树或有限带引用记录；引用目标采用已有合法记录或明确环境代码。相互引用的公共导航边可以后登记，不把未证的循环定义当作形式内容。

**定理 4.7（最小生成）。** 设 F 单调，则 U_Σ 是包含 S 的最小 F-闭集合；可数种子与可数有效规则产生可数 U_Σ。**（PROOF）**

**证明。** 每次构造仅用有限多个输入，其阶段编号有最大值，输出位于下一阶段，故 U_Σ 闭合。设 Y⊇S 且 F(Y)⊆Y：U_0=S⊆Y；若 U_n⊆Y，由单调性 F(U_n)⊆F(Y)⊆Y，故 U_{n+1}⊆Y；归纳得各 U_n⊆Y，故 U_Σ⊆Y。有限元规则作用于可数域的有限元组所得结果可数，可数并仍可数。∎

这里使用 ω 阶段就足够，不将 L_α 的超穷层级移植到有限语法。

**定义 4.8（公平候选生成）。** 按自然数代码递增枚举全部有限描述，或先编码到固定有限字母表，再按编码长度及层内字典序枚举；逐一检查合法的形成树，输出通过者。不能只按可数无限符号表中的符号个数逐层耗尽，因为长度为 1 的一层就可能无限。对公理枚举见证和证明搜索采用交错枚举。每个有限合法候选最终被访问。避免重复可用规范代码集合，但不把逻辑等价当作去重判断。

**命题 4.9（枚举覆盖与边界）。** 每个有有限合法描述及有限认证见证的候选最终输出；不保证在有限时间输出全部候选，也不保证识别全部标准语义真理。**（PROOF）**

**证明。** 其全部代码、规则索引和见证长度有有限最大界，枚举到足够预算时包含该对象。不存在的证据可能被永久搜索，因此整体决定性不随之成立。∎

自动生成的是基础表达、记录及证书候选；有效检查进一步产生认证层。人工选择研究重点及添加公开解释，不负责穷举基础语法。

**说明（枚举覆盖的是记录候选）。** 学习节点由组织接口登记（定义 4.12），其字段与引用可作有限检查；可以枚举候选组织，但定理 4.9 的覆盖边界不自动延伸为“组织得是否合适”，后者属于第 09 章的组织依据与第 10 章的内容检查。

## 4.4　稳定身份与版本

**定义 4.10（记录与学习节点的相等）。** 记录相等按 id,k,d；学习节点相等按其不可变负载 (id,v,Q,B,R,P,g) 的函数式映射。表达可另按 α、βη、可证等价或模型外延相等比较，各自带类型和背景。后四者都不自动推出记录相等或学习节点相等。

规范表达锚定可以对 α 代码采用一个确定的生成引用；带不同来源、角色或材料的记录仍独立存在。这样允许机械识别绑定名差异，又保留不同内容记录。

独立的来源记录不必全部成为第 05 章 κ 的同码别名。该查询须有限返回，因此在固定登记版本中，同一规范表达只登记有限个概念锚点；更多来源经独立的溯源关联保存，不据此合并记录身份。

**命题 4.11（学习者替换保持身份）。** 若 M 与 L 固定，任意两个 `LearnerRecord`、`PlanContext` 和 `ExtensionPackage` 输入只通过只读引用接入，则它们对记录身份、WF、已登记证明的 Check 结果，以及学习节点的字段、目标与注册摘要给出相同值。**（PROOF）**

**证明。** 这些判断均只读取固定的 id、负载、签名、证书与学习节点字段，不读取外部状态。函数性给出相等。∎

新增证明应建立新 Proof 记录并追加认证关联，不改旧证明内容；改写定义正文则建立新版本并给兼容/翻译说明。学习者答对题只更新外部记录，不能借用“版本更新”绕过此隔离。

## 4.5　学习节点：引用、内容、先修与目标

**定义 4.12（学习节点）。** 公共学习节点 n=(id,v,Q,B,R,P,g) 属于 N_L。id,v 为独立身份和内容版本；Q 为有限精确对象引用列表；B 为非空 Markdown 讲解正文；R 为讲解角色关系；P 为显式学习先修；g 为公共学习目标和可检查的承诺。Q 可以引用任意多个尺度对象或模块，同一对象可被多篇节点引用。纯方法论节点可取 Q=∅，但不能提供对象层的形式证据。**（DEF）**

形成检查要求身份唯一、引用版本/锚点/摘要有效、正文非空、目标非空，学习先修指向准确版本的阅读节点；不根据正文标题推断对象身份。协议首版把 R 留在正文，目标与检查任务写在 goals；Q 对应 objects，P 对应 prerequisites。学习节点没有数学尺度，不能作为形式模块成员。

完整性表示完成本篇承诺，不代表正文数学内容都已证明，更不表示学习者已经掌握。可在正文中完整讲解一个推论，也可独立写一篇证明节点，两者共用同一 M 声明。个人目标属于 `PlanContext.goal`，公共目标属于 L；规划器读取指定公共版本，将本次适配写入 `DerivedResult`。

对象正文仅为注释，权威数学内容来自形式负载。节点摘要覆盖目标、引用和讲解，完整文件摘要另覆盖原始字节；对象形式摘要只覆盖形式结构与依赖。因此修改讲解不改变对象身份或形式摘要。跨工具的具体摘要算法由共享实现固定，不以“语义等价”代替摘要比较。

## 4.6　方法节点：形式规格与启发体的边界

**定义 4.13（方法记录接口）。**

\[
\mathrm{meth}=(name,scope,In,Out,Pre,Post,Use,Demo,Fail,body).
\]

该接口首先属于公共 L，不是一项形式对象准入豁免。In/Out 为任务与候选结果的类型；Pre/Post 是有明确语义的条件，允许标注尚不能完全形式化的范围；Use 是结构性概念锚定；Demo/Fail 是公共案例及失败范围；body 是自然语言启发体。WF 检查字段格式与引用，不谎称可以判定一切 Pre/Post。

全局方法包括直觉建立与失效、内省、从特例切入、反例构造、逆向分析、不变量、应用替代练习、可视化。局部方法如“用夹逼估计处理特定极限”，可实例化全局策略。一个方法若后来取得严格算法和正确性证明，可另建 Construction 与 Proof 记录；启发内容与形式实现通过显式关系连接，不偷换。

一般方法呈现可作为 Λ_L 中的公开行动，但其证书仅保证任务接口匹配及内容合法。学习成功率、难度、掌握变化均由第 07 章外部模型评价。

## 4.7　学习节点与外部认知接口

本体记录是可独立引用并具有明确输入输出接口的知识描述；学习节点是组织接口；两者都**不是预设对所有人的最小心理单位**。本体保存分解候选及重构契约；认知原子性

\[
\operatorname{Atom}_x(s,n;g,\mathcal R,\mathcal D)
\]

由第 07 章定义在扩展中，其 n 是学习节点或节点组。给定学习目标和表征，某学习节点可整体呈现，也可分解成多个目标；这是扩展组块及派生视图的差异。语法原子 `Atom_G`（定义 2.19）与扩展原子 `Atom_x` 分别命名、不得混用：同一学习节点可以在一个扩展中整体呈现、在另一个扩展中拆开，而语法尺度不随模型变化。

有限可判的分解域可供穷举最小性检验；一般“没有想到更小分解”不是极小性证明。方法记录也可参与这类分解，但不能强制其启发体成为封闭形式公式。

## 4.8　从本体到具体网络

知识网络是合法本体 M 的关系呈现；学习网络是 `(M,L,LearnerRecord,PlanContext,Extensions)` 的派生结果；可视化网络是带溯源和保持声明的显示投影。画图中的一个点可以是记录、学习节点、聚合或事件，必须标注其类型。不同图的点数、布局和显示标签不决定本体同构。

概念函数、第 06 章关系、第 08 章结构保持映射、第 11 章视图、第 12 章规划都以本章接口为输入。外部模型的知识空间可以成为一个 Theory/Model 描述记录，但其某位学习者的实际状态始终不是 M 的一项运行数据。
