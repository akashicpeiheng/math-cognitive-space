# C　记号、类型与方向

## C.1　基本判断

| 记号 | 类型/含义 | 位置 |
|---|---|---|
| ZFC | 元理论工作背景；不假设 V=L；相对一致性结论分别声明元理论、相关理论及实际假设，不把一致性与传递模型存在混同 | 01 |
| Σ、𝒯 | 有类型符号签名、句子集理论（公理集或其演绎闭包），不指某一结构的真理论 | 01–03 |
| 字体约定 | 高层对象用花体：ℒ_Σ 对象语言、𝒦 模型类、𝒯 理论、ℳ 本体、ℰ 外部模型。结构层对象用哥特体：\(\mathfrak A\) 模型（满足对象语言的结构，第 03 章）、\(\mathfrak C_M\) 概念函数（第 05 章）；外部认知模型 ℰ 不是这一意义上的模型，而是状态空间与接口的规格。对象层的具体项（节点、状态、参数）与集合论层级 L 保持普通字体。𝒟 已用于分解规则，派生结果暂记普通 D。花体与普通体表示不同对象：𝒦 是模型类，K_Σ 是登记概念域 | 01 起 |
| Ξ | 类型环境，形如 x:σ | 02 |
| Γ、Γ₀、Γ_P | 公式假设族；与类型环境不同 | 02、05、06 |
| Ξ⊢Σ t:τ | 良类型项判断 | 02 |
| Γ⊢𝒯 φ | 固定认证演算的推导；Ξ 需要时另列 | 02 |
| t#、φ̂、F_Σ、H_Σ | λ 提升的多排序项/公式翻译、认证语言及背景公理 | 02 |
| A,v⊨φ | 模型与赋值下的满足 | 03 |
| ⊨H、⊨std | Henkin 与全函数标准语义；两者不混用 | 03 |
| Check_𝒯 | 对显式有限实际假设检查证书；理论公理及任意大假设族的成员资格须有可判依据或见证 | 02、06 |

类型 σ→τ 是函数类型，箭头右结合；谓词 α→o 也可作为变量取值并被量化。关系类型 Node→Node→o 不同于记录该关系的节点代码。

## C.2　本体、生成与概念

| 记号 | 含义 | 注意 |
|---|---|---|
| ℳ、N_ℳ、∂ℳ | 本体版本、节点引用域、环境版本边界 | 不含具体学习者 |
| n=(id,k,d) | 不可变节点记录 | 逻辑等价不决定身份 |
| U_Σ、F、U_n | 生成候选全集、有限元规则、有限生成阶段 | 下标 n 是自然数，不是任意可计算序数 |
| Payload、Rep、Cert | 正式负载、公开表征、证据档案 | 自然语言证明与已检查代码分标签 |
| K_Σ、κ | 登记概念域、有限代码到概念锚定 | 每个形式概念有闭表示 t_c |
| C_occ | 直接语法出现函数 | 扫描归约前代码 |
| C_all | 全等价形式概念并集 | 条件下等于 K_Σ；不是集合自映射闭包 |
| Θ、S_exp、S_def、S_prf、S_rte | 指定变换规则及四种带见证支持 | 各记录自己的来源与用途 |
| Info(A) | Unknown 或 Known(a)，a∈A | 一般带标签值域 |
| ISet(K)=Info(𝒫(K)) | 概念集合的未知/精确已知值域 | Known(∅) 不等于 Unknown |
| Supp^bounds、α | 部分支持界接口及其到 ISet(K) 的保守投影 | 仅在 L=U 时投影为 Known(L)，否则为 Unknown |
| (L,U) | 可能集合的上下界 L⊆A⊆U | 不是把未知变为假 |
| MinSupp_u(n) | 指定用途的包含极小充分支持族 | 一般非唯一，可为空 |
| Cn_𝒯 | 固定理论下有限前提演绎闭包 | 不是掌握状态更新 |

L_α、L 只在第 01 章作为集合论背景比较出现。符号 L 在局部公式里也可能指下界，均由上下文明示，不能据同字母推断两者有关；L 保持普通字体，不写成花体 ℒ，以免与对象语言 ℒ_Σ 混淆。

## C.3　关系与路线

| 记号 | 类型/方向 |
|---|---|
| Ded(P,n,p) | 有限带标签前提族 P、结论节点 n、证明代码 p 的三元认证关系 |
| Λ_ℳ、a=(id,I_a,O_a,w,mode) | 公共行动库及有限联合输入/输出契约 |
| Rte_ℳ(B,G) | 给定背景 B 与目标 G 的结构路线族；定义先于个性化规划 |
| P_r、act、h_src、ζ | 事件集、行动标记、输入来源、目标生产者 |
| Req_r(g) | g 活跃事件所需的输入资源并集；与概念支持不同 |
| HardPre_r、HardPre_ℛ | 单路线义务、非空指定路线族的共同义务 |
| NewPre_r | 由事件提供而非背景直接给定的活跃输入 |
| g≽_H s | g 比 s 一般；同载体时由 P_s⇒P_g 认证 |
| HSpec、Spec(g) | 泛化的逆关系、特化的集合值函数；不是逆单值函数 |
| R⁰_ℳ、Eval_ℰ、Soft^π_ℰ,s | 公共软关系描述、外部评价、由明确判据激活的结果 |
| S∘R | 先 R 后 S；中介节点存在量化 |
| R^smile、R* | 逆关系、自反传递闭包 |
| F:ℳ→ℳ' | 带语法及证据输送的认证空间态射 |

## C.4　外部认知、局部化与规划

| 记号 | 含义与归属 |
|---|---|
| ℰ、X_ℰ、s | 外部模型、其状态空间及状态 |
| Obs_ℰ、Trans_ℰ；O_ℰ、K_ℰ | 观察/转移关系；可选概率核 |
| Anchor_ℰ⊆Item_ℰ×N_ℳ×Competence_ℳ | 条目、节点、能力的多对多观测锚定 |
| Atom_ℰ(s,n;g,ℛ,𝒟) | 相对于目标、表征和分解规则的认知原子性；此处 ℛ 是表征族 |
| Inst_ℰ(s,p) | 该状态与公共误区模式的关联判断 |
| D(ℳ,ℰ,s,g,b,ρ) | 明确输入决定的派生结果（含适配视图、评价、路线与呈现）；只读 ℳ。自变量是输入，Loc_λ(ℳ) 与 Plan(V) 是它的分量而非自变量 |
| Flat | 话题/领域/学科对象到节点域的展开 |
| Loc_λ(ℳ)=(V,∂V,τ,Pres) | 可见结构、隐藏义务、溯源、逐项保持声明 |
| Adapt(ℰ,s,g,b) | 从外部输入产生局部化参数 |
| Plan_M,ℰ,s,g,b,ρ:View_M ⇀ FinPos | 部分规划函数；视图映到有限事件偏序的同构类型，行动/来源/外部约束另存结果包 |
| Π、χ、ℓ、ev | 完整规划包、排程约束、通过的线性扩张、事件关注节点 |
| h | 事件数量/规划时域上界；与来源函数 h_src 不同 |

符号 ℛ 在硬先修章节表示路线族，在 Atom 的显示式中按用户原式表示表征族；每次都带类型声明。可实施编码中应分为 RouteFamily 与 RepresentationFamily 两个类型，不能共用未分型变量。

证明长度、所用公理数量等结构量可以在 ℳ 中；个人感知难度、预测时长和预期收益在 ℰ 中。原始数学代码、知识节点、图形显示点与学习事件是四种不同对象。
