# 04　知识记录、学习节点与稳定身份

本章从有类型有限语法生成候选**知识记录**，再定义合法知识本体；记录承载数学内容与证据，**学习节点**把记录组织成一次可独立引用的学习。两类对象分属不同域、分别检查身份。“对谁是最小认知单元”移至第 07 章，不进入生成规则或身份判定。旧版把不可变记录称为“节点”；本次重写把记录改称 Record（记录），把六级尺度中的节点改称 LearnNode（学习节点），记号 \(N_M\) 拆分为 \(R_M\) 与 \(L_M\)，逐项对照见[接口迁移表](publication/接口迁移表.md)。

## 4.1　整个本体的结构签名

**定义 4.1（本体版本）。** 一份集合大小的本体版本记为

\[
M=(\Sigma,T,R_M,L_M,Payload,Rep,Cert,Supp,\Lambda_M,R_M^0,Agg,Templ,\partial M).
\]

Σ,T 是公开语言与背景模块；**R_M 是知识记录引用域**（不可变记录，定义 4.3）；**L_M 是学习节点引用域**（组织接口，定义 4.12）；Payload 是不可变负载解释；Rep 给表达及公开表征；Cert 是已登记证书与认证状态；Supp 是第 05 章的支持接口；Λ_M 是第 06 章的公开行动契约；R⁰_M 是通用关系描述；Agg、Templ 是层级聚合和模板；∂M 是对环境版本的引用边界。**十三个坐标都是公开分量，不含具体学习者**；∂M 声明环境版本引用，也属公开数据。负载、证书、支持族与行动契约绑定记录；聚合按第 09 章的成员类型组织学习节点。硬演绎、放缩与契约先修由这些数据按第 06 章派生，不依赖个人状态。

这些分量**按 2.1 的内部化判据**在第 02 章高阶语言中分型：Record、LearnNode、Code、CertCode、Action、Aggregate、Template 与角色标号域 Role 为互异基本类型（核心签名的完整基本类型清单见附录 E，本段只列本节用到的名字）；Payload 为到代码的函数，HasRole:Record→Role→o，Input:Action→Record→o，Produces:Action→Record→o 等为谓词。有限性和检查器的标准含义先在 ZFC 元层给出；内部编码只解释其被编码部分，不添覆盖自身语言的全局真理谓词。

**定义 4.2（合法本体条件）。** 结构 M 合法当且仅当满足以下条件；这是条件清单的合取，不是一组无需检验的标签。

| 条件 | 精确要求 |
|---|---|
| 身份功能性 | 每个引用在一个版本中恰有一份不可变负载；同名新内容必须用新版本引用 |
| 负载良构 | 每个记录属于定义 4.4 的一个构造类型并带所需形成见证 |
| 节点组织良构 | 每个学习节点满足定义 4.12 的字段与引用条件；中心、内容、先修与目标引用可解析 |
| 引用封闭 | 每个引用要么指向 R_M 或 L_M 的条目，要么指向 ∂M 中声明的环境版本，不能悬空伪装成空依赖 |
| 认证可靠 | 被标作检查通过的证书确实满足固定检查器 Check_T（见命题 2.14）；未编码的数学论证使用不同的证据标签 |
| 行动独立 | Λ 的形成不调用路径规划或个体掌握估计，见第 06 章 |
| 支持有型 | 表达/证明/路线概念支持与输入资源分开；Unknown 与精确空值分开 |
| 层级与溯源 | 聚合保持成员及其层级类型（第 09 章），派生视图保留到环境的来源 |
| 外部隔离 | Payload、Cert、公共契约、硬关系定义与学习节点的公共承诺不含个人标识、观察或学习状态字段 |

表中各条的判据位置：身份功能性与负载良构见定义 4.3–4.4；节点组织良构见定义 4.12；引用封闭见定义 4.1 的 ∂M；认证可靠见命题 2.14；行动独立见第 06 章定义 6.5–6.6；支持有型见第 05 章定义 5.9–5.12；层级与溯源见第 09 章与 11.1；外部隔离见第 07 章与命题 1.5 的检查义务。

这些公理不要求每份有限档案存储所有语法候选或全部真后果。生成完整性与存储完整性不同；稀疏登记实例通过边界引用说明未展开部分。若声称某实例是生成闭包，须另证该闭包性质。

## 4.2　知识记录：构造与形成证据

**定义 4.3（不可变知识记录）。** 记录为

\[
r=(id,k,d),\qquad d\in Data_k.
\]

其中 **Data_k 是定义 4.4 中 k 型构造的有限描述负载所成的域**，每份负载描述有限，域本身可以无限；id 是版本内的唯一标识符，k 是构造类型，d 是有类型负载，映射 id ↦ (k,d) 在一个版本内**函数式**（这正是定义 4.2 的身份功能性）。同一有限描述可以有不同来源记录；固定 id 不允许同时指向不同 k,d。若有形式表达，背景记录为 (T,Ξ,Γ,τ)：Ξ 为类型环境，Γ 为公式假设，τ 为表达类型。记录与服务它的学习节点是多对多：一条证明记录可以在多个学习节点中出现，学习节点不复制记录、也不改变记录的身份与负载。

**定义 4.4（记录构造与形成条件）。**

| 构造类型 | 有限负载 | WF 条件（以及哪些留给另行认证） |
|---|---|---|
| Symbol | 声明、类型、签名版本 | 声明合法；不要求它已有特定真实解释 |
| Term | (T,Ξ,t,τ) | Ξ⊢t:τ；不要求 t 处于某逻辑正规形 |
| Concept | 对象类型、参数、谓词 P | P 类型正确；参数经明确 λ 闭合形成概念表示 |
| Definition | 新符号、旧项、扩张记录 | 默认使用第 03 章的旧语言项定义；更广规格另附实现/闭合证书 |
| Claim | (T,Ξ,Γ,φ) | φ 为 o 型；合法不等于可证 |
| Proof | 目标 Claim、有限证书代码 | 代码语法合法；是否 Check=1 是另一个认证字段 |
| Example | 概念引用、对象规格、满足断言 | 类型及引用正确；满足性另证，不能假称任意模型都可判 |
| Counterexample | 精确目标、对象规格、失败见证 | 引用和量词类型正确；确实反驳另需证书 |
| Problem | 输入输出、目标规格、约束 | 任务接口类型正确；是否已解决另有公共来源记录 |
| Theory | 语言、演算、公理呈现/模块引用 | 有限呈现代码或明确的环境理论引用；公理一致性不由 WF 保证 |
| Construction | 输入输出、步骤规格、验证目标 | 有限步骤及引用类型正确；正确性及终止性分别认证 |
| Method | 范围、公共接口、启发体、案例引用 | 记录格式与引用合法；不要求启发体成为决定算法 |
| Representation | 对象、表达介质、对应说明 | 介质/对象匹配；等价或保真另行认证 |
| MisconceptionPattern | 错误规则、任务、反例、范围 | 公共描述，不包含某个人是否持有它 |

公理、定理、性质是 Claim 的角色：公理角色需要相应理论的成员见证；定理角色需要认证证明或清楚标记的引用证据；性质角色说明用途。全局方法和局部方法是 Method 的范围标签。上述公理、定理、性质角色是 Claim 的标签，**不改变构造类型 k**；其他构造也可拥有各自的合法角色，例如第 05 章的概念与符号锚定。角色可以重叠，但不把不同构造类型混成一个无型记录。学习节点不是表中的第 15 种构造类型：记录描述数学内容，学习节点描述一次学习的组织（定义 4.12），两者不互相替代。

**命题 4.5（良构与真理分离）。** 在有效呈现及有限形成见证条件下 WF 可判，但**仅由 WF(r) 不能推出**记录命题为真或可证（WF 再加上相应的认证字段可能给出更多，见定义 4.4 各行的区分）。**（PROOF）**

**证明。** 表格中的 WF 只执行有限解析、类型、引用与证书格式检查；理论成员需要可判的引用见证。Claim 构造允许任一良类型 φ，因此也允许 φ 与 ¬φ；它不可能仅凭语法就同时认证二者为数学真理。∎

对任意无有效呈现的理论仍可定义语义记录，但不能沿用本命题的算法承诺。记录可以只承载一次已核对的计算或一个失败见证；学习节点（定义 4.12）能否满足一次学习目标，是另一件事，不由本命题回答。

## 4.3　有限生成与自动枚举

**定义 4.6（候选宇宙）。** 固定有效可数符号表、有限字符串编码、规则表与公开理论呈现集合。种子 S 包含符号声明、有限描述原子及背景模块代码。自动生成所用的种子、规则索引与理论引用须有有效枚举，成员调用携带有限形成或枚举见证；仅有可数性不足以保证可枚举。F 是单调的有限元构造规则族（X⊆Y ⟹ F(X)⊆F(Y)），实例通过可判形成见证核验。置

\[
U_0=S,\qquad U_{n+1}=U_n\cup F(U_n),\qquad
U_\Sigma=\bigcup_{n<\omega}U_n.
\]

每份记录描述是有限树或有限带引用记录；引用目标采用已有合法记录或明确环境代码。相互引用的公共导航边可以后登记，不把未证的循环定义当作形式内容。

**定理 4.7（最小生成）。** 设 F 单调，则 U_Σ 是包含 S 的最小 F-闭集合；可数种子与可数有效规则产生可数 U_Σ。**（PROOF）**

**证明。** 每次构造仅用有限多个输入，其阶段编号有最大值，输出位于下一阶段，故 U_Σ 闭合。设 Y⊇S 且 F(Y)⊆Y：U_0=S⊆Y；若 U_n⊆Y，由单调性 F(U_n)⊆F(Y)⊆Y，故 U_{n+1}⊆Y；归纳得各 U_n⊆Y，故 U_Σ⊆Y。有限元规则作用于可数域的有限元组所得结果可数，可数并仍可数。∎

这里使用 ω 阶段就足够，不将 L_α 的超穷层级移植到有限语法。

**定义 4.8（公平候选生成）。** 按自然数代码递增枚举全部有限描述，或先编码到固定有限字母表，再按编码长度及层内字典序枚举；逐一检查合法的形成树，输出通过者。不能只按可数无限符号表中的符号个数逐层耗尽，因为长度为 1 的一层就可能无限。对公理枚举见证和证明搜索采用交错枚举。每个有限合法候选最终被访问。避免重复可用规范代码集合，但不把逻辑等价当作去重判断。

**命题 4.9（枚举覆盖与边界）。** 每个有有限合法描述及有限认证见证的候选最终输出；不保证在有限时间输出全部候选，也不保证识别全部标准语义真理。**（PROOF）**

**证明。** 其全部代码、规则索引和见证长度有有限最大界，枚举到足够预算时包含该对象。不存在的证据可能被永久搜索，因此整体决定性不随之成立。∎

自动生成的是基础表达、记录及证书候选；有效检查进一步产生认证层。人工选择研究重点及添加公开解释，不负责穷举基础语法。

**说明（枚举覆盖的是记录候选）。** 学习节点由组织接口登记（定义 4.12），其字段与引用可作有限检查；可以枚举候选组织，但定理 4.9 的覆盖边界不自动延伸为“组织得是否合适”，后者属于第 09 章的组织依据与第 10 章的内容检查。

## 4.4　稳定身份与版本

**定义 4.10（记录与学习节点的相等）。** 记录相等按 id,k,d；学习节点相等按其不可变负载 (id,v,c,B,R,P,g) 的函数式映射。表达可另按 α、βη、可证等价或模型外延相等比较，各自带类型和背景。后四者都不自动推出记录相等或学习节点相等。

规范表达锚定可以对 α 代码采用一个确定的生成引用；带不同来源、角色或材料的记录仍独立存在。这样允许机械识别绑定名差异，又保留不同内容记录。

独立的来源记录不必全部成为第 05 章 κ 的同码别名。该查询须有限返回，因此在固定登记版本中，同一规范表达只登记有限个概念锚点；更多来源经独立的溯源关联保存，不据此合并记录身份。

**命题 4.11（学习者替换保持身份）。** 若 M 不变，任何外部模型 E₁,E₂ 及状态 s₁,s₂ 对记录身份、WF、已登记证明的 Check 结果，以及学习节点的字段、目标与注册摘要给出相同值。**（PROOF）**

**证明。** 这些判断均只读取固定的 id、负载、签名、证书与学习节点字段，不读取外部状态。函数性给出相等。∎

新增证明应建立新 Proof 记录并追加认证关联，不改旧证明内容；改写定义正文则建立新版本并给兼容/翻译说明。学习者答对题只更新外部记录，不能借用“版本更新”绕过此隔离。

## 4.5　学习节点：中心、内容、先修与目标

一个定义说明对象是什么；一个学习节点帮助学习者理解它为什么出现、如何使用，以及哪些判断有依据。节点的完整性由“一次学习”定义，而不是由篇幅或标题形态定义。

**定义 4.12（学习节点）。** 公共学习节点记为

\[
n=(id,v,c,B,R,P,g).
\]

| 分量 | 含义 |
|---|---|
| id,v | 稳定身份与内容版本 |
| c | 中心对象或中心任务；有类型引用（原子、分子或记录） |
| B | 有限内容集；条目分型为“记录引用条目”或“解释条目” |
| R | 内容之间的关系：解释、证明、举例、应用等角色 |
| P | 本节点声明的先修与背景；分型引用 |
| g | 本次学习承诺的目标与检查任务 |

形成条件（均为有限检查）：id 在版本内唯一且负载函数式；c 的引用可解析且类型正确；B 非空有限，记录引用条目的引用可解析并带内容角色，解释条目带来源或未决标记；R 只引用 B 内的条目；P 的每一项是学习先修（指向学习节点）、内容先修（指向记录或表达）或背景声明（指向 ∂M 的环境引用）三者之一且可解析；g 含一句目标陈述与至少一项检查任务；全部字段不含个人标识、观察或学习状态。**（DEF）**

**说明（组织不等于证明）。** 学习节点内容完整，不蕴含其全部内容已证明，也不蕴含学习者已掌握；记录引用条目中充当证据的引用仍按第 15 章的状态核对。

**说明（角色与尺度是两套坐标）。** “定义、定理、例子、方法、推论”是内容角色；“原子、分子、节点、单元、话题、子学科”是尺度。同一内容可以承担多个角色，角色不改变尺度，反之亦然。推论是否纳入节点由目标决定：围绕拓扑流形节点的开子空间命题可以完整写在节点内；需要独立学习时也可以另立节点，用引用复用同一知识记录。判定一个内容整体是不是节点，不依据标题里有没有并列词，也不依据篇幅，而依据中心对象、先修与目标是否共同确定了一次学习任务。

**说明（共享与复用）。** 同一记录可以服务多个学习节点；同一中心对象也可以围绕不同目标组织多个学习节点。不存在预设的一一对应，也不通过复制记录消除共享。节点之间对同一记录的复用由引用关系登记，不改变记录身份。

**说明（公共承诺与个人适配）。** g 是公共学习承诺 g_n。个人目标 g_E、预算与代价模型属于外部模型 E，适配结果属于派生结果 D；适配只读取公共结构，不改写学习节点版本。候选代价部分未知时，只报告已知候选中的最佳集合与未决集合，最优性标为未决（核验入口 S06；适配语义见第 07 章与 D.1）。相对最优性是相对于声明模型的，不是对真实学习者普遍最优的断言。

**说明（一个例子）。** “拓扑流形”节点的中心是分子 P_n（例 9.16），内容是动机、定义、条件分析、例子、性质与一条推论证明；“黎曼积分”节点的中心是下、上达布积分与逐点相等谓词（例 9.18）。两条实例链的完整构造见第 09 章；本节只登记接口。

## 4.6　方法记录：严格外壳与启发体

**定义 4.13（方法记录接口）。**

\[
\mathrm{meth}=(name,scope,In,Out,Pre,Post,Use,Demo,Fail,body).
\]

In/Out 为任务与候选结果的类型；Pre/Post 是有明确语义的条件，允许标注尚不能完全形式化的范围；Use 是结构性概念锚定；Demo/Fail 是公共案例及失败范围；body 是自然语言启发体。WF 检查字段格式与引用，不谎称可以判定一切 Pre/Post。

全局方法包括直觉建立与失效、内省、从特例切入、反例构造、逆向分析、不变量、应用替代练习、可视化。局部方法如“用夹逼估计处理特定极限”，可实例化全局策略。一个方法若后来取得严格算法和正确性证明，可另建 Construction 与 Proof 记录；启发内容与形式实现通过显式关系连接，不偷换。

一般方法呈现可作为 Λ 中的公开行动，但其证书仅保证任务接口匹配及内容合法。学习成功率、难度、掌握变化均由第 07 章外部模型评价。

## 4.7　学习节点与外部认知接口

本体记录是可独立引用并具有明确输入输出接口的知识描述；学习节点是组织接口；两者都**不是预设对所有人的最小心理单位**。本体保存分解候选及重构契约；认知原子性

\[
\operatorname{Atom}_E(s,n;g,\mathcal R,\mathcal D)
\]

由第 07 章定义在外部，其 n 是学习节点或节点组。给定学习目标和表征，某学习节点可整体呈现，也可分解成多个目标；这是外部组块及派生视图的差异。语法原子 Atom_G（定义 2.19）与此处 Atom_E 分别命名、不得混用：同一学习节点可以在一个外部模型中整体呈现、在另一个模型中拆开，而语法尺度不随模型变化。

有限可判的分解域可供穷举最小性检验；一般“没有想到更小分解”不是极小性证明。方法记录也可参与这类分解，但不能强制其启发体成为封闭形式公式。

## 4.8　从本体到具体网络

知识网络是合法本体 M 的关系呈现；学习网络是 (M,E,s,g,b,ρ) 的派生结果；可视化网络是带溯源和保持声明的显示投影。画图中的一个点可以是记录、学习节点、聚合或事件，必须标注其类型。不同图的点数、布局和显示标签不决定本体同构。

概念函数、第 06 章关系、第 08 章结构保持映射、第 11 章视图、第 12 章规划都以本章接口为输入。外部模型的知识空间可以成为一个 Theory/Model 描述记录，但其某位学习者的实际状态始终不是 M 的一项运行数据。
